ماشىنا ئۈگىنىش 5-باب – ئەۋەت دەرىخلىرى (Random Forest)

Random Forest (ئەۋەت دەرىخلىرى) — ماشىنا ئۈگىنىشنىڭ ئەڭ قۇۋۋەتلىك، ئىشقا سېلىش ئاسان، ئىشەنچلىك ئالگورىتملىرىنىڭ بىرىدۇر. بۇ ئالگورىتم بىر قانچە قەرر دەرىخىنى (Decision Tree) بىرلەشتۈرۈپ، ئەڭ ياخشى نەتىجىنى (majority vote ياكى o'rtacha) چىقىرىدۇ.

Decision Tree نىڭ ئاشۇرۇپ ئۈگىنىش (overfitting) قىلىش كەمچىلىكىنى ئەۋەت دەرىخلىرى ئەقىللىق ئۇسۇل بىلەن تۈزەيدۇ.

Random Forest is one of the most powerful, easy-to-use, and reliable algorithms in machine learning. It combines multiple Decision Trees and outputs the best result via majority voting (for classification) or averaging (for regression). It effectively fixes the overfitting weakness of a single Decision Tree.
1. Random Forest نېمە؟
1. What is Random Forest?

Random Forest — باغلىنىش ئۇسلۇبى (Ensemble Learning) نىڭ بىر تۈرى. بۇ ئۇسلۇب بىر قانچە ئالگورىتمنى بىرلەشتۈرۈپ، ئۇلارنىڭ جەمئىي قۇۋۋىتى بىلەن نەتىجىنى ياخشىلايدۇ.

  • كۆپ سانلىق قەرر دەرىخلىرى قۇرۇش.
  • ھەر بىر دەرىخ مەلۇماتنىڭ تەصادۇفىي بولۇقى (Bootstrap sample) بىلەن تەربىيەلەيدۇ.
  • ھەر بىر دەرىختىكى ھەر بىر نۇرۇقتا تەصادۇفىي ئۆزگەرگۈچ تاللاش قىلىنىدۇ.
  • كلاسسىفىكاتسىيە بولسا — كۆپچىلىك قەررى (Majority Vote) ئېلىنىدۇ.
  • رېگرېسسىيە بولسا — ئوتتۇرا قىممەت (Average) ھېسابلىنىدۇ.

Random Forest is a type of Ensemble Learning that combines multiple models to improve overall performance.

  • Builds many Decision Trees.
  • Each tree is trained on a random bootstrap sample of the data (sampling with replacement).
  • At each split, only a random subset of features is considered.
  • For classification: final prediction = majority vote.
  • For regression: final prediction = average of all trees.
2. قانداق ئىشلەيدۇ؟
2. How Does It Work?
  1. Boostrap Sampling: بىرلىك مەلۇماتتىن n دانە مەلۇماتنى قايتا قويۇش بىلەن (with replacement) تەصادۇفىي تاللايدۇ.
  2. Decision Tree قۇرۇش: ھەر بىر تاللانغان بولۇق بويىچە بىر قەرر دەرىخى قۇرۇش.
  3. Feature Randomness: ھەر بىر نۇرۇق بولۇپ ئايرىلغاندا، بارلىق ئۆزگەرگۈچنى ئەمەس، تەصادۇفىي چەكلىمىلىك ئۆزگەرگۈچ (مەسىلەن: sqrt(features)) نىلا تاللايدۇ.
  4. بىرلەشتۈرۈش: بارلىق دەرىخلەرنىڭ نەتىجىسىنى جەملايدۇ.

مەسىلەن: 100 دەرىخ بار. ھەر بىر دەرىخ "ھەئە" ياكى "ياق" دەيدۇ. ئەگەر 70 دەرىخ "ھەئە" دېسە، نەتىجە — **"ھەئە"**.

  1. Bootstrap Sampling: Randomly select n samples from the dataset with replacement.
  2. Build a Decision Tree for each sampled subset.
  3. Feature Randomness: At each node split, consider only a random subset of features (e.g., sqrt(total_features)).
  4. Aggregate Predictions: Combine all tree outputs.

Example: With 100 trees, if 70 predict "Yes" and 30 predict "No", the final prediction is "Yes".

3. نېمە ئۈچۈن ئىشلىتىلىدۇ؟
3. When to Use Random Forest?
  • كلاسسىفىكاتسىيە: كرېدىت مۇۋاپىقلىقى، كىسىلدىك باھالاش، كىشى تەلىپى.
  • رېگرېسسىيە: ئۈي باھاسى، ماشىنا باھاسى، ئىقتىسادىي كۆرگۈزگۈچ.
  • مەلۇماتتىكى تەسىرگۈچ ئۆزگەرگۈچلەرنى (Feature Importance) بايان قىلىش.
  • Classification: Credit approval, disease diagnosis, customer churn prediction.
  • Regression: House pricing, car valuation, economic forecasting.
  • Identify important features that drive predictions.
4. ئالاھىدىلىكى ۋە كەمچىلىكى
4. Advantages and Disadvantages

ئالاھىدىلىكى:

  • Decision Tree گە قارىغاندا ئاشۇرۇپ ئۈگىنىش (Overfitting) نىڭ خەۋىپى بەك تۆۋەن.
  • سانلىق ۋە كاتېگورىيىلىك مەلۇمات بىلەن ئىشلەيدۇ.
  • مەلۇماتنى نورماللاشتۇرۇش كېرەك ئەمەس.
  • Feature Importance ئىقتىدارى بار.

Advantages:

  • Very low risk of overfitting compared to a single Decision Tree.
  • Works with both numerical and categorical data.
  • No need for feature scaling or normalization.
  • Provides built-in feature importance scores.

كەمچىلىكى:

  • Decision Tree گە قارىغاندا تۈسۈنىش قىيىن.
  • چوڭ مەلۇماتدا ئەمەلگە ئاشۇرۇش ۋاقتى ئۇزۇن.

Disadvantages:

  • Less interpretable than a single Decision Tree ("black-box" nature).
  • Slower prediction speed on very large datasets.

6. مۇھىم پارامېترلار
6. Key Parameters
  • n_estimators: قانچە دەرىخ قۇرۇش كېرەك؟ (ئادەتتە 100–500).
  • max_depth: ھەر بىر دەرىخنىڭ ئېگىزلىكى.
  • max_features: ھەر بىر نۇرۇقتا تاللىنىدىغان ئۆزگەرگۈچ سانى.
  • n_estimators: Number of trees to build (typically 100–500).
  • max_depth: Maximum depth of each tree.
  • max_features: Number of features to consider at each split.
