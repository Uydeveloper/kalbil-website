نېرۋاتور 6-باب – RNN (Recurrent Neural Network)

RNN — ۋاقىتلىق قاتار مەلۇماتى (Sequential Data) بىلەن ئىشلەيدىغان نېرۋاتور. مەسىلەن: جۈملىلەر، ئاۋاز، ھەرەكەت داتچىلىرى. RNN نىڭ ئالاھىدىلىكى — ئۆتمۈش خاتىرىسىنى ساقلايدۇ.

RNNs process sequences by maintaining a hidden state that carries information from previous time steps — ideal for text, speech, and time-series data.
1. RNN نېمە؟
1. What is an RNN?

RNN — ھەر بىر قادامدا (time step) ئۆزىنىڭ يوشۇرۇن ھالىتى (hidden state) نى يېڭىلايدۇ. بۇ ھالەت ئۆتمۈش مەلۇماتنى ساقلايدۇ، شۇڭا جۈملەنىڭ ماڭىسىنى تۈسۈنىدۇ.

At each time step t, RNN computes: \( h_t = \text{tanh}(W_{xh} x_t + W_{hh} h_{t-1} + b) \) where \( h_{t-1} \) is the memory from the previous step.

2. RNN نىڭ تۈزۈلمىسى
2. Structure

كىرگۈزگۈچ: x₁, x₂, ..., xₜ → يوشۇرۇن ھالەت: h₁, h₂, ..., hₜ → چىقىرىش: y₁, y₂, ..., yₜ

Input: x₁, x₂, ..., xₜ → Hidden: h₁, h₂, ..., hₜ → Output: y₁, y₂, ..., yₜ

3. قوللىنىش ساھەلىرى
3. Applications
  • ئۇيغۇرچە جۈملىنى بايان قىلىش (ئاخىرقى سۆزگە قاراپ كېيىنكى سۆزنى باسان)
  • ئاۋاز-تېكىست ئايلاندۇرۇش
  • دېڭىز بايلىقى باھاسى تەھلىلى
  • Language modeling (predict next word)
  • Speech-to-text
  • Stock price forecasting
4. كەمچىلىكى
4. Limitations
  • Gradient Vanishing (Gradients تازىلىنىپ كېتىش): ئۇزۇن جۈملىلەرنى ئۆگىنىش قىيىن.
  • Gradient Exploding: ۋازىنلار سانسىز چوڭ بولۇپ كېتىدۇ.
  • Vanishing gradients: Struggles with long-term dependencies.
  • Exploding gradients: Weights grow uncontrollably.
