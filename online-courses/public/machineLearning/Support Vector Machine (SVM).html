ماشىنا ئۈگىنىش 6-باب – SVM (Support Vector Machine)

SVM (قوشۇمچى ۋېكتور ماشىنىسى) — ماشىنا ئۈگىنىشنىڭ ئەڭ قۇۋۋەتلىك كلاسسىفىكاتسىيە ئالگورىتملىرىنىڭ بىرىدۇر. بۇ ئالگورىتم ئىككى سىنىپنى ئايرىش ئۈچۈن ئەڭ كەڭ مارگىن (Margin) غا ئىگە بولغان دېگىلىك يۈز (Hyperplane) نى تاپىدۇ.

SVM نىڭ ئالاھىدىلىكى — چىچىرەڭ مەلۇمات ئارىلىرىنى تەسىرلىك ئاجراتالايدىغانلىقى، يەنە بىر ئالاھىدىلىكى — كېرنېل تىخنىكىسى (Kernel Trick) ئارقىلىق سىزىقسىز (non-linear) مۇناسىۋەتلەرنى ھەل قىلالايدىغانلىقى.

Support Vector Machine (SVM) is one of the most powerful classification algorithms in machine learning. It finds the optimal hyperplane that separates two classes with the maximum possible margin. Its key strengths are:
  • Effective in high-dimensional spaces.
  • Uses the kernel trick to handle non-linear decision boundaries.
1. SVM نېمە؟
1. What is SVM?

SVM — ئىككى ياكى ئۇندىن ئارتۇق سىنىپنى ئەڭ ئۈنۈملۈك دېگىلىك يۈز (Best Separating Hyperplane) بىلەن ئاجرايدىغان ئالگورىتم. ئاجراتقۇچنىڭ ئىككى يېنىدا مارگىن (Margin) دەپ ئاتىلىدىغان قۇرۇق ئارىلىق بولىدۇ. بۇ مارگىن ئىچىدە **قوشۇمچى ۋېكتورلار** (Support Vectors) دەپ ئاتىلىدىغان مۇھىم نۇقتىلار بار.

SVM is an algorithm that separates classes using the best possible hyperplane. The goal is to maximize the margin — the distance between the hyperplane and the nearest data points (called support vectors).

2. قانداق ئىشلەيدۇ؟
2. How Does SVM Work?

1. **دېگىلىك يۈز تاپىش**: ئىككى سىنىپنى ئاجرايدىغان سىزىق (2D دا) ياكى يۈز (3D دا) قۇرۇش.
2. **مارگىن ماكىسلاشتۇرۇش**: دېگىلىك يۈزگە ئەڭ يېقىن نۇقتىلاردىن ئىبارەت مارگىن ئەڭ كەڭ بولۇشى كېرەك.
3. **قوشۇمچى ۋېكتورلار**: مارگىن چېتىدىكى نۇقتىلار — بۇلار مودېلنى قۇرۇشقا مۇھىم تەسىر كۆرسىتىدۇ.

ئەگەر مەلۇمات سىزىق بىلەن ئاجرىمايدىغان بولسا، SVM كېرنېل تىخنىكىسى (Kernel Trick) نى ئىشلىتىپ، مەلۇماتنى يۇقىرى ئۆلچەملىك فۇڭكىسىيە بۇعدىكى ئەزالىق قىلىپ، ئۇ يەردە سىزىق بىلەن ئاجرىتىدۇ.

1. **Find the hyperplane**: A line (in 2D) or plane (in 3D) that separates classes.
2. **Maximize the margin**: The distance between the hyperplane and the closest points should be as large as possible.
3. **Support Vectors**: These are the data points that lie on the margin edges — they define the model.

If data is not linearly separable, SVM uses the kernel trick to map the data into a higher-dimensional space where a linear separation becomes possible.

3. نېمە ئۈچۈن ئىشلىتىلىدۇ؟
3. When to Use SVM?
  • مەلۇمات سانى ئاز، لېكىن ئۆزگەرگۈچ سانى كۆپ بولغاندا (مەسىلەن: گېنومىكا).
  • تېببىي تەڭشەش (كىسىلدىك تەنھۇرۇشى).
  • تېكىست كلاسسىفىكاتسىيە (ئەخبارات تۈرلىرى، سېنتىمېنت تەھلىلى).
  • سانلىق ۋە كاتېگورىيىلىك مەلۇمات كىرگۈزگۈچ بولغاندا.
  • When you have few samples but many features (e.g., genomics, text classification).
  • Medical diagnosis (e.g., cancer detection from imaging).
  • Text classification, image recognition, handwriting recognition.
  • Effective for both numerical and categorical inputs (after encoding).
4. ئالاھىدىلىكى ۋە كەمچىلىكى
4. Advantages and Disadvantages

ئالاھىدىلىكى:

  • يۇقىرى ئۆلچەملىك مەلۇماتتا ياخشى ئىشلەيدۇ.
  • مارگىن ماكىسلاشتۇرۇش ئارقىلىق ئاشۇرۇپ ئۈگىنىشنى (Overfitting) چەكلىيۇدۇ.
  • كېرنېل تاللاش ئارقىلىق سىزىقسىز مۇناسىۋەتلەرنى ھەل قىلالايدۇ.
  • قوشۇمچى ۋېكتورلار سانى ئادەتتە ئاز، شۇڭا مودېل چوڭ بولمايدۇ.

Advantages:

  • Performs well in high-dimensional spaces.
  • Resistant to overfitting due to margin maximization.
  • Kernel trick allows modeling of complex non-linear boundaries.
  • Only support vectors are stored — memory efficient.

كەمچىلىكى:

  • چوڭ مەلۇمات بىلەن ئىشلىگەندە ۋاقىت ئۇزۇن تۇرىدۇ.
  • مەلۇماتنىڭ نورماللىشى (scaling) زۆرۈر.
  • كېرنېل ۋە پارامېتر تاللاش تەجرۈبە تەلەپ قىلىدۇ.
  • كۆپ سىنىپلىق (multi-class) مەسىلىلەردە قوشۇمچە تەكشۈرۈش كېرەك.

Disadvantages:

  • Slow training on very large datasets.
  • Requires feature scaling (e.g., StandardScaler).
  • Choosing the right kernel and parameters needs experience.
  • Not naturally multi-class — uses one-vs-one or one-vs-rest strategies.
5. مۇھىم پارامېترلار
5. Key Parameters
  • C: مارگىن قاتىشىق دەرىجىسىنى باشقۇرۇش. C چوڭ بولسا — مارگىن تار، C كىچىك بولسا — مارگىن كەڭ.
  • kernel: "linear", "poly", "rbf" (ئەڭ كۆپ ئىشلىتىلىدىغان), "sigmoid".
  • gamma: "rbf" كېرنېلىدە مەلۇمات تەسىر دائىرىسى. gamma چوڭ بولسا — ئەگىز ئۈگىنىش، gamma كىچىك بولسا — يۇمشاق مودېل.
  • C: Regularization parameter. High C = narrow margin (less regularization). Low C = wider margin (more regularization).
  • kernel: "linear", "poly", "rbf" (most common), "sigmoid".
  • gamma (for RBF): Controls influence of a single training example. High gamma = complex model, low gamma = smoother decision boundary.
