What is Linear Regression?

سىزىقلىق رېگرېسسىيە بىر ياكى بىر نەچچە مۇستەقىل ئۆزگەرگۈچى (X) بىلەن بىر تۈگىملىك ئۆزگەرگۈچى (y) ئارىسىدىكى سىزىقلىق مۇناسىۋەتنى مودېللاش ئۇسۇلىدۇر.

Linear regression is a method for modeling the linear relationship between one or more independent variables (X) and a dependent variable (y).

Ordinary Least Squares (OLS) Method

سىزىقلىق رېگرېسسىيەنىڭ مەقسىتى ھەقىقىي y قىممىتى بىلەن تەخمىنىي y قىممىتى (ŷ) ئارىسىدىكى پەرق (قالدۇق) لارنىڭ كۋادراتلىرىنىڭ يىغىندىسىنى مىنىمۇم قىلىش:

The goal of linear regression is to minimize the sum of squared differences (residuals) between the actual y values and the predicted y values (ŷ):

Minimize: Σ(yᵢ - ŷᵢ)²

β₀ ۋە β₁ نى ھېسابلاش فورمۇلاسى:

Formulas for calculating β₀ and β₁:

β₁ = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / Σ[(xᵢ - x̄)²]
β₁ = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / Σ[(xᵢ - x̄)²]
β₀ = ȳ - β₁x̄
β₀ = ȳ - β₁x̄

سىزىقلىق رېگرېسسىيە پرىزۇمپتسىيەلىرى (شەرتلەر):

Linear Regression Assumptions (Conditions):

  1. سىزىقلىقلىق: X بىلەن y ئارىسىدا سىزىقلىق مۇناسىۋەت بولۇشى
    Linearity: There should be a linear relationship between X and y
  2. مۇستەقىللىق: قالدۇقلار (errors) ئۆز-ئارا مۇستەقىل بولۇشى
    Independence: Errors should be independent of each other
  3. نورماللىق: قالدۇقلار نورمال تارقىلىشقا ئىگە بولۇشى
    Normality: Errors should be normally distributed
  4. بەت-باراۋەرلىك: قالدۇقلارنىڭ سەپ سەپلىرى باراۋەر بولۇشى
    Homoscedasticity: Errors should have constant variance
  5. كوللېنېئېرلىقسىزلىق: مۇستەقىل ئۆزگەرگۈچىلەر ئوتتۇرىسىدا كۈچلۈك باغلىنىش بولماسلىقى
    No multicollinearity: Independent variables should not be strongly correlated with each other

سىزىقلىق رېگرېسسىيەنىڭ چەكلىمىلىرى:

Limitations of Linear Regression:

  • سىزىقلىق بولمىغان مۇناسىۋەتلەرنى مودېللىيالمايدۇ - سىزىقلىق بولمىغان مۇناسىۋەتلەرگە پولىنومىيال رېگرېسسىيە قوللىنىش كېرەك
    Cannot model non-linear relationships - For non-linear relationships, polynomial regression should be used
  • ھەسسىسلىك - سانلىق مەلۇماتتىكى چىقىتىۋېتىش قىممەتلىرىگە (outliers) ھەسساس
    Sensitive to outliers - Sensitive to outliers in the data
  • كۆپ دەرىجىلىك باغلىنىش - مۇستەقىل ئۆزگەرگۈچىلەر ئارىسىدا كۈچلۈك باغلىنىش بولسا، پارامېترلەرنى باھالاش قىيىن
    Multicollinearity - When independent variables are highly correlated, it's difficult to estimate parameters
  • ھەددىدىن زىيادە ئوخشاشلىشىش - مودېل تەربىيەلەش سانلىق مەلۇماتىغا ھەددىدىن زىيادە ئوخشاشلىشىپ، يېڭى سانلىق مەلۇماتقا ئومۇميۈزلۈك ئىشلەلمەيدۇ
    Overfitting - Model may overfit to training data and not generalize well to new data

Python دىكى ئەمەلىي كود

Practical Code in Python

# سىزىقلىق رېگرېسسىيە Python دا
# Linear Regression in Python
from sklearn.linear_model import LinearRegression
import numpy as np

# سانلىق مەلۇمات ھازىرلاش | Prepare data
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 5, 4, 5])

# مودېل قۇرۇش ۋە تەربىيەلەش | Build and train model
model = LinearRegression()
model.fit(X, y)

# تەخمىنلەش | Make prediction
y_pred = model.predict([[6]])
print(f"تەخمىنىي قىممەت: {y_pred[0]}")
print(f"Predicted value: {y_pred[0]}")
