ماشىنا ئۈگىنىش 7-باب – K-يېقىن قوۋشۇق (KNN)

K-يېقىن قوۋشۇق (K-Nearest Neighbors, KNN) — ماشىنا ئۈگىنىشنىڭ ئەڭ سادە، لېكىن قۇۋۋەتلىك ئالگورىتملىرىنىڭ بىرىدۇر. بۇ ئالگورىتم يېڭى نۇمۇنە قايسى سىنىپقا تەۋە بولۇشىنى، ئۇنىڭ يېقىن قوۋشۇقلۇرىنىڭ سىنىپى بويىچە باھالايدۇ.

"قاراڭ، سەنگە ئەڭ يېقىن K دانە دوستىڭ نېمە دەيدۇ؟ شۇنى قىلىش كېرەك!"

K-Nearest Neighbors (KNN) is one of the simplest yet powerful machine learning algorithms. It predicts the class of a new data point based on the classes of its K nearest neighbors in feature space.

"Tell me your closest K friends, and I’ll tell you who you are!"
1. KNN نېمە؟
1. What is KNN?

KNN — ئۈگىنىش سىز (lazy learning) ئالگورىتمى. بۇنىڭ مەنىسى: تەربىيەلەش جەريانىدا ھېچقانداق مودېل قۇرمايدۇ، بەلكى بارلىق مەلۇماتنى ساقلايدۇ. نەتىجە چىقىرىش ۋاقتىدا، يېڭى نۇمۇنە بىلەن بارلىق مەلۇماتنى مەسافە (Distance) بويىچە سېلىشتۇرىدۇ.

ئەڭ كۆپ ئىشلىتىلىدىغان مەسافە ئۆلچىمى — Euclidean مەسافىسى.

KNN is a lazy learning algorithm: it does not build a model during training. Instead, it memorizes the entire dataset. At prediction time, it computes the distance between the new sample and all training samples.

The most common distance metric is the Euclidean distance.

2. قانداق ئىشلەيدۇ؟
2. How Does It Work?
  1. يېڭى نۇمۇنە ئۈچۈن بارلىق تەربىيەلەنگەن نۇمۇنە بىلەن مەسافىنى ھېسابلاش.
  2. ئەڭ كىچىك مەسافىلىك K دانە قوۋشۇقنى تاللاش.
  3. كلاسسىفىكاتسىيە بولسا — K قوۋشۇقنىڭ ئىچىدىكى ئەڭ كۆپ سىنىپنى (majority vote) تاللاش.
  4. رېگرېسسىيە بولسا — K قوۋشۇقنىڭ ئوتتۇرا قىممىتىنى ھېسابلاش.
  1. Compute the distance between the new sample and every training sample.
  2. Select the K nearest neighbors (smallest distances).
  3. For classification: assign the most frequent class among the K neighbors.
  4. For regression: return the average value of the K neighbors.
3. K نى قانداق تاللاش كېرەك؟
3. How to Choose K?
  • K بولسا تاق سان بولۇشى كېرەك (كلاسسىفىكاتسىيەدا تەڭ بولۇشنىڭ ئالدىنى ئېلىش ئۈچۈن).
  • K بەك كىچىك بولسا — ئاشۇرۇپ ئۈگىنىش (Overfitting) خەۋىپى.
  • K بەك چوڭ بولسا — ئۈگىنىش يېتەرلىك بولمىسلىق (Underfitting) خەۋىپى.
  • ئادەتتە K = 3, 5, 7, 9 قاتارلىقلار تاللىنىدۇ.
  • ئەڭ ياخشى K نى cross-validation بىلەن باھالاش مۇمكىن.
  • K should be an odd number to avoid ties in classification.
  • Too small K → overfitting (sensitive to noise).
  • Too large K → underfitting (too general).
  • Common choices: K = 3, 5, 7, 9.
  • Best K can be found using cross-validation.
4. نېمە ئۈچۈن ئىشلىتىلىدۇ؟
4. When to Use KNN?
  • مەلۇمات سادە، غىير مۇرەككەپ بولغان ھالەتلەردە.
  • تەربىيەلەش ۋاقتى قىسقۇچ بولغاندا.
  • ئالگورىتمنىڭ مەنتىقىسىنى تۈسۈش كېرەك بولغان ھالەتلەردە.
  • ئاز سانلىق سىنىپ (2–5) بولغان كلاسسىفىكاتسىيە مەسىلىلىرى.
  • When the dataset is small and simple.
  • When quick prototyping is needed.
  • When model interpretability is important.
  • Classification problems with few classes (2–5).
5. ئالاھىدىلىكى ۋە كەمچىلىكى
5. Advantages and Disadvantages

ئالاھىدىلىكى:

  • ئالگورىتم بەك سانلىق بىلەن سادە.
  • تەربىيەلەش جەريانىدا مودېل قۇرمايدۇ، شۇڭا تەربىيەلەش تېز.
  • يېڭى سىنىپ قوشۇلغاندا، قايتا تەربىيەلەش كېرەك ئەمەس.
  • چوڭ مەلۇماتتىكى تەسىرگۈچ ئۆزگەرگۈچلەرنى بايان قىلىش مۇمكىن.

Advantages:

  • Extremely simple and intuitive.
  • Fast training (just stores data).
  • Easy to add new classes without retraining.
  • No assumptions about data distribution.

كەمچىلىكى:

  • بۇرۇن-كېيىن ئۆزگەرگۈچلەر (Feature Scaling) قىلىش كېرەك.
  • چوڭ مەلۇماتدا باھالاش ۋاقتى بەك ئۇزۇن (ھەر قېتىم بارلىق مەلۇمات بىلەن مەسافە ھېسابلىنىدۇ).
  • كامىتىل مەلۇمات (missing values) بىلەن ئىشلىيالمىسۇ.
  • K نى تاللاش قىيىن.

Disadvantages:

  • Requires feature scaling (e.g., StandardScaler).
  • Slow prediction on large datasets (computes distance to all points).
  • Does not handle missing values well.
  • Performance highly depends on choice of K and distance metric.

7. KNN گە كېرەكلىك تەگدەم
7. Essential Preprocessing for KNN
  • Feature Scaling: Euclidean مەسافىسى ئۆزگەرگۈچنىڭ مىقدارىغا تەسىر قىلىدۇ. شۇڭا ھەر بىر ئۆزگەرگۈچنى StandardScaler ياكى MinMaxScaler بىلەن نورماللاشتۇرۇش كېرەك.
  • كامىتىل مەلۇماتنى تولدۇرۇش: KNN كامىتىل مەلۇمات بىلەن ئىشلىيەلمەيدۇ.
  • ئۆزگەرگۈچ تاللاش: ئەھمىيەتسىز ئۆزگەرگۈچلەر مەسافىنى بۇزۇپ قويىدۇ.
  • Feature Scaling: Euclidean distance is sensitive to feature magnitude. Always scale features using StandardScaler or MinMaxScaler.
  • Handle missing values: KNN cannot compute distance with missing data.
  • Feature selection: Irrelevant features add noise and reduce accuracy.
