Variables and Data Types

1. ئۆزگەرگۈچىلەر (Variables)

1. Variables

ئۆزگەرگۈچىلەر - مەلۇماتنى ساقلاش ئۈچۈن ئىشلىتىلىدىغان كونتىنېرلار

Variables are containers used to store data

ئۆزگەرگۈچى = قىممەت

Variable = Value

مىسال:

Example:

name = "ئەخمەت" - بۇ يەردە name ئۆزگەرگۈچى، "ئەخمەت" قىممىتى

name = "Ahmet" - Here name is variable, "Ahmet" is value

Python 
# ئۆزگەرگۈچى ياساش | Creating variables
name = "ئەخمەت"      # تېكىست | Text
age = 25             # سان | Number
height = 1.75        # كەسىر سان | Decimal number
is_student = True    # مەنپىي/ئىجابىي | True/False

# ئۆزگەرگۈچىلەرنى ئىشلىتىش | Using variables
print("ئىسمى:", name)
print("يېشى:", age)
print("ئېگىزلىكى:", height)
print("ئوقۇغۇچىمۇ؟", is_student)

Control Structures

1. IF شەرتىلىك جۈملىسى

1. IF Conditional Statement

IF جۈملىسى بەلگىلەنگەن شەرت توغرا بولغاندا مەلۇم كود بۆلەكلىرىنى ئىجرا قىلىدۇ

IF statement executes certain code blocks when specified condition is true

شەرت توغرا بولسا

If condition is true

قۇرۇلما:

Structure:

if شەرت:

if condition:

    كود (بوشلۇق بىلەن كىرىندىرۈلۈشى كېرەك)

    code (must be indented with spaces)

Python 
# IF جۈملىسى مىسالى | IF statement example
age = 18

if age >= 18:
    print("سىز ۋاقتىدا!")  # بۇ يەردە 4 بوشلۇق بار | There are 4 spaces here
    print("تاشقى ئەركىنلىكتىن بەھرىمەن بولالايسىز")
    
print("پروگرامما داۋاملىشىدۇ...")

2. FOR ھالقىلىق جۈملىسى

2. FOR Loop Statement

FOR ھالقىقى بىر قانچە قېتىم كودنى قايتا-قايتا ئىجرا قىلىدۇ

FOR loop executes code repeatedly several times

Python 
# FOR ھالقىقى مىسالى | FOR loop example

# 5 قېتىم "Hello" بېسىش | Print "Hello" 5 times
for i in range(5):
    print("Hello")

# تىزىملىكتىكى ھەر بىر تېكىستنى بېسىش | Print each text in list
fruits = ["ئالما", "ئانار", "ئۆرۈك"]
for fruit in fruits:
    print(fruit)

فۇنكسىيەلەر

Functions

1. فۇنكسىيە ياساش

1. Creating Functions

فۇنكسىيەلەر - بىر نەرسىنى قىلىدىغان كود بۆلەكلىرى. ئۇلارنى قايتا-قايتا ئىشلىتىش مۇمكىن.

Functions are blocks of code that do something. They can be used repeatedly.

كىرۈش → فۇنكسىيە → چىقىش

Input → Function → Output

فۇنكسىيە قۇرۇلماسى:

Function structure:

def فۇنكسىيە_ئىسمى(پارامېتر):

def function_name(parameter):

    كود

    code

    return نەتىجە (ئىختىيارىي)

    return result (optional)

Python 
# ساددە فۇنكسىيە ياساش | Creating simple function
def سالونلاش(name):
    print("سالون، " + name + "!")

# فۇنكسىيەنى چاقىرىش | Calling the function
سالونلاش("ئەخمەت")
سالونلاش("ئائىشە")

# قىممەت قايتۇرىدىغان فۇنكسىيە | Function that returns value
def كۆپەيت(a, b):
    نەتىجە = a * b
    return نەتىجە

# فۇنكسىيەنى ئىشلىتىش | Using the function
جاۋاب = كۆپەيت(5, 3)
print("5 × 3 =", جاۋاب)

2. ئەمەلىي مىسال: مەنبە كالکۇلىاتورى

2. Practical Example: Basic Calculator

Python 
# مەنبە كالکۇلىاتور فۇنكسىيەسى | Basic calculator function
def كالكۇلىاتور(a, b, ئەمەل):
    if ئەمەل == "+":
        return a + b
    elif ئەمەل == "-":
        return a - b
    elif ئەمەل == "*":
        return a * b
    elif ئەمەل == "/":
        return a / b
    else:
        return "خاتا: نادۇرۇت ئەمەل"

# كالکۇلىاتورنى سىناش | Testing the calculator
print("10 + 5 =", كالكۇلىاتور(10, 5, "+"))
print("10 - 5 =", كالكۇلىاتور(10, 5, "-"))
print("10 * 5 =", كالكۇلىاتور(10, 5, "*"))
print("10 / 5 =", كالكۇلىاتور(10, 5, "/"))
