NumPy Programming Tutorial | نامپاى دەرىجىلىك دەرىس

دەرس بايانى | Introduction

بۇ بابتا نامپاىنىڭ ئاساسىي تۇشۇنچىلىرى، ماترىتسا (Array) قۇرۇش، ئورنىتىش ھەققىدە ئۆگىنىمىز.

In this chapter, we learn the basic concepts of NumPy, creating arrays, and installation.

نامپاىنى ئورنىتىش | Installing NumPy

نامپاىنى ئورنىتىش ئۈچۈن تۆۋەندىكى كوماندىنى ئىشلىتىڭ:

pip install numpy

Use the following command to install NumPy:

pip install numpy

ماترىتسا قۇرۇش | Creating Arrays

ئاددىي ماترىتسا قۇرۇش:

import numpy as np

# ئاددىي ماترىتسا
arr = np.array([1, 2, 3, 4, 5])
print(arr)

2-ئۆلچەملىك ماترىتسا:

# 2-ئۆلچەملىك ماترىتسا
arr_2d = np.array([[1, 2, 3], [4, 5, 6]])
print(arr_2d)

Creating a simple array:

import numpy as np

# Simple array
arr = np.array([1, 2, 3, 4, 5])
print(arr)

2D array:

# 2D array
arr_2d = np.array([[1, 2, 3], [4, 5, 6]])
print(arr_2d)

ماترىتسا ئۆلچىمى | Array Dimensions

ماترىتسىنىڭ ئۆلچىمىنى كۆرۈش:

print("شەكلى:", arr_2d.shape)
print("ئۆلچەم سانى:", arr_2d.ndim)
print("ئېلېمېنت سانى:", arr_2d.size)

Checking array dimensions:

print("Shape:", arr_2d.shape)
print("Number of dimensions:", arr_2d.ndim)
print("Number of elements:", arr_2d.size)

چۈشەندۈرۈش | Explanation

بۇ بابتا نامپاىنى ئورنىتىش، ماترىتسا قۇرۇش، ماترىتسىنىڭ ئۆلچىمىنى كۆرۈشنى ئۆگىنىدۇق. بۇ نامپاى بىلەن ماتماتىكىلىق ھېسابلاشنى باشلاشنىڭ ئەڭ مۇھىم قەدەمى.

In this chapter, we learned how to install NumPy, create arrays, and check array dimensions. This is the most important step to start mathematical calculations with NumPy.
