9. ئاساسىي سىزىقلىق ئالجىبرا ھېسابلاش

9.1 نورم، نورماللاشتۇرۇش، ئورتوقوناللاشتۇرۇش

# ۋېكتور نورمى v = np.array([3, 4]) norm = np.linalg.norm(v) print("ۋېكتور نورمى:", norm) # نورماللاشتۇرۇش normalized_v = v / norm print("نورماللاشتۇرۇلغان ۋېكتور:", normalized_v) print("نورماللاشتۇرۇلغان ۋېكتور نورمى:", np.linalg.norm(normalized_v))

9.2 ئالماشتۇرۇش، ئىز، تەتۈر ماترىتسا، ماترىتسا ئانىقلىقى

# ماترىتسا ئالماشتۇرۇش A = np.array([[1, 2], [3, 4]]) A_transpose = A.T print("ئەسلى ماترىتسا:") print(A) print("ئالماشتۇرۇلغان ماترىتسا:") print(A_transpose) # ماترىتسا ئىزى trace = np.trace(A) print("ماترىتسا ئىزى:", trace) # تەتۈر ماترىتسا A_inv = np.linalg.inv(A) print("تەتۈر ماترىتسا:") print(A_inv) # ماترىتسا ئانىقلىقى det = np.linalg.det(A) print("ماترىتسا ئانىقلىقى:", det)

9.3 تەڭلىمە سىستېمىسى

# تەڭلىمە سىستېمىسى ھەل قىلىش # 2x + 3y = 8 # 4x + y = 6 A = np.array([[2, 3], [4, 1]]) b = np.array([8, 6]) x = np.linalg.solve(A, b) print("تەڭلىمە سىستېمىسى ھەل قىلىش:") print("x =", x[0], ", y =", x[1])

9.4 ئىگىلىك قىممەت

# ئىگىلىك قىممەت ۋە ئىگىلىك ۋېكتور A = np.array([[4, -2], [1, 1]]) eigenvalues, eigenvectors = np.linalg.eig(A) print("ئىگىلىك قىممەتلەر:", eigenvalues) print("ئىگىلىك ۋېكتورلار:") print(eigenvectors)

14.3 مونتې كارلو ئۇسۇلى

# π نى مونتې كارلو ئۇسۇلى بىلەن ھېسابلاش n_points = 100000 x = np.random.random(n_points) y = np.random.random(n_points) inside_circle = (x**2 + y**2) <= 1 pi_estimate = 4 * np.sum(inside_circle) / n_points print("مونتې كارلو ئۇسۇلى بىلەن ھېسابلانغان π:", pi_estimate) print("ھەقىقىي π:", np.pi) print("خاتالىق:", abs(pi_estimate - np.pi))
