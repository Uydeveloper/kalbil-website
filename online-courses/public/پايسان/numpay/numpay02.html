دەرس بايانى | Introduction

بۇ بابتا نامپاى بىلەن ماتماتىكىلىق ھېسابلاش، قوشۇش، كۆپەيتىش، ترانسپوزىتسىيە، ماتماتىكىلىق فۇنكسىيەلەر ھەققىدە ئۆگىنىمىز.

In this chapter, we learn mathematical calculations with NumPy, including addition, multiplication, transpose, and mathematical functions.

قوشۇش ۋە كۆپەيتىش | Addition and Multiplication

ماترىتسىلارنى قوشۇش ۋە كۆپەيتىش:

import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# قوشۇش
print("قوشۇش:", a + b)

# كۆپەيتىش
print("كۆپەيتىش:", a * b)

Adding and multiplying arrays:

import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# Addition
print("Addition:", a + b)

# Multiplication
print("Multiplication:", a * b)

ترانسپوزىتسىيە | Transpose

ماترىتسىنى ترانسپوزىتسىيە قىلىش:

arr = np.array([[1, 2, 3], [4, 5, 6]])
print("ئەسلى شەكلى:")
print(arr)

print("ترانسپوزىتسىيە شەكلى:")
print(arr.T)

Transposing an array:

arr = np.array([[1, 2, 3], [4, 5, 6]])
print("Original:")
print(arr)

print("Transposed:")
print(arr.T)

ماتماتىكىلىق فۇنكسىيەلەر | Mathematical Functions

ماتماتىكىلىق فۇنكسىيەلەر:

arr = np.array([1, 4, 9, 16])

print("كىچىك سان:", np.sqrt(arr))
print("ئوتتۇرچە:", np.mean(arr))
print("ئەڭ چوڭ:", np.max(arr))
print("ئەڭ كىچىك:", np.min(arr))

Mathematical functions:

arr = np.array([1, 4, 9, 16])

print("Square root:", np.sqrt(arr))
print("Mean:", np.mean(arr))
print("Max:", np.max(arr))
print("Min:", np.min(arr))

چۈشەندۈرۈش | Explanation

بۇ بابتا نامپاى بىلەن ماتماتىكىلىق ھېسابلاش، ترانسپوزىتسىيە، ماتماتىكىلىق فۇنكسىيەلەرنى ئۆگىنىدۇق. بۇ نامپاى بىلەن مەلۇمات تەھلىلى ۋە ماتماتىكىلىق مودېللارنى قۇرۇشنىڭ ئەڭ مۇھىم قەدەمى.

In this chapter, we learned mathematical calculations with NumPy, transpose, and mathematical functions. This is the most important step for data analysis and building mathematical models with NumPy.
