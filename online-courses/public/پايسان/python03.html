پايسان 3-باب - if/else ۋە لوگىكىلىق ئامەللەر

دەرس بايانى

بۇ بابتا شەرتلىك بايانلار (if/else) ۋە لوگىكىلىق ئامەللەرنى ئۆگىنىمىز. شەرتلىك بايانلار ئارقىلىق پروگراممىڭىزغا قارار قىلىش ئىقتىدارى قوشالايسىز.

if/else بايانى

age = 18

if age >= 18:
    print("سىز چوڭسىز.")
else:
    print("سىز ياشسىز.")

ئەگەر age 18 دىن چوڭ ياكى تەڭ بولسا "سىز چوڭسىز" چىقىدۇ، ئەكسىچە بولسا "سىز ياشسىز" چىقىدۇ.

elif ئىشلىتىش

score = 75

if score >= 90:
    print("A دەرىجىسى")
elif score >= 75:
    print("B دەرىجىسى")
elif score >= 60:
    print("C دەرىجىسى")
else:
    print("F دەرىجىسى")

بۇنداق شەرتلىك بايانلار بىلەن كۆپ شەرتلەرنى تەكشۈرۈپ، تۈرلۈك چىقىشلارغا يېتىشىشكە بولىدۇ.

لوگىكىلىق ئامەللەر

  • and - ھەر ئىككى شەرت توغرا بولغاندا True
  • or - ئىككى شەرتتىن بىر شەرت توغرا بولغاندا True
  • not - شەرتنى ئىنكار قىلىش
x = 10
y = 5

if x > 5 and y < 10:
    print("ھەربىر شەرت توغرا")
    
if x > 5 or y > 10:
    print("ئەڭ ئاز بىر شەرت توغرا")
    
if not x < 5:
    print("x 5 دىن كىچىك ئەمەس")

مەسىل

ئىككى ساننى سېلىشتۇرۇپ، چوڭ ياكى كىچىك ساننى چىقىرىش:

a = 12
b = 20

if a > b:
    print("a چوڭ سان")
elif a < b:
    print("b چوڭ سان")
else:
    print("a ۋە b تەڭ سان")

چۈشەندۈرۈش

بۇ بابتا if/else ۋە elif ئارقىلىق شەرتلىك قارار قىلىش، ۋە لوگىكىلىق ئامەللەرنى ئىشلىتىشنى چۈشەندۇق. بۇنى ئىشلىتىپ پروگرامما ئىچىدە قارارغا يەتمەك، سانلارنى سېلىشتۇرۇش، ۋە ئەمەلىي مەسىللىكتە ئىشلىتىشكە بولىدۇ.
