پايسان 6-باب - فايل بىلەن ئىش

دەرس بايانى

بۇ بابتا Python دا فايللارنى ئېچىش، يېزىش، ئوقۇش ۋە يېپىشنى ئۆگىنىمىز.

فايل ئېچىش ۋە يېزىش

# write مودىنى ئىشلىتىپ يېڭى فايلغا يېزىش
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("Python دەرسلىكى\n")
    file.write("قاۋۇلجانغا سالام\n")

فايلنى ئوقۇش

# read مودىنى ئىشلىتىپ فايلنى ئوقۇش
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

line by line ئوقۇش

with open("example.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())  # سۈزۈش (strip) ئارقىلىق بوش بەلگە چىقىرىشنى توختىتىش

ئاۋارەتىش (append) ھالىتى

with open("example.txt", "a", encoding="utf-8") as file:
    file.write("Python دا فايل بىلەن ئىشلىتىش\n")

مەسىل

ئىشلەتكۈچىدىن ئۇچۇر ئالىپ، ئۇنى فايلغا ساقلاش ۋە ئاندىن قايتا ئوقۇش:

name = input("ئىسمىڭىزنى كىرگۈزۈڭ: ")

with open("user.txt", "w", encoding="utf-8") as file:
    file.write("ئىسم: " + name + "\n")

with open("user.txt", "r", encoding="utf-8") as file:
    print(file.read())

چۈشەندۈرۈش

بۇ بابتا Python دا فايل بىلەن ئىشلىتىشنى چۈشەندۇق. write، read ۋە append مودىنى ئىشلىتىش ئارقىلىق فايلغا يېزىش، ئوقۇش ۋە يېڭىلىق قوشۇشقا بولىدۇ. with open() ئارقىلىق فايلنى ئاپتوماتىك يېپىش ھەم قۇلايلىق.
