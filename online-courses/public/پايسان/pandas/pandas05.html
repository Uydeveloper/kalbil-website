دەرس بايانى

بۇ بابتا پەنداس بىلەن ئامالىي مەشىقلەر، ھەقىقىي مەلۇمات بىلەن ئىشلىش، نەتىجىنى CSV/Excel غا ساقلاش ھەققىدە ئۆگىنىمىز.

ھەقىقىي مەلۇمات بىلەن ئىشلىش

ھەقىقىي مەلۇمات بىلەن تەھلىل قىلىش:

import pandas as pd

# مەلۇماتنى ئوقۇش
df = pd.read_csv('sales_data.csv')

# ھەر بىر مەھسۇلات تۈرىنىڭ جەمئىي سېتىش مىقدارى
sales_by_product = df.groupby('مەھسۇلات')['مەبلەغ'].sum()
print(sales_by_product)

# ئەڭ ياخشى سېتىلغان 5 مەھسۇلات
top_5 = sales_by_product.nlargest(5)
print(top_5)

نەتىجىنى ساقلاش

تەھلىل نەتىجىسىنى CSV/Excel غا ساقلاش:

# CSV غا ساقلاش
top_5.to_csv('top_5_products.csv')

# Excel غا ساقلاش
top_5.to_excel('top_5_products.xlsx', sheet_name='Top 5')

گىرافىك تەھلىل

ماتپلۆتلىب بىلەن گىرافىك تەھلىل:

import matplotlib.pyplot as plt

# پىيى گىرافىكى
top_5.plot(kind='pie', autopct='%1.1f%%')
plt.title('ئەڭ ياخشى سېتىلغان 5 مەھسۇلات')
plt.show()
