دەرس بايانى

بۇ دەرىجىلىك دەرىستە Python نىڭ قايتىلىنىش مۇھىتى (for/while)، فۇنكسىيە قۇرۇش، مودۇللار ۋە ئۆبىيكت ئوبژېكت قۇرۇلۇشى (OOP) نى ئۆگىنىمىز.

4-باب - for/while مۇھىتى

بۇ بابتا Python دا قايتىلىنىش مۇھىتى (loops) نى ئۆگىنىمىز. for ۋە while مۇھىتى ئارقىلىق سانلىق مەلۇمات ياكى تىزىملىك ئۈستىدە قايتىلىنىپ ئامەل قىلدۇرىدۇق.

for مۇھىتى

تىزىملىك ئۈستىدە قايتىلاش:

fruits = ["alma", "banan", "portakal"]

for fruit in fruits:
    print(fruit)

ئەتىرلىكنى بىر-بىر قاراپ، ھەر بىر مىۋىنى چىقىرىدۇ.

range() بىلەن for مۇھىتى

# 0 دىن 4 گىچە سانلار
for i in range(5):
    print("سان:", i)

while مۇھىتى

count = 0

while count < 5:
    print("count =", count)
    count += 1 # count نى 1 قوشۇش

break ۋە continue

for i in range(10):
    if i == 5:
        break # 5 غىچە توختاش
    print(i)

for i in range(5):
    if i == 2:
        continue # 2 نى ئۆتكۈزۈش
    print(i)

مەسىل

ئىككى ساننىڭ جەمئىيىنى ھېسابلاش ئۈچۈن for مۇھىتى ئىشلىتىش:

numbers = [2, 5, 7, 10]
total = 0

for num in numbers:
    total += num

print("سانلار جەمئىيى:", total)

5-باب - فۇنكسىيە ۋە مودۇل

بۇ بابتا Python دا فۇنكسىيە قۇرۇش، ئۇنى چاقىرىش ۋە مودۇللارنى ئىشلىتىشنى ئۆگىنىمىز. فۇنكسىيە پروگراممىڭىزنى قۇراللار بىلەن بۆلۈش، قايتىدىن ئىشلىتىشكە قولايلىق بولىدۇ.

فۇنكسىيە قۇرۇش

# فۇنكسىيە ئېلان قىلىش
def greet(name):
    print("ياخشىمۇسىز, " + name + "!")

# فۇنكسىيەنى چاقىرىش
greet("قاۋۇلجان")

قايتۇرۇش قىممىتى

def add(a, b):
    return a + b

sum = add(5, 7)
print("جەمئىي:", sum)

مودۇل ئىشلىتىش

Python نىڭ بىرىنچى قوشۇمچە قۇراللىرىنى ئىشلىتىپ، مودۇلدىن پايدىلىنىش:

# math مودۇلنى چاقىرىش
import math

print("π قىممىتى:", math.pi)
print("كىچىك سان:", math.sqrt(16))

from ... import ...

# پەقەت sqrt فۇنكسىيەنى import قىلىش
from math import sqrt

print("كىچىك سان:", sqrt(25))

مەسىل

ئىككى ساننى قوشۇش ۋە ھەرىكىتىنى باشقۇرۇش فۇنكسىيەسى:

def compare_numbers(a, b):
    if a > b:
        return "a چوڭ"
    elif a < b:
        return "b چوڭ"
    else:
        return "a ۋە b تەڭ"

result = compare_numbers(12, 15)
print(result)

7-باب - ئۆبىيكت ئوبژېكت قۇرۇلۇشى (OOP)

بۇ بابتا Python دا ئۆبىيكت ئوبژېكت قۇرۇلۇشى (OOP) نى ئۆگىنىمىز. OOP ئارقىلىق كودلارنى تېخىمۇ تۈزۈملۈك ۋە قايتىدىن ئىشلىتىشكە بولىدۇ.

كلاس ۋە ئۆبىيكت

# كلاس قۇرۇش
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year

    def info(self):
        return f"{self.year} {self.brand} {self.model}"

# ئۆبىيكت قۇرۇش
my_car = Car("Toyota", "Corolla", 2020)
print(my_car.info())

Attributes (ئۆزگەرگۈچلەر)

print("Brand:", my_car.brand)
print("Model:", my_car.model)
print("Year:", my_car.year)

Methods (فۇنكسىيە)

# كلاس ئىچىدە info() ناملىق فۇنكسىيەنى ئالدىن بەرگەن
print(my_car.info())

Inheritance (ۋارىسىلىق)

# Car كلاسنىڭ يىڭى كلاسقا ۋارىس قىلىش
class ElectricCar(Car):
    def __init__(self, brand, model, year, battery_size):
        super().__init__(brand, model, year)
        self.battery_size = battery_size

    def battery_info(self):
        return f"Battery size: {self.battery_size} kWh"

my_electric_car = ElectricCar("Tesla", "Model 3", 2021, 75)
print(my_electric_car.info())
print(my_electric_car.battery_info())

مەسىل

ئىككى كىلاس قۇرۇپ، ئادەم ۋە ئوقۇغۇچى ئارقىلىق مەلۇماتنى ساقلاش:

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"ياخشىمۇسىز, {self.name}!")

class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)
        self.student_id = student_id

    def info(self):
        print(f"Student: {self.name}, Age: {self.age}, ID: {self.student_id}")

s = Student("قاۋۇلجان", 25, "S123")
s.greet()
s.info()

چۈشەندۈرۈش

بۇ دەرىجىلىك دەرىستە Python نىڭ قايتىلىنىش مۇھىتى (for/while)، فۇنكسىيە قۇرۇش، مودۇللار ۋە ئۆبىيكت ئوبژېكت قۇرۇلۇشى (OOP) نى ئۆگىنىدۇق. بۇ ئۇسۇل سانلىق مەلۇمات تەھلىلى، پروگرامما ئىچىدە مەسىل ھەل قىلىش، كودنى بۆلەك بۆلەك قىلىپ ئىشلىتىش، قايتىدىن ئىشلىتىش ۋە چوڭ دەرىجىلىك كودلارنى باشقۇرۇشقا قولايلىق.
