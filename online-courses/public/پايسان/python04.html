پايسان 4-باب - for/while مۇھىتى

دەرس بايانى

بۇ بابتا Python دا قايتىلىنىش مۇھىتى (loops) نى ئۆگىنىمىز. for ۋە while مۇھىتى ئارقىلىق سانلىق مەلۇمات ياكى تىزىملىك ئۈستىدە قايتىلىنىپ ئامەل قىلدۇرىدۇق.

for مۇھىتى

# تىزىملىك ئۈستىدە قايتىلاش
fruits = ["alma", "banan", "portakal"]

for fruit in fruits:
    print(fruit)

ئەتىرلىكنى بىر-بىر قاراپ، ھەر بىر مىۋىنى چىقىرىدۇ.

range() بىلەن for مۇھىتى

# 0 دىن 4 گىچە سانلار
for i in range(5):
    print("سان:", i)

while مۇھىتى

count = 0

while count < 5:
    print("count =", count)
    count += 1  # count نى 1 قوشۇش

break ۋە continue

for i in range(10):
    if i == 5:
        break   # 5 غىچە توختاش
    print(i)

for i in range(5):
    if i == 2:
        continue  # 2 نى ئۆتكۈزۈش
    print(i)

مەسىل

ئىككى ساننىڭ جەمئىيىنى ھېسابلاش ئۈچۈن for مۇھىتى ئىشلىتىش:

numbers = [2, 5, 7, 10]
total = 0

for num in numbers:
    total += num

print("سانلار جەمئىيى:", total)

چۈشەندۈرۈش

بۇ بابتا Python دا for ۋە while مۇھىتى ئارقىلىق قايتىلىنىشنى چۈشەندۇق. break ۋە continue ئارقىلىق قايتىلىنىشقا يېڭىلىق كىرگۈزۈشنى ئۆگىنىدۇق. بۇ ئۇسۇل سانلىق مەلۇمات تەھلىلى ۋە پروگرامما ئىچىدە مەسىل ھەل قىلىشتا مۇھىم.
