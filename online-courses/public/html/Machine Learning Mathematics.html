四則演算 — چوڭقۇرلىقنىڭ ئاساسى
Arithmetic Operations — Foundation of Depth

AI·ماشىنا ئوقۇشنىڭ ماتېماتىكىسىنىڭ ئەڭ ئاساسىي ئۇچۇرى — قوشۇش، ئالىش، كۆپەيتىش، بۆلۈش. بارلىق ئىشلەش ئۇسۇلى — تېخى كۆپ ئىشلەش ئۇسۇلى بولۇپمۇ، ئاخىرىدا بۇ 4 تەرەپنى ئىشلىتىدۇ.
The most fundamental concept in AI/machine learning mathematics is addition, subtraction, multiplication, and division. No matter how complex the algorithm, it ultimately relies on these four operations.

تۈشەندۈرۈش: دېرېۋاتىۋە، ئىنتېگرال، ئىتىراپ — بارلىقى بۇ 4 ئىشلەش ئۇسۇلىنىڭ تىزىقلىقى بىلەن ئىشلىتىلىدۇ.
Explanation: Derivatives, integrals, and iterations—all are ultimately built from these four basic operations.

مەسىلەن، f(x) = x² + 3x - 5 دېگەن تېڭلىكنى دېرېۋاتىۋە قىلىشنىڭ ئۇچۇرى — 2x + 3 دېگەن نەتىجىنى چىقىرىش ئۈچۈن، كۆپەيتىش ۋە قوشۇشنى ئىشلىتىش.
For example, differentiating f(x) = x² + 3x - 5 yields 2x + 3 using multiplication and addition.

文字式と添字 — ھەرپ ۋە كۆرستكۈچ
Algebraic Expressions & Subscripts

ھەرپلەر (x, y, w) — ماتېماتىكىلىق ئۇچۇرلىرىنىڭ ئومۇمىي كۆرۈنۈشى. كۆرستكۈچ (x₁, x₂, ..., xₙ) — بىر نەچچە قىممەتنى بىرلىكتە ئىشلەش ئۈچۈن.
Letters (x, y, w) represent general mathematical quantities. Subscripts (x₁, x₂, ..., xₙ) allow us to handle multiple values collectively.

مەسىلەن، Σᵢ₌₁ⁿ xᵢ دېگەن ئىشلەش — بارلىق xᵢ قىممەتلىرىنى قوشۇش دېگەن مەنىنى بىلدۈرىدۇ.
For example, Σᵢ₌₁ⁿ xᵢ means summing all xᵢ values.

総和（Σ）— بارلىقىنى قوشۇش
Summation (Σ) — Adding Everything

Σ (سىگما) — "بارلىقىنى قوش" دېگەن مەنىنى بىلدۈرىدۇ. بۇ ماتېماتىكىلىق ئۇچۇر مۇھىم، چۈنكى مەسىلەن، كۆپلىگەن داتىلارنىڭ يېڭىلىشىنى ياكى خاتالىقىنى قوشۇش ئۈچۈن قوللىنىلىدۇ.
Σ (sigma) means "add everything." This is crucial—for example, summing errors or updates across many data points.

مەسىلە: Σᵢ₌₁⁵ (xᵢ - μ)² — بارلىق داتىلارنىڭ ئورتاچىسىدىن بولغان خاتالىقىنىڭ كۋادراتىنى قوشۇش.
Example: Σᵢ₌₁⁵ (xᵢ - μ)² sums the squared deviations from the mean.

بۇ ئىشلەش مەخسۇس دېرېۋاتىۋە ئۈچۈن مۇھىم، چۈنكى بۇ ئىشلەشنىڭ مىنىمۇم قىلىشى — ئورتاچى قىممەتنى تاپىشنىڭ ئۇسۇلى.
This is essential for optimization—minimizing this sum gives the mean value.

距離の計算 — پىتاغورىسنىڭ تېئورېمى
Distance Calculation — Pythagorean Theorem

2 نۇقتا ئارىسىدىكى مەسافىنى تاپىش ئۈچۈن:
d = √[(x₂ - x₁)² + (y₂ - y₁)²]
To find the distance between two points:
d = √[(x₂ - x₁)² + (y₂ - y₁)²]

بۇ ئىشلەش k-means كۈچۈلۈش ئۇسۇلىدا ئىشلىتىلىدۇ — بىر نۇقتا بىلەن بارلىق مەركەزلەرنىڭ مەسافىنى تاپىپ، يېقىن بولغان مەركەزگە ئەۋەتىش.
This is used in k-means clustering—assigning a point to the nearest centroid by distance.

微分 — ئەڭ كىچىك قىلىش
Differentiation — Minimization

微分 — بىر قىممەتنىڭ ئىشلەش ئۇسۇلىنىڭ ئەڭ كىچىك ياكى ئەڭ ئېگىز قىلىشىنى تاپىش ئۈچۈن.
Differentiation finds where a function reaches its minimum or maximum.

مەسىلە: f(x) = x² دېگەن تېڭلىكنىڭ ئەڭ كىچىك قىممىتى؟
دېرېۋاتىۋە: f’(x) = 2x → 2x = 0 → x = 0 ← ئەڭ كىچىك نۇقتا!
Example: Minimum of f(x) = x²?
Derivative: f’(x) = 2x → 2x = 0 → x = 0 ← minimum point!

بۇ ئىشلەش مۇئەييەنلىك ئۇسۇلى (gradient descent) ئۈچۈن مۇھىم — بۇ ئۇسۇل مەشىن ئوقۇشنىڭ ئىچىدىكى "ئىشلەش" ئۇسۇلى.
This is key for gradient descent—the core "learning" algorithm in machine learning.

💡 تەپسىلىي: دېرېۋاتىۋە — "ئۇچۇرنىڭ قانچە تېز ئۆزگەرىدىغانلىقى".
💡 Detail: Derivative = "how fast the value changes."

偏微分 — كۆپ ئۇچۇرلىق ئىشلەش
Partial Differentiation — Multi-variable Processing

بىر قىممەت بىر قانچە ئۇچۇرغا ئېگە بولسا، بىر ئۇچۇرغا ئېتىبار قىلىپ، باشقا ئۇچۇرلارنى "تۇرۇش" قىلىپ ئىشلىتىش — بۇ 偏微分.
When a function has multiple variables, partial differentiation focuses on one variable while treating others as constants.

مەسىلە: L(w₁, w₂) = (y - w₁x₁ - w₂x₂)²
∂L/∂w₁ — w₁ بىلەن بولغان خاتالىقنىڭ ئۆزگەرىشى.
Example: L(w₁, w₂) = (y - w₁x₁ - w₂x₂)²
∂L/∂w₁ = how error changes with w₁.

بۇ ئىشلەش نيورال نېتۋېكنىڭ "ئىشلەش" ئۇسۇلىنىڭ ئىچىدىكى بەكىتىش (backpropagation) ئۈچۈن مۇھىم.
This is essential for backpropagation in neural networks.

ベクトル — چوڭقۇرلىقنى بىرلىكتە ئىشلەش
Vectors — Unified Depth Processing

بىر نەچچە قىممەتنى بىرلىكتە بىر ھەرپ بىلەن كۆرسىتىش — بۇ ベクトر.
A vector represents multiple values as a single entity.

ئىچىدە: قوشۇش، سانغا كۆپەيتىش، ئىچكى كۆپەيتىش (dot product).
a · b = a₁b₁ + a₂b₂ + ... — بۇ ئوخشاشلىق (cosine similarity) تاپىش ئۈچۈن قوللىنىلىدۇ.
Includes: addition, scalar multiplication, dot product.
a · b = a₁b₁ + a₂b₂ + ... — used for similarity (cosine similarity).

行列 — چوڭقۇرلىقنى جەدۋەلگە ئېلىپ كىرگۈزۈش
Matrices — Tabular Representation of Depth

بىر نەچچە بېكتورنى بىرلىكتە جەدۋەلگە سىزىش — بۇ مەترىس.
A matrix is a table of numbers—essentially multiple vectors arranged together.

مەترىسنىڭ ئىشلىتىلىشى: نيورال نېتۋېكنىڭ تەسىرى، ئىشلەش، قايتا تەسىرلىتىشنى بىر سىزىق بىلەن ئىشلىتىش.
Matrices enable compact representation of neural network weights, transformations, and backpropagation.

確率と統計 — بەلگىسىزلىقنى باشقۇرۇش
Probability & Statistics — Managing Uncertainty

ماشىنا ئوقۇشنىڭ 90%ى — بەلگىسىزلىك بىلەن ئىشلەيدۇ.
90% of machine learning deals with uncertainty.

ئاساسىي تۈرلىرى:
• شەرتلىك ئېھتىماللىق (Conditional Probability)
• بېيېز تېئورېمى (Bayes' Theorem): P(A|B) = P(B|A)·P(A)/P(B)
• نورمال تارقىلىش (Gaussian Distribution)
Key Concepts:
• Conditional Probability
• Bayes' Theorem: P(A|B) = P(B|A)·P(A)/P(B)
• Gaussian Distribution

بېيېز تېئورېمى — ئىشلەش ئۇسۇلىنىڭ ئىچىدىكى ئېھتىماللىقنى ئىشلەش ئۈچۈن مۇھىم — مەسىلەن، ئېمەيلنى "سۈپەتلىك" ياكى "سۈپەتسىز" دېگەنلىكىنى ئىشلەش.
Bayes' Theorem is vital for probabilistic reasoning—e.g., classifying emails as "spam" or "not spam."

💡 تەپسىلىي: "بىر نەرسەنىڭ بولۇشىنى بىلگەندە، باشقا بىر نەرسەنىڭ بولۇشىنى قانچە ئېھتىمال بولۇشىنى بىلىش" — بۇ بېيېزنىڭ سىرى.
💡 Detail: "Given that A happened, how likely is B?" — that’s Bayes.

指数と対数 — ئەسلىي ھەرەكەت
Exponents & Logarithms — Fundamental Behavior

ئىندېكس — بىر خىل ساننى بىر قانچە قېتىم كۆپەيتىش.
لوغاريتم — بىر ساننىڭ قانچە قېتىم كۆپەيتىلىشىنى تاپىش.
Exponentiation = multiplying a number by itself multiple times.
Logarithm = finding how many times you multiplied.

مەسىلە: e ≈ 2.718 — تەبىئىي لوغاريتمنىڭ ئاساسى.
σ(x) = 1 / (1 + e⁻ˣ) — sigmoid ئاكتىۋاتسىيە فۇنksiya — نېورال نېتۋېكلەردە ئىشلىتىلىدۇ.
Example: e ≈ 2.718 — base of natural logarithm.
σ(x) = 1 / (1 + e⁻ˣ) — sigmoid activation in neural networks.

بۇ ئىشلەش — نورمال تارقىلىشنىڭ ھەرەكىتىنى ئىپادىلەش ئۈچۈن مۇھىم.
This is key for modeling normal distributions and activation functions.

0の取り扱い — 0نىڭ سىرلىرى
Handling Zero — Secrets of Zero

ئەمەس، 0 — بىر سان ئەمەس، بۇ سېزىمسىزلىقنىڭ ئىشلىتىلىشى.
Zero isn’t just a number—it’s a special case in computation.

  • ✅ 0⁰ = 1 (مەشىن ئوقۇشتا قۇرۇلۇشنى ئىشلىتىش ئۈچۈن)
    ✅ 0⁰ = 1 (for consistency in formulas)
  • ❌ x/0 = تەئىينلىنىمىدۇ (بۇ سىزنىڭ دەرىسىڭىزنىڭ ئىشلىتىلىشىنى توختىتىدۇ!)
    ❌ x/0 = undefined (crashes your code!)
  • ✅ 0! = 1 (فاكتورىال — ماتېماتىكىلىق ئىشلەشنىڭ ئاساسى)
    ✅ 0! = 1 (by definition in combinatorics)
⚠️ ئېسكەرتىش: مەشىن ئوقۇشتا 0-گە بۆلۈش — بارلىق كودنى چەكىپ قالىدۇ. بۇنىڭ ئۈچۈن epsilon = 1e-8 قوشۇلىدۇ.
⚠️ Warning: Division by zero crashes programs. Use epsilon = 1e-8 to avoid it.

行列式 — ھەجىم ۋە يۈز
Determinants — Volume & Area

مەترىسنىڭ ئىچىدىكى "ھەجىم" ياكى "يۈز"نى تاپىش — بۇ 行列式 (Determinant).
The determinant measures the "signed volume" or "area" scaled by a matrix.

بۇ ئىشلەش — مەترىسنىڭ ئىشلىتىلىشىنى ياكى تەرەپلىكنى تاپىش ئۈچۈن قوللىنىلىدۇ.
Used to check if a matrix is invertible or to compute geometric scaling.

固有値・固有ベクトル — ماترىسنىڭ ئىچىدىكى سىر
Eigenvalues & Eigenvectors — Secrets Inside Matrices

مەترىسنىڭ بىر نۇقتىسىنى ئىشلىتىش — بۇ ئۇچۇرنىڭ ئىشلىتىلىشىنى ئۆزگەرتمەيدۇ!
An eigenvector’s direction doesn’t change under a linear transformation!

بۇ ئىشلەش — PCA (ئىشلەشنىڭ ئىشلىتىلىشىنى ئىشلىتىش) ئۈچۈن مۇھىم — ئۇچۇرنىڭ ئەڭ ئىشلىتىلىشىنى تاپىش.
Crucial for PCA (Principal Component Analysis)—finding directions of maximum variance.

Summary — The Essence of This Course

Σ, ∂, W, X, e — these are tools of your trade; understand their purpose.
