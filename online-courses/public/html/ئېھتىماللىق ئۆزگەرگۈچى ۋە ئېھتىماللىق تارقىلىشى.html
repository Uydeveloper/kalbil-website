ئېھتىماللىق ئۆزگەرگۈچى ۋە ئېھتىماللىق تارقىلىشى

Probability Variable and Probability Distribution

كىرىش

ئېھتىماللىق ئۆزگەرگۈچى: بىر ئۆزگەرگۈچىنىڭ قىممىتىنىڭ ئېلىنىش ئېھتىماللىقى بار بولغان ئۆزگەرگۈچى. مەسىلەن، زار ئاتقاندا چىققان نۇمۇر {1, 2, 3, 4, 5, 6} نىڭ ھەر قايسىسى بولۇپ، ھەر بىر نۇمۇرنىڭ چىقىش ئېھتىماللىقى بولغاچقا، زار ئاتقاندا چىققان نۇمۇر ئېھتىماللىق ئۆزگەرگۈچى دەپ ئېيتىلىدۇ.

ئېھتىماللىق تارقىلىشى: ئېھتىماللىق ئۆزگەرگۈچىنىڭ ئېلىدىغان قىممىتى ۋە بۇ قىممەتنىڭ ئېلىنىش ئېھتىماللىقىنىڭ مۇناسىۋىتى. مەسىلەن، زار ئاتقاندا، 1 دىن 6 غىچە بولغان ئېھتىماللىق ئۆزگەرگۈچى قىممىتىگە ھەر قايسىسى ئېھتىماللىقى مۇناسىۋەتلىك بولغانلىقى ئۈچۈن، بۇ ئېھتىماللىق تارقىلىشى دەپ ئېيتىلىدۇ.

Random variable: A variable whose value has a probability of occurrence. For example, when rolling a die, the outcome is one of {1, 2, 3, 4, 5, 6}, and since each number has a probability of occurring, the outcome of rolling a die is called a random variable.

Probability distribution: The relationship between the values a random variable can take and the probability of taking those values. For example, when rolling a die, since each value from 1 to 6 is associated with a probability of , this is called a probability distribution.

مىسال 1: زار ئاتقان

زار ئاتقاندا چىققان نۇمۇر ئېھتىماللىق ئۆزگەرگۈچى. ھەر بىر نۇمۇرنىڭ چىقىش ئېھتىماللىقى بولىدۇ.

مىسال 2: تەڭگە ئاتقان

تەڭگە ئاتقاندا، قارا يۈزگە «1»، ئارقى يۈزگە «0» دەپ قارايسۇن. قارا يۈز ۋە ئارقى يۈزنىڭ چىقىش ئېھتىماللىقى بولغاچقا، بۇمۇ ئېھتىماللىق ئۆزگەرگۈچى.

مىسال 3: ئوقۇغۇچىلارنىڭ ئىمتىھان نەتىجىسى

بىر سىنىپتىكى ئوقۇغۇچىلارنىڭ ئىمتىھان نەتىجىسى ئېھتىماللىق ئۆزگەرگۈچى بولۇپ، ھەر بىر نەتىجىنىڭ ئېلىنىش ئېھتىماللىقى بار.

ئېھتىماللىق ئۆزگەرگۈچى (Random Variable)

ئېھتىماللىق ئۆزگەرگۈچى نېمە؟

ئېھتىماللىق ئۆزگەرگۈچى دېگەندە، بىر ئۆزگەرگۈچىنىڭ قىممىتىنىڭ ئېلىنىش ئېھتىماللىقى بار بولغان ئۆزگەرگۈچى. مەسىلەن، زار ئاتقاندا چىققان نۇمۇر {1, 2, 3, 4, 5, 6} نىڭ ھەر قايسىسى بولۇپ، ھەر بىر نۇمۇرنىڭ چىقىش ئېھتىماللىقى بولغاچقا، زار ئاتقاندا چىققان نۇمۇر ئېھتىماللىق ئۆزگەرگۈچى دەپ ئېيتىلىدۇ.

بۇ ھالەتتە، ئېھتىماللىق ئۆزگەرگۈچىنىڭ قىممىتى (يەنى زارنىڭ چىققان نۇمۇرى) X دەپ بەلگىلەنسە، تۆۋەندىكىدەك كۆرسىتىشكە بولىدۇ. ئوڭ تەرەپتىكى قاۋۇش ئىچىدىكى X نىڭ ئېلىدىغان قىممەت چېگرىسى بولۇپ، بۇ مىسالدا «ئېھتىماللىق ئۆزگەرگۈچى 1 دىن 6 غىچە بولغان تام سان قىممىتىنى ئېلىدۇ» دېگەن مەنىنى بىلدۈرىدۇ.

X \in \{1, 2, 3, 4, 5, 6\}

مەسىلەن «زار ئاتقاندا 3 نۇمۇر چىقىش پەزىلەتىنىڭ ئېھتىماللىقى » دېگەندە، تۆۋەندىكى ئىككى خىل ئۇسۇلنىڭ ھەر قايسىسى بىلەن يېزىشكە بولىدۇ:

P(X=3) = \frac{1}{6} \quad \text{or} \quad P(3) = \frac{1}{6}

A random variable is a variable whose value has a probability of occurrence. For example, when rolling a die, the outcome is one of {1, 2, 3, 4, 5, 6}, and since each number has a probability of occurring, the outcome of rolling a die is called a random variable.

In this case, if we denote the value of the random variable (i.e., the outcome of the die roll) as X, it can be expressed as follows. The set in the parentheses on the right represents the range of values X can take, meaning in this example that "the random variable takes integer values from 1 to 6."

X \in \{1, 2, 3, 4, 5, 6\}

For example, "the probability of the event that a 3 appears when rolling a die is " can be written in either of the following two ways:

P(X=3) = \frac{1}{6} \quad \text{or} \quad P(3) = \frac{1}{6}

سانسىز پەزىلەتلەرنىڭ ئېھتىماللىق ئۆزگەرگۈچىسى

زار ئاتقاندا، چىققان نۇمۇرنىڭ قىممىتىنى ئېھتىماللىق ئۆزگەرگۈچىنىڭ قىممىتى قىلىشقا بولىدۇ. لېكىن، پەزىلەتنىڭ رەقەملىرى بولمىغان ھالەتتىمۇ، ھەر بىر پەزىلەتكە سان قىممىتى بەلگىلەش ئارقىلىق ئېھتىماللىق ئۆزگەرگۈچىنىڭ قىممىتى قىلىشقا بولىدۇ. مەسىلەن، بىر خىل تەڭگە ئاتقاندا، قارا يۈز چىققان پەزىلەتكە «1»، ئارقى يۈز چىققان پەزىلەتكە «0» دەپ مۇناسىۋەت بەلگىلەنسە، X ئېھتىماللىق ئۆزگەرگۈچى بولىدۇ.

قارا يۈز چىققان پەزىلەت ۋە ئارقى يۈز چىققان پەزىلەتنىڭ ھەر قايسىسىنىڭ ئېھتىماللىقى بولغاچقا، ئېھتىماللىق ئۆزگەرگۈچىنى ئىشلىتىپ تۆۋەندىكىدەك يېزىشكە بولىدۇ:

P(X=1) = \frac{1}{2}, \quad P(X=0) = \frac{1}{2}

In the case of rolling a die, the outcome's value can be used as the value of the random variable. However, even when events do not have numerical values, assigning numerical values to each event can make them values of a random variable. For example, when tossing a coin, if we assign "1" to the event of heads and "0" to the event of tails, X becomes a random variable.

Since both the event of heads and the event of tails have a probability of , we can write using the random variable as follows:

P(X=1) = \frac{1}{2}, \quad P(X=0) = \frac{1}{2}

ئېھتىماللىق تارقىلىشى

ئېھتىماللىق ئۆزگەرگۈچىنىڭ ئېلىدىغان قىممىتى ۋە بۇ قىممەتنىڭ ئېلىنىش ئېھتىماللىقىنىڭ مۇناسىۋىتى «ئېھتىماللىق تارقىلىشى» دەپ ئاتىلىدۇ. مەسىلەن، زار ئاتقان مىسالىدا، 1 دىن 6 غىچە بولغان ئېھتىماللىق ئۆزگەرگۈچى قىممىتىگە ھەر قايسىسى ئېھتىماللىقى مۇناسىۋەتلىك بولغانلىقى ئۈچۈن، ئېھتىماللىق تارقىلىشى دەپ ئېيتىلىدۇ.

ئېھتىماللىق \(\frac{1}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\)

تەڭگەنىڭ ئارقى-قارا يۈزى قارا (=1) ئارقى (=0)
ئېھتىماللىق \(\frac{1}{2}\) \(\frac{1}{2}\)

دائىملىق ئېھتىماللىق تارقىلىشى (Discrete Probability Distribution)

دائىملىق ئېھتىماللىق ئۆزگەرگۈچىسى

دائىملىق ئۆزگەرگۈچى بولسا، ئۈزۈلۈشلۈك قىممەتلەرنى ئېلىدىغان ئۆزگەرگۈچى بولۇپ، قوشنى سانلار ئارىسىدا قىممەت يوق. دائىملىق ئۆزگەرگۈچىگە، زارنىڭ چىققان نۇمۇرى، ئادەم سانى قاتارلىقلار كىرىدۇ. مەسىلەن، زارنىڭ 3 نۇمۇرىدىن كېيىنكىسى 4 بولۇپ، ئۇنىڭ ئارىسىدا 3.2 ياكى 3.5 قاتارلىق سانلار يوق.

تۆۋەندىكى جەدۋەلدىكىدەك، دائىملىق ئۆزگەرگۈچىنىڭ ئېلىدىغان قىممىتى (\(x_i\)) ھەر قايسىسىغا مۇناسىۋەتلىك ئېھتىماللىق بار بولسا، بۇ ئۆزگەرگۈچى «دائىملىق ئېھتىماللىق ئۆزگەرگۈچىسى» دەپ ئاتىلىدۇ.

X \(x_1\) \(x_2\) ... \(x_n\)
P(X) \(p_1\) \(p_2\) ... \(p_n\)

A discrete variable is a variable that takes discrete values, with no values existing between adjacent numbers. Discrete variables include die outcomes, number of people, etc. For example, after 3 on a die comes 4, with no values like 3.2 or 3.5 in between.

If, as shown in the table below, each value (\(x_i\)) that a discrete variable can take has a corresponding probability, this variable is called a "discrete random variable".

X \(x_1\) \(x_2\) ... \(x_n\)
P(X) \(p_1\) \(p_2\) ... \(p_n\)

دائىملىق ئېھتىماللىق تارقىلىشى

ئېھتىماللىق ئۆزگەرگۈچىسى دائىملىق بولغان ھالەتتىكى ئېھتىماللىق تارقىلىشى «دائىملىق ئېھتىماللىق تارقىلىشى» ياكى «دائىملىق تارقىلىش» دەپ ئاتىلىدۇ. تۆۋەندىكى رەسىم دائىملىق ئېھتىماللىق تارقىلىشىنىڭ كۆرۈنۈشىنى كۆرسىتىدۇ. گورىزونتال ئوق ئېھتىماللىق ئۆزگەرگۈچىنى، ۋېرتىكال ئوق X نىڭ ئېھتىماللىقى \(P(X)\) نى كۆرسىتىدۇ.

When a random variable is discrete, the probability distribution is called a "discrete probability distribution" or "discrete distribution". دائىملىق ئېھتىماللىق ئۆزگەرگۈچىسى بىر قىممەتنى ئېلىش ئېھتىماللىقىنى فۇنكسىيە قىلغاندا، بۇ «ئېھتىماللىق مەسىلىسى فۇنكسىيىسى» دەپ ئاتىلىدۇ. \(f(x)\) نى ئىشلىتىپ، \(X=x\) (بىر قىممەت) بولۇش ئېھتىماللىقى تۆۋەندىكىدەك كۆرسىتىشكە بولىدۇ:

P(X=x) = f(x)

ئېھتىماللىقنىڭ بىر كېلىشىمى بولۇپ، «بارلىق پەزىلەتلەرنىڭ كۆرۈلۈش ئېھتىماللىقى 1 بولىدۇ» دېگەنلىك 9-1-بەتتە ئۆگىنىلگەن. بۇ دېگەندە، دائىملىق ئېھتىماللىق تارقىلىشىدا تۆۋەندىكىدەك كۆرسىتىشكە بولىدۇ:

\sum_{i=1}^{n} P(X=x_i) = \sum_{i=1}^{n} f(x_i) = 1

زارنى بىر قېتىم ئاتقان ھالەتنى مىسال قىلىپ ئېلىپ باقايلى. ئېھتىماللىق ئۆزگەرگۈچىسى X نى زارنىڭ چىققان نۇمۇرى دەپ قارايمىز، ھەر بىر \(x_i\) ئۈچۈن \(P(X=x_i)=\frac{1}{6}\) بولغاچقا، بۇ ئېھتىماللىقلارنىڭ جەمئىيىتى تۆۋەندىكىدەك «1» بولۇپ ھېسابلىنىدۇ:

\sum_{i=1}^{6} P(X=x_i) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = 1

When the probability that a discrete random variable takes a certain value is expressed as a function, it is called a "probability mass function". Using \(f(x)\), the probability that \(X=x\) (a certain value) can be expressed as follows:

P(X=x) = f(x)

One of the agreements of probability is that "the probability of all events occurring is 1," as learned in Chapter 9-1. This means that in a discrete probability distribution, it can be expressed as follows:

\sum_{i=1}^{n} P(X=x_i) = \sum_{i=1}^{n} f(x_i) = 1

Taking the example of rolling a die once. Let the random variable X be the outcome of the die roll, since for each \(x_i\), \(P(X=x_i)=\frac{1}{6}\), the sum of these probabilities is calculated as "1" as follows:

\sum_{i=1}^{6} P(X=x_i) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = 1

ئۈزلۈكسىز ئېھتىماللىق تارقىلىشى (Continuous Probability Distribution)

ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى

ئۈزلۈكسىز ئۆزگەرگۈچى بولسا، سالماق، تېمپېراتۇرا قاتارلىقلارغا ئوخشاش، ئۈزلۈكسىز قىممەتلەرنى ئېلىدىغان ئۆزگەرگۈچى. مەسىلەن، سالماقنىڭ 50kg بىلەن 51kg ئارىسىدا 50.5kg، 50.1kg، 50.000001kg قاتارلىق چەكسىز كۆپ قىممەت بار.

ئۈزلۈكسىز ئۆزگەرگۈچىنىڭ ئېلىدىغان قىممىتىگە مۇناسىۋەتلىك ئېھتىماللىق بار بولسا، بۇ ئۆزگەرگۈچى «ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى» دەپ ئاتىلىدۇ. ئېھتىماللىق ئۆزگەرگۈچىسى ئۈزلۈكسىز بولغان ھالەتتىكى ئېھتىماللىق تارقىلىشى «ئۈزلۈكسىز ئېھتىماللىق تارقىلىشى» ياكى «ئۈزلۈكسىز تارقىلىش» دەپ ئاتىلىدۇ.

A continuous variable is a variable that takes continuous values, such as weight or temperature. For example, between 50kg and 51kg of weight, there are infinitely many values such as 50.5kg, 50.1kg, 50.000001kg, etc.

If a continuous variable has a probability corresponding to the values it can take, this variable is called a "continuous random variable". When a random variable is continuous, the probability distribution is called a "continuous probability distribution" or "continuous distribution".

مىسال: ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى

ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى X نىڭ ئېلىدىغان قىممىتى 1 دىن 6 غىچە بولغان ھەقىقىي سان بولسۇن. X نىڭ ھەر قايسى ساننى ئېلىش ئېھتىماللىقى باراۋەر بولسا، \(P(X=3)\) نىڭ ئېھتىماللىقى قانچە؟

11-2-بەتتىكى دائىملىق ئېھتىماللىق ئۆزگەرگۈچىسى بىلەن ئوخشىمۇق ئويلاپ، \(P(X=3)=\frac{1}{6}\) دەپ قاراش خاتا. ئۈزلۈكسىز تارقىلىشتا، ئېھتىماللىق ئۆزگەرگۈچىسىنىڭ بىر نۇقتىدىكى قىممىتىنى بەلگىلەشكە ئېھتىماللىقى «0» بولىدۇ، بۇ توغرا جاۋاب.

ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى ھالىتىدە، 1 دىن 6 غىچە X نىڭ ئېلىدىغان قىممىتى چەكسىز. مەسىلەن، 1 بىلەن 1.1 ئارىسىدا 1.01، 1.00001 قاتارلىق قىممەتلەر چەكسىز بار. X نىڭ ھەر قايسى قىممىتىنى ئېلىش ئېھتىماللىقى باراۋەر بولسا، بۇ ئېھتىماللىقلارنىڭ جەمئىيىتى 1 بولۇپ، ياكى چەكسىز بار بولغان قىممەتلەرنىڭ ئىچىدىكى بىر نۇقتا بولغانلىقى ئۈچۈن، \(P(X=3)\) تۆۋەندىكىدەك «0» بولىدۇ:

P(X=3) = 0

Let the continuous random variable X take real values from 1 to 6. If the probability of X taking any numerical value is equal, what is the probability of \(P(X=3)\)?

It is incorrect to think similarly to the discrete random variable in Chapter 11-2 and consider \(P(X=3)=\frac{1}{6}\). In a continuous distribution, when the value of the random variable is fixed at a certain point, the probability of taking that value is "0", which is the correct answer.

In the case of a continuous random variable, there are infinitely many values that X can take between 1 and 6. For example, between 1 and 1.1, there are infinitely many values such as 1.01, 1.00001, etc. If the probability of X taking each value is equal, the sum of these probabilities is 1, or since it is one point among infinitely many values, \(P(X=3)\) is "0" as follows:

P(X=3) = 0

ئېھتىماللىق زىچلىقى

تۆۋەندىكى رەسىم ئۈزلۈكسىز ئېھتىماللىق تارقىلىشىنىڭ كۆرۈنۈشىنى كۆرسىتىدۇ. گورىزونتال ئوق ئېھتىماللىق ئۆزگەرگۈچىنى كۆرسىتىدۇ. 11-3-بەتتە ئۆگىنىلگەندەك، ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى ھالىتىدە ئېھتىماللىق ئۆزگەرگۈچىسىنىڭ بىر نۇقتىدىكى قىممىتىنىڭ ئېھتىماللىقى 0 بولغاچقا، ۋېرتىكال ئوق ئېھتىماللىق ئەمەس، «ئېھتىماللىق زىچلىقى» دەپ ئاتىلىدىغان نەرسىنى ئىشلىتىمىز. ئېھتىماللىق زىچلىقى بەلگىلىك رايون ئىچىدىكى X نىڭ قىممىتىنىڭ «نىسبىي چىقىش ئاسانلىقى» نى كۆرسىتىدۇ.

The figure below shows the appearance of a continuous probability distribution. The horizontal axis represents the random variable. As learned in Chapter 11-3, in the case of a continuous random variable, since the probability of the random variable taking a value at a certain point is 0, the vertical axis does not represent probability, but uses something called "probability density". Probability density represents the "relative likelihood" of the value of X within a defined range.

ئېھتىماللىق زىچلىقى فۇنكسىيىسى

ئۈزلۈكسىز ئېھتىماللىق ئۆزگەرگۈچىسى X نىڭ بىر قىممەت x نى ئېلىش ئېھتىماللىق زىچلىقىنى فۇنكسىيە قىلغاندا، بۇ «ئېھتىماللىق زىچلىقى فۇنكسىيىسى» دەپ ئاتىلىدۇ. ئېھتىماللىقتىن ئوخشىمايدىكى، \(f(x)>1\) بولۇشى مۇمكىن.

When the probability density of a continuous random variable X taking a certain value x is expressed as a function, it is called a "probability density function". Unlike probability, \(f(x)>1\) is possible.

مىسال 1: ئېھتىماللىق زىچلىقى فۇنكسىيىسى

ئېھتىماللىق ئۆزگەرگۈچىسى X نىڭ ئېلىدىغان قىممىتى 0 دىن 3 غىچە بولغان ھەقىقىي سان بولسا، تۆۋەندىكى ئېھتىماللىق زىچلىقى فۇنكسىيىسىنى ئانىقلايمىز. بۇ فۇنكسىيەدىن نېمە دېگەن نەتىجىگە ئېرىشكىلى بولىدۇ؟

f(x) = \frac{x}{3} \quad (0 \leq x \leq 3)

\(f(1)\) ۋە \(f(3)\) نىڭ قىممىتىنى تاپىمىز:

f(1) = \frac{1}{3}, \quad f(3) = \frac{3}{3} = 1

مەسىلەن، $f(1)=\frac{1}{3}$، $f(3)=1$ بولىدۇ. بۇ يەردە $f(x)$ نىڭ قىممىتى «ئېھتىماللىق» ئەمەس، بەلكى «ئېھتىماللىق زىچلىقى»دۇر.

ئېھتىماللىق زىچلىقى فۇنكسىيىسىدىن بىر رايوندىكى ئېھتىماللىقنى تاپقاندا، ئىنتېگرال ئىشلىتىمىز:

P(a \leq X \leq b) = \int_a^b f(x)\,dx

مەسىلەن، $P(1 \leq X \leq 2)$ نى ھېسابلايمىز:

P(1 \leq X \leq 2) = \int_1^2 \frac{x}{3}\,dx = \left[\frac{x^2}{6}\right]_1^2 = \frac{4}{6} - \frac{1}{6} = \frac{1}{2}

دېمەك، $X$ نىڭ 1 بىلەن 2 ئارىلىقىدا بولۇش ئېھتىماللىقى 0.5 (يەنى 50%) بولىدۇ.

For example, $f(1)=\frac{1}{3}$ and $f(3)=1$. Here, the value of $f(x)$ is not a "probability" but a "probability density".

To find the probability over an interval from the probability density function, we use the integral:

P(a \leq X \leq b) = \int_a^b f(x)\,dx

For example, let's calculate $P(1 \leq X \leq 2)$:

P(1 \leq X \leq 2) = \int_1^2 \frac{x}{3}\,dx = \left[\frac{x^2}{6}\right]_1^2 = \frac{4}{6} - \frac{1}{6} = \frac{1}{2}

Thus, the probability that $X$ lies between 1 and 2 is 0.5 (i.e., 50%).

ئادەتتىكى ئېھتىماللىق تارقىلىش تۈرلىرى

1. بىنوم تارقىلىش (Binomial Distribution)

بىنوم تارقىلىش — بىر پەزىلەتنىڭ «ئۈلگۈرۈش/ئۈلگۈرەمسىزلىك» شەكلىدە بولغاندا، ئۇنى $n$ قېتىم تەكرارلىغاندا ئېرىشىلىدىغان تارقىلىش. فورمۇلا:

P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}

The binomial distribution arises when an experiment has two outcomes (success/failure) and is repeated $n$ times. The formula is:

P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}

2. پوئسون تارقىلىش (Poisson Distribution)

پوئسون تارقىلىش — بەلگىلەنگەن ۋاقىت ياكى رايوندا ئوتتۇرىچە $\lambda$ قېتىم كۆرۈلىدىغان پەزىلەتنىڭ ئېھتىماللىق تارقىلىشى:

P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}

The Poisson distribution describes the probability of observing $k$ events in a fixed interval, when the average number of occurrences is $\lambda$:

P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}

3. نورمال تارقىلىش (Normal Distribution)

نورمال تارقىلىش — مەركىزىي چەكلەنمە تېئورىيىسى بىلەن بەك مۇھىم. ئۇنىڭ فورمۇلاسى:

f(x) = \frac{1}{\sqrt{2\pi \sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}

The normal distribution is fundamental due to the central limit theorem. Its formula is:

f(x) = \frac{1}{\sqrt{2\pi \sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
