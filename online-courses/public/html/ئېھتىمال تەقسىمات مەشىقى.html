Random Variables, Probability Mass Functions, and Probability Density Functions - Practice Problems

ئېھتىمال ئۆزگەرگۈچى ۋە ئېھتىمال تەقسىمات

بۇ مەشىقتە، ئېھتىمال ئۆزگەرگۈچى ۋە ئېھتىمال تەقسىمات ھەققىدىكى چۈشەنچىڭىزنى چوڭقۇرلاشتۇرىدىغان مەسىلىلەرنى ھەل قىلىسىز. تۆۋەندىكى تۈرلەرنى ئۆز ئىچىگە ئالىدۇ:

  • ئايرىم ۋە داۋاملىق ئۆزگەرگۈچىلەرنى ئايرىش
  • ئېھتىمال زىچلىق فۇنكسىيەسى ۋە ئېھتىمال زىچلىق فۇنكسىيەسىنىڭ خاسلىقلىرى
  • ئېھتىمال زىچلىق فۇنكسىيەسى ياردىمىدە ئېھتىمالنى ھېسابلاش
  • ئېھتىمال تەقسىمات شەرتلىرىنى قاندۇرىدىغان ثابىتلىرىنى بەلگىلەش

In this practice exercise, you will solve problems to deepen your understanding of random variables and probability distributions. It includes the following types of problems:

  • Identifying discrete and continuous variables
  • Properties of probability mass functions and probability density functions
  • Calculating probabilities using probability density functions
  • Determining constants that satisfy probability distribution conditions

ئېھتىمال ئۆزگەرگۈچى

ئېھتىمال ئۆزگەرگۈچى دېگەن ئىمكانىيەت فەزاسىدا ئېنىقلىنىدىغان، ئىمكانىيەت نۇقتىلىرىنى ھەقىقىي سانلارغا سىلىشتۇرىدىغان فۇنكسىيەدۇر.

A random variable is a function defined on a sample space that maps sample points to real numbers.

ئايرىم ئېھتىمال ئۆزگەرگۈچى

چەكتە سان ياكى سانىغا بولىدىغان سانسىز قىممەتلەرنى ئالايدىغان ئېھتىمال ئۆزگەرگۈچى.

A random variable that takes a finite or countably infinite number of values.

داۋاملىق ئېھتىمال ئۆزگەرگۈچى

قىممەتلىرى بىر ئاراللىقنى (ياكى بىر قانچە ئاراللىقنىڭ بىرلىشىشىنى) تولدۇرىدىغان ئېھتىمال ئۆزگەرگۈچى.

A random variable whose values fill an interval (or union of intervals).

ئېھتىمال زىچلىق فۇنكسىيەسى (PMF)

ئايرىم ئېھتىمال ئۆزگەرگۈچىنىڭ ئېھتىمال زىچلىق فۇنكسىيەسى \(p(x)\) ئۆزگەرگۈچىنىڭ بەلگىلەنگەن \(x\) قىممىتىنى ئېلىش ئېھتىماللىقىنى بېرىدۇ:

\[ p(x) = P(X = x) \]

ئېھتىمال زىچلىق فۇنكسىيەسى تۆۋەندىكى شەرتلەرنى قاندۇرىدۇ:

  1. ھەممە \(x\) ئۈچۈن، \(0 \leq p(x) \leq 1\)
  2. \(\sum_{x} p(x) = 1\)

Probability Mass Function (PMF)

The probability mass function \(p(x)\) of a discrete random variable gives the probability that the random variable takes the specific value \(x\):

\[ p(x) = P(X = x) \]

The probability mass function satisfies the following conditions:

  1. \(0 \leq p(x) \leq 1\) for all \(x\)
  2. \(\sum_{x} p(x) = 1\)

ئېھتىمال زىچلىق فۇنكسىيەسى (PDF)

داۋاملىق ئېھتىمال ئۆزگەرگۈچىنىڭ ئېھتىمال زىچلىق فۇنكسىيەسى \(f(x)\) ئۆزگەرگۈچىنىڭ بىر قىممەت ئەتراپىدىكى ئېھتىمال زىچلىقىنى تەسۋىرلەيدۇ:

\[ P(a \leq X \leq b) = \int_{a}^{b} f(x) \, dx \]

ئېھتىمال زىچلىق فۇنكسىيەسى تۆۋەندىكى شەرتلەرنى قاندۇرىدۇ:

  1. ھەممە \(x\) ئۈچۈن، \(f(x) \geq 0\)
  2. \(\int_{-\infty}^{\infty} f(x) \, dx = 1\)

Probability Density Function (PDF)

The probability density function \(f(x)\) of a continuous random variable describes the probability density of the random variable around a certain value:

\[ P(a \leq X \leq b) = \int_{a}^{b} f(x) \, dx \]

The probability density function satisfies the following conditions:

  1. \(f(x) \geq 0\) for all \(x\)
  2. \(\int_{-\infty}^{\infty} f(x) \, dx = 1\)

مەسىلە 1: ئايرىم ئۆزگەرگۈچىلەرنى تونۇش

تۆۋەندىكىلەردىن ئايرىم ئۆزگەرگۈچىلەرنى تاللاڭ:

1. بىر چوڭ ياشلىق ئەرنىڭ ئېغىرلىقى X
2. 10 تەڭگە ئىشلەپ، يۈزى ئۈستىگە چۈشكەن سانى X
3. بىر كىتابنىڭ بەت سانى X
4. ئاتموسفېرادىكى نەملىك X
5. ئىچكىلىكتىكى ئالكوگول دەرىجىسى X
6. بىر ئادىل تەڭگىنى يۈزى ئۈستىگە چىققۇچە ئىشلەپ چىققان قېتىم سانى X

چۈشەندۈرۈش:

داۋاملىق ئۆزگەرگۈچى دېگەن ئېغىرلىق ۋە تېمپېراتۇرا ئوخشاش داۋاملىق قىممەتلەرنى ئالايدىغان ئۆزگەرگۈچىلەرگە ئىشارەت قىلىدۇ. تاللاش 1, 4, 5 داۋاملىق قىممەتلەرنى ئالايدىغان ئۆزگەرگۈچىلەر بولۇپ، بىر قىممەت بىلەن يەنە بىر قىممەت ئارىسىدا سانسىز قىممەتلەر بار دەپ قاراشقا بولىدۇ، شۇڭا ئۇلار داۋاملىق ئۆزگەرگۈچىلەر.

شۇڭا، قالغان تاللاشلار "2, 3, 6" ئايرىم ئۆزگەرگۈچىلەر بولىدۇ.

  • تاللاش 2: 10 تەڭگە ئىشلىگەندە، يۈزى ئۈستىگە چۈشكەن سانى 0 دىن 10 گىچە پەقەت پۈتۈن سانلار بولالايدۇ، شۇڭا ئايرىم ئۆزگەرگۈچى.
  • تاللاش 3: كىتاب بەت سانى پۈتۈن سان، شۇڭا ئايرىم ئۆزگەرگۈچى.
  • تاللاش 6: يۈزى ئۈستىگە چىققۇچە تەڭگە ئىشلەش قېتىم سانى 1, 2, 3, ... ئوخشاش پۈتۈن سانلار، شۇڭا ئايرىم ئۆزگەرگۈچى.

Continuous variables are those that take continuous values like weight and temperature. Options 1, 4, and 5 are variables that can take continuous values, and there are countless values between one value and another, so they are continuous variables.

Therefore, the remaining options "2, 3, 6" are discrete variables.

  • Option 2: When tossing 10 coins, the number of heads can only be integers from 0 to 10, so it is a discrete variable.
  • Option 3: The number of pages in a book is an integer, so it is a discrete variable.
  • Option 6: The number of times a coin is tossed until heads appear is an integer like 1, 2, 3, ..., so it is a discrete variable.

مەسىلە 2: ئېھتىمال زىچلىق فۇنكسىيەسى ۋە ئېھتىمال زىچلىق فۇنكسىيەسى

ئېھتىمال زىچلىق فۇنكسىيەسى ۋە ئېھتىمال زىچلىق فۇنكسىيەسى ھەققىدە، تۆۋەندىكى 4 تاللاشتىن توغرا چۈشەندۈرۈشنى تاللاڭ:

1. \(f(x)\) X نىڭ قىممىتىگە قاراپ مەنپىي بولۇشى مۇمكىن.
2. ئېھتىمال زىچلىق فۇنكسىيەسى 1 دىن ئېشىپ كېتىشى مۇمكىن.
3. ئېھتىمال زىچلىق فۇنكسىيەسى 1 دىن ئېشىپ كېتىشى مۇمكىن.
4. ئىككىسى 0.4 دە قىممەتكە ئىگە بولغاندا، \(f(0.4)\) ۋە \(p(0.4)\) ھەر ئىككىسى ئېھتىمال.

چۈشەندۈرۈش:

×：ئېھتىمال زىچلىق فۇنكسىيەسى ۋە ئېھتىمال زىچلىق فۇنكسىيەسى ھەرگىز مەنپىي بولمايدۇ. ئىككىسىمۇ مەنپىي بولماسلىق شەرتini قاندۇرۇشى كېرەك.

×：ئېھتىمال زىچلىق فۇنكسىيەسىدە ھەر بىر \(x\) گە ماس كېلىدىغان قىممەت ئېھتىمالنىڭ ئۆزى بولۇپ، شۇڭا 1 دىن ئېشىپ كېتەلمەيدۇ.

◯：ئېھتىمال زىچلىق فۇنكسىيەسىدە ھەر بىر \(x\) گە ماس كېلىدىغان قىممەت ئېھتىمال ئەمەس بەلكى ئېھتىمال زىچلىقى بولۇپ، شۇڭا 1 دىن ئېشىپ كېتەلەيدۇ.

×：ئېھتىمال زىچلىق فۇنكسىيەسىنىڭ بىر نۇقتىدىكى قىممىتى ئېھتىمال ئەمەس. ئېھتىمال زىچلىق فۇنكسىيەسىنىڭ بىر ئارalلىقتىكى ئىنتېگرالى ئېھتىمال بولىدۇ.

×：Neither probability mass functions nor probability density functions can become negative. Both must satisfy non-negativity.

×：In a probability mass function, the value corresponding to each \(x\) is the probability itself, so it cannot exceed 1.

◯：In a probability density function, the value corresponding to each \(x\) is not a probability but a probability density, so it can exceed 1.

×：The value of a probability density function at a single point is not a probability. The integral of the probability density function over an interval is the probability.

مەسىلە 3: ئېھتىمال زىچلىق فۇنكسىيەسى بىلەن ئېھتىمال ھېسابلاش

تۆۋەندىكى ئېھتىمال زىچلىق فۇنكسىيەسى بەرلگەندە، \(P(1 \leq X \leq 2)\) ئېھتىماللىقىنى تاپىڭ:

\[ f(x) = \begin{cases} \frac{1}{4}x & (0 \leq x \leq 2) \\ -\frac{1}{4}x + 1 & (2 \leq x \leq 4) \\ 0 & (x < 0, x > 4) \end{cases} \]
1. \(\frac{1}{8}\)
2. \(\frac{3}{8}\)
3. \(\frac{5}{8}\)
4. \(\frac{7}{8}\)

چۈشەندۈرۈش:

X>3 رايونىدا \(f(x)=0\) بولغاچقا، ئەتراپلىق ئويلىشىشنىڭ ھاجىتى يوق. شۇڭا، ئىنتېگرال ئارقىلىق تۆۋەندىكىدەك ھېسابلايدۇ ۋە \(\frac{3}{8}\) دىن تېپىدۇ:

\[ P(1 \leq X \leq 2) = \int_{1}^{2} \frac{1}{4}x \, dx = \left[ \frac{1}{8}x^2 \right]_{1}^{2} = \frac{1}{8}(4) - \frac{1}{8}(1) = \frac{4}{8} - \frac{1}{8} = \frac{3}{8} \]

Since \(f(x)=0\) for X>3, we don't need to consider that region. Therefore, using integration, we calculate as follows and get \(\frac{3}{8}\):

\[ P(1 \leq X \leq 2) = \int_{1}^{2} \frac{1}{4}x \, dx = \left[ \frac{1}{8}x^2 \right]_{1}^{2} = \frac{1}{8}(4) - \frac{1}{8}(1) = \frac{4}{8} - \frac{1}{8} = \frac{3}{8} \]

مەسىلە 4: ئېھتىمال زىچلىق فۇنكسىيەسى بىلەن ئېھتىمال ھېسابلاش

تۆۋەندىكى ئېھتىمال زىچلىق فۇنكسىيەسى بەرلگەندە، \(P(X \geq 1)\) ئېھتىماللىقىنى تاپىڭ:

\[ f(x) = \begin{cases} \frac{1}{4}x & (0 \leq x \leq 2) \\ -\frac{1}{4}x + 1 & (2 \leq x \leq 4) \\ 0 & (x < 0, x > 4) \end{cases} \]
1. \(\frac{1}{8}\)
2. \(\frac{3}{8}\)
3. \(\frac{5}{8}\)
4. \(\frac{7}{8}\)

چۈشەندۈرۈش:

ئىنتېگرال ئارقىلىق تۆۋەندىكىدەك ھېسابلايدۇ ۋە \(\frac{7}{8}\) دىن تېپىدۇ:

\[ P(X \geq 1) = \int_{1}^{4} f(x) \, dx = \int_{1}^{2} \frac{1}{4}x \, dx + \int_{2}^{4} \left(-\frac{1}{4}x + 1\right) \, dx \] \[ = \left[ \frac{1}{8}x^2 \right]_{1}^{2} + \left[ -\frac{1}{8}x^2 + x \right]_{2}^{4} \] \[ = \left( \frac{4}{8} - \frac{1}{8} \right) + \left( \left( -\frac{16}{8} + 4 \right) - \left( -\frac{4}{8} + 2 \right) \right) \] \[ = \frac{3}{8} + \left( (-2 + 4) - (-0.5 + 2) \right) = \frac{3}{8} + (2 - 1.5) = \frac{3}{8} + \frac{1}{2} = \frac{3}{8} + \frac{4}{8} = \frac{7}{8} \]

Using integration, we calculate as follows and get \(\frac{7}{8}\):

\[ P(X \geq 1) = \int_{1}^{4} f(x) \, dx = \int_{1}^{2} \frac{1}{4}x \, dx + \int_{2}^{4} \left(-\frac{1}{4}x + 1\right) \, dx \] \[ = \left[ \frac{1}{8}x^2 \right]_{1}^{2} + \left[ -\frac{1}{8}x^2 + x \right]_{2}^{4} \] \[ = \left( \frac{4}{8} - \frac{1}{8} \right) + \left( \left( -\frac{16}{8} + 4 \right) - \left( -\frac{4}{8} + 2 \right) \right) \] \[ = \frac{3}{8} + \left( (-2 + 4) - (-0.5 + 2) \right) = \frac{3}{8} + (2 - 1.5) = \frac{3}{8} + \frac{1}{2} = \frac{3}{8} + \frac{4}{8} = \frac{7}{8} \]

مەسىلە 5: ئېھتىمال تەقسىمات شەرتى

بىر قېتىم زار ئېتىپ، شۇ چاغدا چىققان نومۇرى X نى ئېھتىمال ئۆزگەرگۈچى قىلىپ بەلگىلەڭ. ئەمما، بۇ زارنىڭ ھەر بىر نومۇر چىقىش ئېھتىماللىقى تەڭ ئەمەس، نومۇرغا نىسبەتەن пропорционаلدۇر. يەنى، بىر ثابىت c نى ئىشلىتىپ، k نومۇر چىقىش ئېھتىماللىقى تۆۋەندىكىدەك ئىپادىلىنىشى مۇمكىن:

\[ P(X = k) = ck \quad (k = 1, 2, 3, 4, 5, 6) \]

بۇنى ئېھتىمال تەقسىمات قىلىدىغان c نىڭ قىممىتىنى تاپىڭ.

1. \(\frac{1}{6}\)
2. \(\frac{1}{12}\)
3. \(\frac{1}{18}\)
4. \(\frac{1}{21}\)

چۈشەندۈرۈش:

ئېھتىمال تەقسىمات كېلىشىمى بويىچە، پۈتۈن ۋەقەلەر ئېھتىماللىقىنىڭ يىغىندىسى 1 گە تەڭ بولۇشى كېرەك، شۇنىڭ بويىچە c نى بەلگىلەيمىز. ئۇنىڭ ئۈستىگە، ھەممە k ئۈچۈن \(P(X=k) \geq 0\) بولغاچقا، c نۇرغۇن بولۇشى كېرەك. زارنىڭ قايسى نومۇر چىقىشى ئۆزئارا ئايرىم ۋەقەلەر بولۇپ، تۆۋەندىكى تەڭلىك ئورۇنلىشىدۇ:

\[ \sum_{k=1}^{6} P(X=k) = 1 \]

\(P(X=k)=ck\) دەپ ئىپادىلىنىشى مۇمكىن بولغاچقا، بۇ فورمۇلا تۆۋەندىكىدەك ئۆزگەرتىلىدۇ:

\[ \sum_{k=1}^{6} ck = c(1+2+3+4+5+6) = 21c = 1 \]

شۇڭا، c نىڭ قىممىتى \(\frac{1}{21}\) دەپ تاپىلىدۇ.

According to the requirement of probability distributions, the sum of probabilities for all events must be 1, so we determine c accordingly. Also, since \(P(X=k) \geq 0\) for all k, c must be greater than 0. The events of each face of the die appearing are mutually exclusive, so the following equation holds:

\[ \sum_{k=1}^{6} P(X=k) = 1 \]

Since it can be expressed as \(P(X=k)=ck\), this equation can be transformed as follows:

\[ \sum_{k=1}^{6} ck = c(1+2+3+4+5+6) = 21c = 1 \]

Therefore, the value of c is found to be \(\frac{1}{21}\).
