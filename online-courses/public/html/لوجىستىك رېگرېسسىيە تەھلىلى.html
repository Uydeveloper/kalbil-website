Logistic Regression Analysis

ئىككى قىممەتلىك مەلۇماتلارنى تەھلىل قىلىش ئۇسۇلى

Method for analyzing binary data

1. لوجىستىك رېگرېسسىيە نىمە؟ (ロジスティック回帰分析)

1. What is Logistic Regression? (ロジスティック回帰分析)
لوجىستىك رېگرېسسىيە تەھلىلى دېگەن نىشان ئۆزگەرگۈچى 0 ۋە 1 دىن ئىبارەت ئىككى قىممەتلىك مەلۇمات ياكى 0 دىن 1 گىچە بولغان ئېھتىماللىق قىممەتلىرى بولغاندا، چۈشەندۈرگۈچى ئۆزگەرگۈچىلەر ئارقىلىق ئىپادىلەش ئۇسۇلىدۇر.
Logistic Regression Analysis is a method to express a target variable that consists of binary data (0 and 1) or probability values (0 to 1) using explanatory variables.
لوجىستىك رېگرېسسىيە مودېلى:
P(Y=1) = 1 / [1 + exp(-(β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ))]
Logistic Regression Model:
P(Y=1) = 1 / [1 + exp(-(β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ))]
بۇ يەردە:
Where:
  • Y - نىشان ئۆزگەرگۈچى (0 ياكى 1) Y - Target variable (0 or 1)
  • P(Y=1) - Y نىڭ 1 بولۇش ئېھتىماللىقى P(Y=1) - Probability of Y being 1
  • X₁, X₂, ..., Xₖ - چۈشەندۈرگۈچى ئۆزگەرگۈچىلەر X₁, X₂, ..., Xₖ - Explanatory variables
  • β₀, β₁, ..., βₖ - رېگرېسسىيە كوئېففىتسېنتلىرى β₀, β₁, ..., βₖ - Regression coefficients
  • exp() - ئېكىسپونېنتسىيال فۇنكسىيە exp() - Exponential function

2. لوجىت ئايلاندۇرۇش ۋە لوجىستىك ئايلاندۇرۇش

2. Logit Transformation and Logistic Transformation
لوجىت ئايلاندۇرۇش دېگەن ئېھتىماللىق P نى لوجىت (log-odds) قا ئايلاندۇرۇش:
Logit Transformation is the transformation of probability P to logit (log-odds):
لوجىت ئايلاندۇرۇش:
logit(P) = ln[P / (1 - P)]
Logit Transformation:
logit(P) = ln[P / (1 - P)]
لوجىستىك ئايلاندۇرۇش دېگەن لوجىت نىڭ تەتۈر ئايلاندۇرۇلۇشى:
Logistic Transformation is the inverse transformation of logit:
لوجىستىك ئايلاندۇرۇش:
P = 1 / [1 + exp(-z)]
z = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ
Logistic Transformation:
P = 1 / [1 + exp(-z)]
z = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ

3. سىگموىد فۇنكسىيە (シグモイド関数)

3. Sigmoid Function (シグモイド関数)
سىگموىد فۇنكسىيە ياكى لوجىستىك فۇنكسىيە ھەرقانداق كىرگۈزۈش قىممىتى ئۈچۈن چىقىرىش قىممىتىنى 0 دىن 1 گىچە چەكلىگەن فۇنكسىيەدۇر.
Sigmoid Function or Logistic Function is a function that limits the output value between 0 and 1 for any input value.
سىگموىد فۇنكسىيە:
f(z) = 1 / (1 + e⁻ᶻ)
Sigmoid Function:
f(z) = 1 / (1 + e⁻ᶻ)
سىگموىد فۇنكسىيەنىڭ ئالاھىدىلىكلىرى:
Characteristics of Sigmoid Function:
  • زىيارىەت قىممىتى -∞ دىن +∞ گىچە بولسىمۇ، فۇنكسىيە قىممىتى ھەمىشە 0 دىن 1 گىچە بولىدۇ Even if the input value ranges from -∞ to +∞, the function value is always between 0 and 1
  • فۇنكسىيە S شەكىللىك قىياپەتكە ئىگە The function has an S-shaped curve
  • زىيارىەت قىممىتى 0 بولغاندا، فۇنكسىيە قىممىتى 0.5 بولىدۇ When the input value is 0, the function value is 0.5
  • فۇنكسىيە ھەسساسلىقى ئۆزگىرىدۇ (ئوتتۇرىدا ئەڭ ھەسساس) Function sensitivity changes (most sensitive in the middle)

4. ئەڭ زور ئېھتىماللىق ھېسابلاش (最尤法)

4. Maximum Likelihood Estimation (最尤法)
لوجىستىك رېگرېسسىيەدە رېگرېسسىيە كوئېففىتسېنتلىرىنى ئەڭ زور ئېھتىماللىق ھېسابلاش ئارقىلىق باھالىنىدۇ.
In logistic regression, regression coefficients are estimated using Maximum Likelihood Estimation.
ئېھتىماللىق فۇنكسىيەسى:
L(β) = Π [Pᵢ]^Yᵢ × [1 - Pᵢ]^(1-Yᵢ)
Likelihood Function:
L(β) = Π [Pᵢ]^Yᵢ × [1 - Pᵢ]^(1-Yᵢ)
لوجارىفملىق ئېھتىماللىق فۇنكسىيەسى:
ln L(β) = Σ [Yᵢ × ln(Pᵢ) + (1-Yᵢ) × ln(1-Pᵢ)]
Log-Likelihood Function:
ln L(β) = Σ [Yᵢ × ln(Pᵢ) + (1-Yᵢ) × ln(1-Pᵢ)]
ئەڭ زور ئېھتىماللىق ھېسابلاش قەدەملىرى
Maximum Likelihood Estimation Steps
1
1. باشلانغۇچ قىممەتلەرنى بەلگىلەش
β₀, β₁, ..., βₖ نىڭ باشلانغۇچ قىممەتلىرىنى بەلگىلەيمىز
1. Set initial values
Set initial values for β₀, β₁, ..., βₖ
2. ئېھتىماللىقنى ھېسابلاش
ھەر بىر مەلۇمات نۇقتىسى ئۈچۈن Pᵢ نى ھېسابلاپ، لوجارىفملىق ئېھتىماللىقنى ھېسابلايمىز
2. Calculate likelihood
Calculate Pᵢ for each data point and compute the log-likelihood
3. گرادىيېنت ۋە Hessian ماترىتسىسىنى ھېسابلاش
نيۇتون-رافسون ئۇسۇلى ئارقىلىق كوئېففىتسېنتلارنى ياخشىلايمىز
3. Calculate gradient and Hessian matrix
Improve coefficients using Newton-Raphson method
4. تەكرارلاش
ئېھتىماللىق يېقىنلاشقۇچە تەكرارلايمىز
4. Iterate
Repeat until likelihood converges

لوجىستىك رېگرېسسىيە نەتىجىسى:
logit(P) = -5.2 + 0.08 × يېشى + 0.12 × قان بېسىمى

چۈشەندۈرۈش:

Interpretation:

يېشى كوئېففىتسېنتى (0.08): يېشى ھەر بىر ياش ئاشقاندا، يۈرەك خەتتىرى بولۇش لوجىتى 0.08 گە ئاشىدۇ.

Age Coefficient (0.08): For each additional year of age, the log-odds of heart disease increases by 0.08.

قان بېسىمى كوئېففىتسېنتى (0.12): قان بېسىمى ھەر بىر بىرلىك ئاشقاندا، يۈرەك خەتتىرى بولۇش لوجىتى 0.12 گە ئاشىدۇ.

Blood Pressure Coefficient (0.12): For each unit increase in blood pressure, the log-odds of heart disease increases by 0.12.
مىسال: 50 يېشىدا، 140 قان بېسىمى بولغان كىشىنىڭ يۈرەك خەتتىرى بولۇش ئېھتىماللىقى
Example: Probability of heart disease for a 50-year-old with 140 blood pressure

6. لوجىستىك رېگرېسسىيەنىڭ ئىشلىتىش دائىرىسى

6. Applications of Logistic Regression
لوجىستىك رېگرېسسىيە تۆۋەندىكى ساھەلەردە كەڭ ئىشلىتىلىدۇ:
Logistic regression is widely used in the following areas:
  • مېدىتسىنا: كېسەل دىئاگنوزى، خەتتەرلىك تەھلىلى Medicine: Disease diagnosis, risk analysis
  • مالىيە: كرېدىت خەتتىرى، ئالدىن بىلەن بەلگىلەش Finance: Credit risk, prediction
  • ماركېتىڭ: خېرىدار ئالدىراش ئېھتىماللىقى، مەھسۇلات سېتىۋېلىش ئېھتىماللىقى Marketing: Customer churn probability, product purchase probability
  • ئىجتىمائىي پەنلەر: سايلام نەتىجىسىنى ئالدىن بىلەن بەلگىلەش، ئىجتىمائىي پەن تەتقىقاتلىرى Social Sciences: Election outcome prediction, social science research
  • ماشىنا ئۆگىنىش: تەسۋىرلەش تەھلىلى، كاتېگورىيە بەلگىلەش Machine Learning: Classification analysis, category labeling
