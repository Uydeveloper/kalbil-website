1. بايانلىق سىتاستىكا نىمە؟ / What is Descriptive Statistics?

ئۇيغۇرچە: يىغىلغان سانلىق مەلۇماتنى تەرتىپلەش، خۇلاسىلەش، بايان قىلىش ۋە تەسۋىرلەش ئۇسۇلى. ئوتتۇرىچە، مېدىئان، تارقالغانلىق، ھىستوگرامما بىلەن مەلۇماتنىڭ خۇسۇسىيىتىنى چۈشىنىش.

مىسال: 50 كىشىنىڭ باھىسىنىڭ ئوتتۇرىچىسى، تارقالغانلىقى، تۆت پەسىلىنى بايان قىلىش.

English: Methods to organize, summarize, describe, and visualize data. Use mean, median, variance, histograms to understand data characteristics.

Example: Compute average, spread, and quartiles of 50 students' scores.

2. ئوتتۇرىچە قىممەت (Mean)

ئۇيغۇرچە: بارلىق سانلارنىڭ يىغىندىسىنى سان مىقدارىغا بۆلۈش. مەلۇماتنىڭ مەركىزىنى بايان قىلىدۇ.

Mean = Σx / n

مىسال: 160, 165, 170, 155, 180 → (160+165+170+155+180)/5 = 830/5 = 166 cm

ئەھمىيىتى: بارلىق سانلارنىڭ تەسىرى بولۇپ، چېتىشچان سانلار (outliers) بولسا، مەركىزدىن كېتىپ كېتىشى مۇمكىن.

Excel: =AVERAGE(مەيدانى) ياكى «بيان تالقىنى» → «نەزەرىيە» → «ئاساسىي نەزەرىيە»

English: Sum of all values divided by number of values. Measures central tendency.

Mean = Σx / n

Example: 160, 165, 170, 155, 180 → (160+165+170+155+180)/5 = 830/5 = 166 cm

Note: Influenced by all data; sensitive to outliers.

Excel: =AVERAGE(range) or Data → Data Analysis → Descriptive Statistics

3. مېدىئان (Median)

ئۇيغۇرچە: سانلىق مەلۇماتنى چوڭلىقى بويىچە تەرتىپلەپ، مىللەتتىكى ئوتتۇرىدىكى سان.

تەرتىپ: تەك سان مىقدارى → ئوتتۇرىدىكى سان؛ جۈپ سان مىقدارى → ئوتتۇرىدىكى ئىككى ساننىڭ ئوتتۇرىچىسى.

مىسال: (155, 160, 165, 170, 180) → 165 cm؛ (155, 160, 165, 170, 175, 180) → (165+170)/2 = 167.5 cm

ئەھمىيىتى: چېتىشچان سانلار (outliers) نىڭ تەسىرىدىن ئاز قارايدۇ.

Excel: =MEDIAN(مەيدانى) ياكى «بيان تالقىنى» → «نەزەرىيە» → «ئاساسىي نەزەرىيە»

English: Middle value when data is sorted. Half values are above, half below.

Rule: Odd count → middle value; even count → average of two middle values.

Example: (155, 160, 165, 170, 180) → 165 cm; (155, 160, 165, 170, 175, 180) → (165+170)/2 = 167.5 cm

Note: Resistant to outliers.

Excel: =MEDIAN(range) or Data → Data Analysis → Descriptive Statistics

4. مودا (Mode)

ئۇيغۇرچە: مەلۇماتلاردا ئەڭ كۆپ ئۇچرايدىغان سان.

مىسال: 50, 60, 70, 80, 70, 90, 80, 70 → مودا = 70

ئەھمىيىتى: سانلىق ۋە سۈپەتلىك مەلۇماتلارغا ئىشلىتىلىدۇ. چېتىشچان سانلار نىڭ تەسىرىدىن ئاز قارايدۇ.

Excel: =MODE.SNGL(مەيدانى) ياكى «بيان تالقىنى» → «نەزەرىيە» → «ئاساسىي نەزەرىيە»

English: The most frequently occurring value in a dataset.

Example: 50, 60, 70, 80, 70, 90, 80, 70 → Mode = 70

Note: Applicable to both numerical and categorical data; robust to outliers.

Excel: =MODE.SNGL(range) or Data → Data Analysis → Descriptive Statistics

5. تارقالغانلىق (Variance)

ئۇيغۇرچە: ھەر بىر ساننىڭ ئوتتۇرىچىسىدىن پەرقىنىڭ كۋادراتىنىڭ ئوتتۇرىچىسى. مەلۇماتنىڭ تارقالغانلىقىنى بايان قىلىدۇ.

σ² = Σ(x−μ)² / n

مىسال: سانلار: 160, 165, 170, 155, 180، ئوتتۇرىچىسى = 166 → σ² = (36+1+16+121+196)/5 = 370/5 = 74 cm²

ئەھمىيىتى: بىرلىك كۋادرات بولۇپ، تۇشۇنۇشقا قىينىش مۇمكىن.

Excel: =VAR.P(مەيدانى) (تاجاۋۇز)، =VAR.S(مەيدانى) (نۇسخى)

English: Average of squared deviations from the mean. Measures spread.

σ² = Σ(x−μ)² / n

Example: Data: 160, 165, 170, 155, 180, mean=166 → σ² = (36+1+16+121+196)/5 = 370/5 = 74 cm²

Note: Unit is squared; less intuitive.

Excel: =VAR.P(range) (population), =VAR.S(range) (sample)

6. ستاندارد ئېشىپ كېتىش (Standard Deviation)

ئۇيغۇرچە: تارقالغانلىقنىڭ كىۋادرات يىلتىزى. مەلۇماتنىڭ تارقالغانلىقىنى بىرلىك بويىچە بايان قىلىدۇ.

σ = √Variance

مىسال: تارقالغانلىق = 74 → σ = √74 ≈ 8.6 cm

ئەھمىيىتى: چوڭ بولسا، تارقالغانلىق چوڭ؛ كىچىك بولسا، تارقالغانلىق كىچىك.

Excel: =STDEV.P(مەيدانى) (تاجاۋۇز)، =STDEV.S(مەيدانى) (نۇسخى)

English: Square root of variance. Measures spread in original units.

σ = √Variance

Example: Variance = 74 → σ = √74 ≈ 8.6 cm

Note: Larger value = more spread; smaller = less spread.

Excel: =STDEV.P(range) (population), =STDEV.S(range) (sample)

7. چاستوتا تەقسىملەش / ھىستوگرامما

ئۇيغۇرچە: سانلىق مەلۇماتنى دائىرىگە ئايرىپ، ھەر دائىرىدىكى سان سانىنى كۆرسىتىش. مەلۇماتنىڭ شەكلىنى، مەركىزىنى، تارقالغانلىقىنى كۆرۈشگە ياردەم بېرىدۇ.

مىسال: 150-160cm: 5 كىشى، 160-170cm: 12 كىشى، 170-180cm: 8 كىشى

Excel: =FREQUENCY(مەيدانى, دائىرى) ياكى «قۇرۇلۇش» → «گراف» → «ھىستوگرامما»

English: Group data into intervals and count frequency. Visualized as a histogram. Helps see shape, center, and spread.

Example: 150-160cm: 5 people, 160-170cm: 12 people, 170-180cm: 8 people

Excel: =FREQUENCY(data_range, bins) or Insert → Chart → Histogram

8. استانداردلاش (Standardization)

ئۇيغۇرچە: سانلىق مەلۇماتنى ئوتتۇرىچىسى 0، ستاندارد ئېشىپ كېتىشى 1 بولۇش ئۇچۇن ئۆزگەرتىش. بۇ Z-سېنىقى (z-score) دەپ ئاتىلىدۇ.

Z = (X − μ) / σ

مىسال: X=180، μ=166، σ=8.6 → Z = (180−166)/8.6 ≈ 1.63

ئەھمىيىتى: تۈرلۈك بىرلىكلىك سانلارنى سالىشتۇرۇش، چېتىشچان سانلارنى تېپىش.

Excel: =STANDARDIZE(قىممەت, ئوتتۇرىچە, ستاندارد)

English: Transform data to have mean 0 and standard deviation 1. Resulting value is called Z-score.

Z = (X − μ) / σ

Example: X=180, μ=166, σ=8.6 → Z = (180−166)/8.6 ≈ 1.63

Note: Used to compare different units, detect outliers.

Excel: =STANDARDIZE(value, mean, std_dev)
