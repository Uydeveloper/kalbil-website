ئېھتىماللىق ئۆزگەرگۈچى ۋە ئېھتىماللىق تارقىلىشى

Probability Variable and Probability Distribution

كىرىش | Introduction

ئېھتىماللىق ئۆزگەرگۈچى: بىر ئۆزگەرگۈچىنىڭ قىممىتىنىڭ ئېلىنىش ئېھتىماللىقى بار بولغان ئۆزگەرگۈچى. مەسىلەن، زار ئاتقاندا چىققان نۇمۇر {1, 2, 3, 4, 5, 6} نىڭ ھەر قايسىسى بولۇپ، ھەر بىر نۇمۇرنىڭ چىقىش ئېھتىماللىقى بولغاچقا، زار ئاتقاندا چىققان نۇمۇر ئېھتىماللىق ئۆزگەرگۈچى دەپ ئېيتىلىدۇ.

ئېھتىماللىق تارقىلىشى: ئېھتىماللىق ئۆزگەرگۈچىنىڭ ئېلىدىغان قىممىتى ۋە بۇ قىممەتنىڭ ئېلىنىش ئېھتىماللىقىنىڭ مۇناسىۋىتى. مەسىلەن، زار ئاتقاندا، 1 دىن 6 غىچە بولغان ئېھتىماللىق ئۆزگەرگۈچى قىممىتىگە ھەر قايسىسى ئېھتىماللىقى مۇناسىۋەتلىك بولغانلىقى ئۈچۈن، بۇ ئېختىماللىق تارقىلىشى دەپ ئېيتىلىدۇ.

Random variable: A variable whose value has a probability of occurrence. For example, when rolling a die, the outcome is one of {1, 2, 3, 4, 5, 6}, and since each number has a probability of occurring, the outcome of rolling a die is called a random variable.

Probability distribution: The relationship between the values a random variable can take and the probability of taking those values. For example, when rolling a die, since each value from 1 to 6 is associated with a probability, this is called a probability distribution.

ئەھمىيەتلىك ئېسكەرتىش / Important Note:
ئېھتىماللىق ئۆزگەرگۈچىنىڭ بارلىق مۇمكىن بولغان قىممەتلەرنىڭ ئېھتىماللىقىنىڭ جەمى 1 بولۇشى كېرەك.
The sum of probabilities of all possible values of a random variable must equal 1.

مىسال 1: زار ئاتقان | Example 1: Rolling a Die

زار ئاتقاندا چىققان نۇمۇر ئېھتىماللىق ئۆزگەرگۈچى. ھەر بىر نۇمۇرنىڭ چىقىش ئېھتىماللىقى بولىدۇ.

The outcome of rolling a die is a random variable. Each number has a probability of occurring.

مىسال 2: تەڭگە ئاتقان | Example 2: Coin Toss

تەڭگە ئاتقاندا، قارا يۈزگە «1»، ئارقى يۈزگە «0» دەپ قارايسۇن. قارا يۈز ۋە ئارقى يۈزنىڭ چىقىش ئېھتىماللىقى بولغاچقا، بۇمۇ ئېختىماللىق ئۆزگەرگۈچى.

When tossing a coin, assign "1" to heads and "0" to tails. Since both heads and tails have a probability, this is also a random variable.

مىسال 3: ئوقۇغۇچىلارنىڭ ئىمتىھان نەتىجىسى | Example 3: Student Exam Scores

بىر سىنىپتىكى ئوقۇغۇچىلارنىڭ ئىمتىھان نەتىجىسى ئېختىماللىق ئۆزگەرگۈچى بولۇپ، ھەر بىر نەتىجىنىڭ ئېلىنىش ئېختىماللىقى بار.

The exam scores of students in a class are a random variable, with each score having a probability of occurrence.

ئېھتىماللىق ئۆزگەرگۈچى | Random Variable

ئېھتىماللىق ئۆزگەرگۈچى نېمە؟ | What is a Random Variable?

ئېختىماللىق ئۆزگەرگۈچى دېگەندە، بىر ئۆزگەرگۈچىنىڭ قىممىتىنىڭ ئېلىنىش ئېختىماللىقى بار بولغان ئۆزگەرگۈچى. مەسىلەن، زار ئاتقاندا چىققان نۇمۇر {1, 2, 3, 4, 5, 6} نىڭ ھەر قايسىسى بولۇپ، ھەر بىر نۇمۇرنىڭ چىقىش ئېختىماللىقى بولغاچقا، زار ئاتقاندا چىققان نۇمۇر ئېختىماللىق ئۆزگەرگۈچى دەپ ئېيتىلىدۇ.

X \in \{1, 2, 3, 4, 5, 6\}

مەسىلەن، «زار ئاتقاندا 3 نۇمۇر چىقىش ئېختىماللىقى» تۆۋەندىكىدەك يېزىلىدۇ:

P(X=3) = \frac{1}{6}

A random variable is a variable whose value has a probability of occurrence. For example, when rolling a die, the outcome is one of {1, 2, 3, 4, 5, 6}, and each number has a probability of occurring, so it is called a random variable.

X \in \{1, 2, 3, 4, 5, 6\}

For example, "the probability of rolling a 3" is written as:

P(X=3) = \frac{1}{6}

سانسىز پەزىلەتلەرنىڭ ئېختىماللىق ئۆزگەرگۈچىسى | Random Variables for Non-Numeric Events

تەڭگە ئاتقاندا، قارا يۈزگە «1»، ئارقى يۈزگە «0» دەپ قارايمىز. قارا يۈز ۋە ئارقى يۈزنىڭ چىقىش ئېختىماللىقى بولغاچقا، بۇمۇ ئېختىماللىق ئۆزگەرگۈچى:

P(X=1) = \frac{1}{2}, \quad P(X=0) = \frac{1}{2}

When tossing a coin, we assign "1" to heads and "0" to tails. Since both have a probability, this is a random variable:

P(X=1) = \frac{1}{2}, \quad P(X=0) = \frac{1}{2}

دائىملىق ئېختىماللىق تارقىلىشى | Discrete Probability Distribution

دائىملىق ئېختىماللىق ئۆزگەرگۈچىسى | Discrete Random Variable

دائىملىق ئۆزگەرگۈچى ئۈزۈلۈشلۈك قىممەتلەرنى ئېلىدۇ. مەسىلەن، زارنىڭ نۇمۇرى ياكى ئادەم سانى.

X\(x_1\)\(x_2\)...\(x_n\)
P(X)\(p_1\)\(p_2\)...\(p_n\)

دائىملىق ئېختىماللىق تارقىلىشىنىڭ ئاساسىي شەرتى:

\sum_{i=1}^{n} P(X = x_i) = 1

A discrete random variable takes discrete values, like die outcomes or number of people.

X\(x_1\)\(x_2\)...\(x_n\)
P(X)\(p_1\)\(p_2\)...\(p_n\)

The fundamental condition for discrete probability distribution:

\sum_{i=1}^{n} P(X = x_i) = 1

ئېختىماللىق مەسىلىسى فۇنكسىيىسى | Probability Mass Function

دائىملىق ئېختىماللىق ئۆزگەرگۈچىسىنىڭ ئېختىماللىقى:

P(X=x) = f(x), \quad \sum_{i=1}^{n} f(x_i) = 1

بۇ يەردىكى \(f(x)\) نى ئېختىماللىق مەسىلىسى فۇنكسىيىسى (PMF) دەپ ئاتايدۇ.

The probability of a discrete random variable:

P(X=x) = f(x), \quad \sum_{i=1}^{n} f(x_i) = 1

Here, \(f(x)\) is called the Probability Mass Function (PMF).

ئۈزلۈكسىز ئېختىماللىق تارقىلىشى | Continuous Probability Distribution

ئۈزلۈكسىز ئېختىماللىق ئۆزگەرگۈچىسى | Continuous Random Variable

ئۈزلۈكسىز ئۆزگەرگۈچى چەكسىز قىممەتلەرنى ئېلىدۇ، مەسىلەن، سالماق ياكى تېمپېراتۇرا.

ئۈزلۈكسىز ئۆزگەرگۈچىنىڭ ئاساسىي خۇسۇسىيىتى: بىر نۇقتىنىڭ ئېختىماللىقى نۆل بولىدۇ.

A continuous random variable takes infinitely many values, e.g., weight or temperature.

The key property of continuous variables: the probability at a single point is zero.

مىسال: ئۈزلۈكسىز ئېختىماللىق | Example: Continuous Probability

X نىڭ قىممىتى 1 دىن 6 غىچە. \(P(X=3) = 0\) چۈنكى ئۈزلۈكسىز تارقىلىشتا بىر نۇقتىنىڭ ئېختىماللىقى نۆل.

لېكىن بىر ئارىلىقتىكى ئېختىماللىق نۆلدىن چوڭ بولىدۇ: \(P(2 \leq X \leq 4) > 0\)

X takes values from 1 to 6. \(P(X=3) = 0\) because in a continuous distribution, the probability at a single point is zero.

However, the probability over an interval is positive: \(P(2 \leq X \leq 4) > 0\)

ئېختىماللىق زىچلىقى | Probability Density Function

ئېختىماللىق زىچلىقى | Probability Density

ئۈزلۈكسىز تارقىلىشتا، ئېختىماللىق زىچلىقى X نىڭ قىممىتىنىڭ نىسبىي چىقىش ئاسانلىقىنى كۆرسىتىدۇ.

ئېختىماللىق زىچلىقى فۇنكسىيىسى (PDF) نىڭ ئاساسىي شەرتى:

\int_{-\infty}^{\infty} f(x) \, dx = 1

In a continuous distribution, probability density shows the relative likelihood of X's values.

The fundamental condition for Probability Density Function (PDF):

\int_{-\infty}^{\infty} f(x) \, dx = 1

مىسال 1: ئېختىماللىق زىچلىقى فۇنكسىيىسى | Example 1: Probability Density Function

X نىڭ قىممىتى 0 دىن 3 غىچە، فۇنكسىيە:

f(x) = \frac{x}{3}, \quad (0 \leq x \leq 3)

ھېسابلاش:

1 فۇنكسىيەنى تەكشۈرۈش

فۇنكسىيەنىڭ توغرىلىقىنى تەكشۈرۈش ئۈچۈن، ئىنتېگرالى 1 گە تەڭ بولۇشى كېرەك:

\int_0^3 \frac{x}{3} \, dx = \left[ \frac{x^2}{6} \right]_0^3 = \frac{3^2}{6} - \frac{0^2}{6} = \frac{9}{6} = 1.5

ئىنتېگرال 1.5 بولغانلىقى ئۈچۈن، نورماللاش كېرەك:

f(x) = \frac{x}{4.5}, \quad \int_0^3 \frac{x}{4.5} \, dx = 1
2 قىممەتلەرنى ھېسابلاش

\(f(1) = \frac{1}{4.5} \approx 0.222\), \(f(3) = \frac{3}{4.5} \approx 0.667\)

3 ئېختىماللىق ھېسابلاش

\(P(1 \leq X \leq 2) = \int_1^2 \frac{x}{4.5} \, dx = \left[ \frac{x^2}{9} \right]_1^2 = \frac{4}{9} - \frac{1}{9} = \frac{3}{9} = \frac{1}{3}\)

X takes values from 0 to 3, function:

f(x) = \frac{x}{3}, \quad (0 \leq x \leq 3)

Calculation:

1 Verify the function

The integral must equal 1:

\int_0^3 \frac{x}{3} \, dx = \left[ \frac{x^2}{6} \right]_0^3 = \frac{9}{6} = 1.5

Since the integral is 1.5, normalize:

f(x) = \frac{x}{4.5}, \quad \int_0^3 \frac{x}{4.5} \, dx = 1
2 Calculate values

\(f(1) = \frac{1}{4.5} \approx 0.222\), \(f(3) = \frac{3}{4.5} \approx 0.667\)

3 Calculate probability

\(P(1 \leq X \leq 2) = \int_1^2 \frac{x}{4.5} \, dx = \left[ \frac{x^2}{9} \right]_1^2 = \frac{4}{9} - \frac{1}{9} = \frac{1}{3}\)

مىسال 2: يېشىل يورۇقلۇق چىراغ | Example 2: Green Light Duration

X يورۇقلۇق چىراغنىڭ يېشىل ۋاقتى (سېكۇنت)، \(f(x) = \frac{1}{30}\), \(0 \leq x \leq 30\). \(P(10 \leq X \leq 20)\) نى ھېسابلاش:

P(10 \leq X \leq 20) = \int_{10}^{20} \frac{1}{30} \, dx = \frac{20-10}{30} = \frac{1}{3}

بۇ بىر تەرەپلىمە تارقىلىش (Uniform Distribution) نىڭ مىسالى.

X is the duration of a green light (seconds), \(f(x) = \frac{1}{30}\), \(0 \leq x \leq 30\). Calculate \(P(10 \leq X \leq 20)\):

P(10 \leq X \leq 20) = \int_{10}^{20} \frac{1}{30} \, dx = \frac{20-10}{30} = \frac{1}{3}

This is an example of Uniform Distribution.

مەسىلە: تاسادىپىي ۋاقىت | Problem: Random Time

X 0 دىن 5 گىچە، \(f(x) = \frac{2x}{25}\). \(P(2 \leq X \leq 4)\) نى ھېسابلاش.

X from 0 to 5, \(f(x) = \frac{2x}{25}\). Calculate \(P(2 \leq X \leq 4)\).

1 فۇنكسىيەنى تەكشۈرۈش | Verify the function
\int_0^5 \frac{2x}{25} \, dx = \left[ \frac{x^2}{25} \right]_0^5 = \frac{25}{25} = 1
2 ئېختىماللىق ھېسابلاش | Calculate probability
P(2 \leq X \leq 4) = \int_2^4 \frac{2x}{25} \, dx = \left[ \frac{x^2}{25} \right]_2^4 = \frac{16}{25} - \frac{4}{25} = \frac{12}{25} = 0.48

تارقىلىش تۈرلىرى | Types of Distributions

بىر تەرەپلىمە تارقىلىش | Uniform Distribution

باراۋەر ئېختىماللىق بىلەن تارقىلىدۇ. مەسىلەن، \(f(x) = \frac{1}{b-a}\), \(a \leq x \leq b\).

ئاساسىي خۇسۇسىيىتى: ھەر بىر قىممەتنىڭ ئېختىماللىقى باراۋەر.

Distributed with equal probability, e.g., \(f(x) = \frac{1}{b-a}\), \(a \leq x \leq b\).

Main property: every value has equal probability.

نورمال تارقىلىش | Normal Distribution

قوڭغۇر شەكىلدىكى تارقىلىش، فۇنكسىيە:

f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}

ئاساسىي خۇسۇسىيىتى: ئوتتۇرىچە قىممەت (\(\mu\)) دىن ئىككى تەرەپكە سىممېتىرىك.

Bell-shaped distribution, function:

f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}

Main property: symmetric around the mean (\(\mu\)).

بىنومىيال تارقىلىش | Binomial Distribution

n قېتىم سىناقتىكى مۇۋەپپەقىيەت سانى، \(P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}\).

ئاساسىي خۇسۇسىيىتى: ھەر بىر سىناقتىكى مۇۋەپپەقىيەت ئېھتىماللىقى باراۋەر.

Number of successes in n trials, \(P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}\).

Main property: constant probability of success in each trial.
