Simple Linear Regression Analysis

بىر ئۆزگەرگۈچى بىلەن باشقا بىر ئۆزگەرگۈچى ئارىسىدىكى مۇناسىۋەتنى چۈشىنىش

Understanding the relationship between one variable and another variable

1. رېگرېسسىيە نىمە؟ (回帰とは)

1. What is Regression? (回帰とは)
رېگرېسسىيە دېگەن نىمە؟ رېگرېسسىيە دېگەن بىر نىشان ئۆزگەرگۈچىنى (باغلىنىشلىق ئۆزگەرگۈچى) چۈشەندۈرگۈچى ئۆزگەرگۈچىلەر ئارقىلىق ئىپادىلەش ئۇسۇلىدۇر.
Regression is a method to express a target variable (dependent variable) using explanatory variables.
رېگرېسسىيە فورمۇلىسى: Y = β₀ + β₁X + ε
Regression Formula: Y = β₀ + β₁X + ε
بۇ يەردە:
Where:
  • Y - نىشان ئۆزگەرگۈچى (باغلىنىشلىق ئۆزگەرگۈچى) Y - Target variable (dependent variable)
  • X - چۈشەندۈرگۈچى ئۆزگەرگۈچى (مۇستەقىل ئۆزگەرگۈچى) X - Explanatory variable (independent variable)
  • β₀ - قىيىپ (ئۇزۇنلۇق كېسىش نۇقتىسى) β₀ - Intercept (y-intercept)
  • β₁ - ئېگىزلىك (رېگرېسسىيە كوئېففىتسېنتى) β₁ - Slope (regression coefficient)
  • ε - خاتالىق (ئۈزۈلۈش) ε - Error (residual)

2. ئاددىي رېگرېسسىيە (単回帰分析)

2. Simple Linear Regression (単回帰分析)
ئاددىي رېگرېسسىيە دېگەن بىر چۈشەندۈرگۈچى ئۆزگەرگۈچى (X) بىلەن بىر نىشان ئۆزگەرگۈچى (Y) ئارىسىدىكى سىزىقلىق مۇناسىۋەتنى تەھلىل قىلىش ئۇسۇلىدۇر.
Simple Linear Regression is a method to analyze the linear relationship between one explanatory variable (X) and one target variable (Y).
ئاددىي رېگرېسسىيە فورمۇلىسى: Ŷ = b₀ + b₁X
Simple Linear Regression Formula: Ŷ = b₀ + b₁X
بۇ يەردە:
Where:
  • Ŷ - Y نىڭ باھالىنىش قىممىتى Ŷ - Estimated value of Y
  • b₀ - قىيىپنىڭ باھالىنىش قىممىتى b₀ - Estimated value of intercept
  • b₁ - ئېگىزلىكنىڭ باھالىنىش قىممىتى b₁ - Estimated value of slope
ئاددىي رېگرېسسىيە ۋە كۆپ رېگرېسسىيە پەرقى:
Difference between Simple and Multiple Regression:
  • ئاددىي رېگرېسسىيە: بىر چۈشەندۈرگۈچى ئۆزگەرگۈچى + بىر نىشان ئۆزگەرگۈچى Simple Regression: One explanatory variable + One target variable
  • كۆپ رېگرېسسىيە: كۆپ چۈشەندۈرگۈچى ئۆزگەرگۈچى + بىر نىشان ئۆزگەرگۈچى Multiple Regression: Multiple explanatory variables + One target variable

3. ئەڭ كىچىك كۋادراتلار ئۇسۇلى (最小二乗法)

3. Least Squares Method (最小二乗法)
ئەڭ كىچىك كۋادراتلار ئۇسۇلى دېگەن رېگرېسسىيە سىزىقىنى ھېسابلاش ئۇسۇلى بولۇپ، ھەقىقىي مەلۇمات نۇقتىلىرى بىلەن رېگرېسسىيە سىزىقى ئارىسىدىكى ئۇزۇنلۇقلارنىڭ كۋادراتلىرىنىڭ يىغىندىسىنى ئەڭ كىچىك قىلىدىغان سىزىقنى تېپىش ئۇسۇلىدۇر.
Least Squares Method is a method to calculate the regression line by finding the line that minimizes the sum of squared distances between actual data points and the regression line.
ئەڭ كىچىك كۋادراتلار فورمۇلىسى:
b₁ = Σ[(Xᵢ - X̄)(Yᵢ - Ȳ)] / Σ[(Xᵢ - X̄)²]
b₀ = Ȳ - b₁X̄
Least Squares Formula:
b₁ = Σ[(Xᵢ - X̄)(Yᵢ - Ȳ)] / Σ[(Xᵢ - X̄)²]
b₀ = Ȳ - b₁X̄
بۇ يەردە:
Where:
  • X̄ - X نىڭ ئوتتۇرىچە قىممىتى X̄ - Mean value of X
  • Ȳ - Y نىڭ ئوتتۇرىچە قىممىتى Ȳ - Mean value of Y
  • Xᵢ, Yᵢ - ھەر بىر مەلۇمات نۇقتىسى Xᵢ, Yᵢ - Each data point
