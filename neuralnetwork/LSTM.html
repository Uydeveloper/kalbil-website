نېرۋاتور 7-باب – LSTM/GRU

LSTM (Long Short-Term Memory) ۋە GRU (Gated Recurrent Unit) — RNN نىڭ ياخشىلانغان نۇسخىلىرى. بۇلار ئۇزۇن مۇددەتلىك بايلىنىش (Long-term Dependencies) نى ساقلاش ئۈچۈن ئىشىقچا (Gates) ئىشلىتىدۇ.

LSTM and GRU solve RNN’s vanishing gradient problem using gating mechanisms to control information flow over long sequences.
1. LSTM نېمە؟
1. What is LSTM?

LSTM — ئۈچ خىل ئىشىقچا بار: Forget Gate (ئۇنتۇش ئىشىقچىسى)، Input Gate (كىرگۈزگۈچ ئىشىقچىسى)، Output Gate (چىقىرىش ئىشىقچىسى). بۇ ئىشىقچىلار بىلەن مەلۇماتنىڭ قاچىلا ساقلىنىشى، قاچىلا ئۇنتۇلۇشى باشقۇرۇلىدۇ.

LSTM uses three gates to regulate memory: Forget Gate (what to discard), Input Gate (what new info to store), Output Gate (what to output).

2. GRU نېمە؟
2. What is GRU?

GRU — LSTM نىڭ سادىرەك نۇسخىسى. ئۇ ئىككى ئىشىقچا (Reset Gate, Update Gate) ئىشلىتىدۇ. ھېسابلاش تېز، لېكىن ئىقتىدارى LSTM دىن بىر قەدەر كىچىك.

GRU simplifies LSTM with two gates: Reset and Update. Faster, slightly less powerful.

3. قوللىنىش ساھەلىرى
3. Applications
  • ئۇزۇن ماقالەلەرنى تەرجىمە قىلىش

  • Machine translation (e.g., Uyghur ↔ English)
  • Music generation
  • Language learning apps
