What is an Activation Function?

ئاكتىپلاش فۇنكسىيەسى نېرۋاتوردىكى ھەر بىر نوروننىڭ چىقىرىش قىممىتىنى بېكىتىدىغان مۇھىم بىر قىسمى. بۇ فۇنكسىيە نورونغا كىرىدىغان سىگنالنى قانداق مەيدانغا كەلتۈرۈشىنى بېكىتىدۇ ۋە نېرۋاتورنىڭ سىزىقلىق بولمىغانلىقىنى كاپالەتلەندۈرىدۇ.

The activation function is a crucial component of each neuron in a neural network that determines its output. This function decides how the input signal should be transformed and ensures the non-linearity of the neural network.

\( \text{Output} = f(\sum_{i=1}^{n} w_i x_i + b) \)
كىرىش (Input)
\( x_1, x_2, ..., x_n \)
  • نورونغا كىرىدىغان سىگناللار
  • Input signals to the neuron
ئېغىرلىق (Weights)
\( w_1, w_2, ..., w_n \)
  • ھەر بىر كىرىشنىڭ مۇھىملىق دەرىجىسى
  • Importance of each input
يىلتىز (Bias)
\( b \)
  • نوروننىڭ ئاكتىپلىشىش چېگراسى
  • Activation threshold of neuron
ئاكتىپلاش (Activation)
\( f(z) \)
  • نوروننىڭ چىقىرىشىنى بېكىتىدۇ
  • Determines neuron's output

سىگموئىد فۇنكسىيەسى (Sigmoid Function)

سىگموئىد فۇنكسىيەسى لوجىستىك رېگرېسسىيەدە كەڭ قوللىنىلغان بولۇپ، ھەر قانداق كىرىش قىممىتىنى 0 دىن 1 گىچە بولغان ئارىلىققا سىقىپ چىقىرىدۇ. بۇ ئاكتىپلاش فۇنكسىيەسى ئېھتىماللىقنى تەخمىنلەشتە ئۈنۈملۈك.

The sigmoid function, widely used in logistic regression, squeezes any input value into the range 0 to 1. This activation function is effective for probability estimation.

ئۈستۈنلۈكلىرى
Advantages
  • چىقىرىش قىممىتى 0-1 ئارىلىقىدا
  • بارلىق جايلاردا دىففېرېنسىياللاشقا بولىدۇ
  • ئېھتىماللىق تەخمىنى ئۈچۈن مۇناسىۋەتلىك
چەكلىمىلىرى
Limitations
  • گرادىيېنتنىڭ يوقىلىشى مەسىلىسى
  • ھېسابلاش جىددىي
  • چىقىرىش قىممىتى سىفىر ئەتراپىدا ئەمەس
\( \tanh(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} \)

تانگېنت ھىپېربولىك فۇنكسىيەسى (Tanh Function)

تانگېنت ھىپېربولىك فۇنكسىيەسى سىگموئىدكە ئوخشاش بولۇپ، ئەمما چىقىرىش دائىرىسى -1 دىن +1 گىچە. بۇ فۇنكسىيە سىگموئىدىن ئەتراپلىق بولۇپ، چىقىرىش قىممىتىنىڭ ئوتتۇرىچە قىممىتى سىفىر بولىدۇ.

The tanh function is similar to sigmoid but has an output range of -1 to +1. This function is better than sigmoid as it centers the output around zero.

خۇسۇسىيەت سىگموئىد تانگېنت ھىپېربولىك
چىقىرىش دائىرىسى (0, 1) (-1, 1)
ئوتتۇرىچە قىممىتى 0.5 0
گرادىيېنت يوقىلىشى يۇقىرى تۆۋەن
قوللىنىش ساھەسى ئېھتىماللىق تەخمىنى چوڭقۇر نېرۋاتورلار
\( \text{ReLU}(x) = \max(0, x) \)

رېلۇ فۇنكسىيەسى (Rectified Linear Unit)

رېلۇ زامانىۋى نېرۋاتورلاردا ئەڭ كەڭ قوللىنىلىدىغان ئاكتىپلاش فۇنكسىيەسى. بۇ فۇنكسىيە ھېسابلاش جىددىي ئەمەس ۋە گرادىيېنتنىڭ يوقىلىشى مەسىلىسىنى ياخشىراق ھەل قىلىدۇ.

ReLU is the most widely used activation function in modern neural networks. This function is computationally efficient and better handles the vanishing gradient problem.

ئۈستۈنلۈكلىرى
Advantages
  • ھېسابلاش ئاسان
  • گرادىيېنت يوقىلىشىنىڭ ئالدىنى ئالىدۇ
  • بىر تەرەپلىمە چىقىرىش
چەكلىمىلىرى
Limitations
  • "ئۆلۈك رېلۇ" مەسىلىسى
  • سىزىقلىق بولمىغانلىق چەكلىك
  • مەنفىي قىممەتلەرنى قوبۇل قىلمايدۇ
لىكى رېلۇ (Leaky ReLU)
\( f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha x & \text{if } x \leq 0 \end{cases} \)
  • مەنفىي قىممەتلەرگە كىچىك گرادىيېنت
  • Small gradient for negative values
  • "ئۆلۈك رېلۇ" مەسىلىسىنى ھەل قىلىدۇ
  • Solves "dead ReLU" problem
ئېلۇ (ELU)
\( f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha(e^{x} - 1) & \text{if } x \leq 0 \end{cases} \)
  • مەنفىي قىممەتلەرگە سىزىقلىق بولمىغان يول قويىدۇ
  • Non-linear path for negative values
  • رېلۇدىن تېخىمۇ ياخشى نەتىجە بېرىدۇ
  • Better performance than ReLU
سۋىش (Swish)
\( f(x) = x \cdot \sigma(\beta x) \)
  • Google تەرەپتىن تەۋسىيە قىلىنغان
  • Recommended by Google
  • رېلۇدىن تېخىمۇ ياخشى نەتىجە بېرىدۇ
  • Outperforms ReLU in many tasks
گېلۇ (GELU)
\( f(x) = x \cdot \Phi(x) \)
  • GPT ئەسلىتىش ئۈچۈن ئىشلىتىلگەن
  • Used in GPT models
  • سۋىشتىن تېخىمۇ ياخشى نەتىجە بېرىدۇ
  • Outperforms Swish in some cases

تۆۋەندىكى يېتەكچى ئارقىلىق ئوڭۇشلۇق ئاكتىپلاش فۇنكسىيەسىنى تاللىيالايسىز:

Use the following guide to select the appropriate activation function:

چىقىرىش قاتلىمى
Output Layer
  • ئېھتىماللىق: سىگموئىد
  • رېگرېسسىيە: سىزىقلىق
  • كۆپلىمە كەسپىي: سوۋتمەكس
    • يوشۇرۇن قاتلاملار
    Hidden Layers
  • ئادەتتىكى: رېلۇ
  • يۇقىرى دەرىجىلىك: ئېلۇ/گېلۇ
  • ئەسكىچى ئەسلىتىش: تانگېنت ھىپېربولىك
    • مەسىلىلەرگە قاراش
    Problem Considerations
  • گرادىيېنت يوقىلىشى: رېلۇ/لىكى رېلۇ
  • ھېسابلاش جىددىي: رېلۇ
  • ئەڭ يۇقىرى نەتىجە: سۋىش/گېلۇ

    import tensorflow as tf
    from tensorflow import keras
    # مودېل قۇرۇش | Building a model

    keras.layers.Dense(128, activation='relu'), # يوشۇرۇن قاتلام
    keras.layers.Dense(64, activation='relu'), # يوشۇرۇن قاتلام
    keras.layers.Dense(32, activation='tanh'), # يوشۇرۇن قاتلام
    keras.layers.Dense(10, activation='softmax') # چىقىرىش قاتلىمى
    ])
