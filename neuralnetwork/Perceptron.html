نېرۋاتور 2-باب – Perceptron

Perceptron (پېرسېپترون) — نېرۋاتورنىڭ ئەڭ سادە، ئاساسىي بۆلىكى ھىسابلىنىدۇ. بۇ 1957-يىلى Frank Rosenblatt تەرىپىدىن تەقدىم قىلىنغان بولۇپ، بىر قەۋەتلىك سۈنئىي نېرۋا تورى (Single-layer Neural Network) دۇر.

Perceptron — چىزىقلىق ئايرىشچان مەسىلىلەرنى (Linearly Separable Problems) ھەل قىلىش ئۈچۈن ئىشلىتىلىدۇ. بۇ نېرۋاتورنىڭ تۇخۇمى دېيىش مۇمكىن.

Perceptron is the simplest and foundational unit of a neural network. Introduced by Frank Rosenblatt in 1957, it is a single-layer neural network.

It can only solve linearly separable problems — the "egg" from which deep learning hatched.
1. Perceptron نېمە؟
1. What is a Perceptron?

Perceptron — بىر ياكى بىر قانچە كىرگۈزگۈچ (Inputs)، ۋازىن (Weights)، چىقىرىش (Output) قانچىلىك بولغان ماتېماتىك مودېل. بۇ مودېلنىڭ چىقىرىشى — بىنار (Binary): 0 ياكى 1.

ماتېماتىك فورماتى: \( z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b \) \( \text{Output} = \begin{cases} 1 & \text{ئەگەر } z \geq 0 \\ 0 & \text{ئەگەر } z < 0 \end{cases} \)

A Perceptron takes inputs \(x_1, x_2, \dots\), multiplies them by weights \(w_1, w_2, \dots\), adds a bias \(b\), and applies a step function to produce a binary output (0 or 1).

Mathematical Form: \( z = \sum_{i=1}^{n} w_i x_i + b \) \( \text{Output} = \begin{cases} 1 & \text{if } z \geq 0 \\ 0 & \text{if } z < 0 \end{cases} \)

2. قانداق ئىشلەيدۇ؟
2. How Does It Work?
  1. كىرگۈزگۈچ مەلۇماتلارنى \(x_1, x_2, \dots\) قوبۇل قىلىدۇ.
  2. ھەر بىر كىرگۈزگۈچكە ۋازىن (Weight) بېكىتىلىدۇ.
  3. ۋازىن ۋە كىرگۈزگۈچنىڭ كۆپەيتمىسى + بىئاس (bias) ھېسابلىنىدۇ.
  4. نەتىجە 0 گە سېلىشتۇرۇلىدۇ — ئەگەر نۆل ياكى ئۇنىڭدىن چوڭ بولسا، 1؛ ئەگەر كىچىك بولسا، 0.
  5. ئۈگىنىش جەريانىدا، ئالگورىتم خاتالىق بويىچە ۋازىن ۋە بىئاسنى يېڭىلايدۇ.
  1. Receive inputs \(x_1, x_2, \dots\).
  2. Multiply each input by its weight \(w_i\).
  3. Compute the weighted sum + bias: \(z = \sum w_i x_i + b\).
  4. Apply step function: output = 1 if \(z \geq 0\), else 0.
  5. During training, update weights and bias based on prediction error.
3. مۇھىملىقى ۋە چەكلىمىسى
3. Importance and Limitations

مۇھىملىقى:

  • نېرۋاتورنىڭ ئاساسىي بۆلىكى.
  • چىزىقلىق كلاسسىفىكاتسىيە مەسىلىلىرىنى ھەل قىلىدۇ (مەسىلەن: AND، OR دېگەن مەنتىقىي دورا).
  • ئۈگىنىش ئۇسلۇبى سادە — Weight Update Rule بىلەن.

Importance:

  • Foundational building block of neural networks.
  • Solves linear classification (e.g., AND, OR logic gates).
  • Simple learning rule: adjust weights based on error.

چەكلىمىسى:

  • XOR مەسىلىسىنى ھەل قىلالمايدۇ — چۈنكى XOR چىزىقلىق ئايرىشچان ئەمەس.
  • پەقەت بىنار كلاسسىفىكاتسىيە (2 سىنىپ) غا ئىشلىتىشكە بولىدۇ.
  • چوڭ مەلۇمات ياكى مۇرەككەپ مۇناسىۋەتلەرگە ئىشلىتىشكە بولمايدۇ.

Limitations:

  • Cannot solve XOR — because it’s not linearly separable.
  • Only handles binary classification (two classes).
  • Fails on complex, non-linear patterns.

5. تارىخى ۋە ئەھمىيىتى
5. Historical Context

1957-يىلى Frank Rosenblatt «Perceptron» نى تەقدىم قىلغاندا، بۇ «ئىنسان مېڭىسىنى ماشىنا بىلەن قايتۇرۇش» دېگەن ئۈمىد بولۇپ قالغان. لېكىن 1969-يىلى Minsky ۋە Papert «Perceptrons» كىتابىدا، بۇنىڭ XOR مەسىلىسىنى ھەل قىلالمايدىغانلىقىنى ئىسپاتلىغان. بۇ نېرۋاتورنىڭ كېيىنكى 15 يىلغا يېقىن ۋاقىت «قىشقا چۈشۈشىگە» سەۋەب بولغان. 1980-يىللاردا Multi-layer Perceptron (MLP) ۋە Backpropagation ئىشلىتىلگەندىن كېيىن، Perceptron نىڭ ئۇزارتىلمىسى ئىلىپ بېرىلدى.

When Frank Rosenblatt introduced the Perceptron in 1957, it sparked hopes of "mimicking the human mind." But in 1969, Minsky & Papert proved in their book Perceptrons that it cannot solve XOR. This led to the first "AI winter" — a 15-year stagnation in neural network research. Only in the 1980s, with multi-layer networks and backpropagation, did neural networks revive.
