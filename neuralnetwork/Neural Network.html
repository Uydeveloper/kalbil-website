نېرۋاتور 1-باب – ئاساسىي ئۇچۇرلار

نېرۋاتور (Neural Network) — ئىنسان نېرۋا تىزىمىنى سۈنئىي ماشىنا ئارقىلىق تەقلىد قىلىش ئۇسلۇبى. بۇ ماشىنا ئۈگىنىش (Machine Learning) نىڭ ئەڭ قۇۋۋەتلىك، زامانىۋى تارماقى بولۇپ، تېكىست، رەسىم، ئۈن، ۋىديو كۆرۈنۈشىدەك مۇرەككەپ مەلۇماتلارنى تەھلىل قىلىش ئىقتىدارىغا ئىگە.

Neural Networks are computational models inspired by the human brain's nervous system. They are the backbone of modern Machine Learning and Deep Learning, capable of processing complex data like text, images, audio, and video.
1. نېرۋاتور نېمە؟
1. What is a Neural Network?

نېرۋاتور — نېرۋا سېللىرى (Neurons) دېگەن بىر قانچە ئۇچۇر بىرلىكلىرىدىن تۈزۈلگەن ماتېماتىك مودېل. ھەر بىر سېل — كىرگۈزگۈچ مەلۇماتنى قوبۇل قىلىپ، ئۇنى چىقىرىشقا ئايلاندۇرىدۇ. بۇ سېللار قەۋەتلەر (Layers) شەكلىدە تىزىلغان بولۇپ، مۇرەككەپ مۇناسىۋەتلەرنى ئۆگىنىدۇ.

A neural network is a mathematical model composed of interconnected artificial neurons. Each neuron receives input, processes it, and produces output. Neurons are organized into layers, enabling the network to learn complex patterns.

نېرۋاتورنىڭ سادە تۈزۈلمىسى:
كىرگۈزگۈچ قەۋىتى → يوشۇرۇن قەۋىتى(lar) → چىقىرىش قەۋىتى
Simple Neural Network Structure:
Input Layer → Hidden Layer(s) → Output Layer
2. نېرۋاتورنىڭ تارىخى
2. Historical Background
  • 1943-يىلى: Warren McCulloch ۋە Walter Pitts «نېرۋا سېلىنىڭ ماتېماتىك مودېلى» نى ئىلىپ چىقتى.
  • 1957-يىلى: Frank Rosenblatt «Perceptron» نى تەقدىم قىلدى — بۇ بىر قەۋەتلىك نېرۋاتور.
  • 1986-يىلى: Backpropagation (خەتەرگە قايتۇرۇش) ئۇسلۇبى قايتا تېرىلىپ، Multi-layer Networks يېڭىدىن ئۆسۈش باشلىدى.
  • 2010-يىللاردىن باشلاپ: Deep Learning، GPU لار، چوڭ مەلۇمات بىلەن بىرلەشتۈرۈلۈپ، نېرۋاتور زامانىۋى تەتقىقاتنىڭ تۆۋەندىكى تىزى بولۇپ قالدى.
  • 1943: McCulloch & Pitts proposed the first mathematical model of a neuron.
  • 1957: Rosenblatt introduced the Perceptron.
  • 1986: Backpropagation revived interest in multi-layer networks.
  • 2010s–present: With GPUs and big data, Deep Learning became the engine of AI.
3. نېرۋاتورنىڭ تۈزۈلمىسى
3. Structure of a Neural Network

ئاساسىي قەۋەتلەر:

  • كىرگۈزگۈچ قەۋىتى (Input Layer): مەلۇماتنى قوبۇل قىلىدۇ (مەسىلەن: رەسىم پىكسېللىرى).
  • يوشۇرۇن قەۋىتى (Hidden Layer): مۇرەككەپ ئالاھىدىلىكلەرنى ئۆگىنىدۇ.
  • چىقىرىش قەۋىتى (Output Layer): نەتىجىنى چىقىرىدۇ (مەسىلەن: "مۇشۇك" ياكى "ئىت").

Core Layers:

  • Input Layer: Receives raw data (e.g., image pixels).
  • Hidden Layer(s): Learns complex features through weighted connections.
  • Output Layer: Produces final prediction (e.g., "cat" or "dog").
        [x1]     [h1]     [o1]
        [x2] --> [h2] --> [o2]
        [x3]     [h3]     [o3]

Example: 3-input → 3-hidden → 3-output

4. نېرۋاتور قانداق ئىشلەيدۇ؟
4. How Does It Work?
  1. كىرگۈزگۈچ مەلۇمات ھەر بىر نېرۋا سېلىغا يېتىپ كېلىدۇ.
  2. ھەر بىر سېل ۋازىن (Weight) ۋە بىئاس (Bias) بىلەن مەلۇماتنى كۆپەيتىپ، قوشۇپ چىقىرىش ئالىدۇ.
  3. چىقىرىش ئاكتىۋاتسىيە فۇنكسىيىسى (Activation Function) دىن ئۆتىدۇ (مەسىلەن: ReLU, Sigmoid).
  4. بۇ جەريان ھەر بىر قەۋەتتە تەكرارلىنىدۇ.
  5. ئۈگىنىش جەريانىدا، مودېل خاتالىق (Loss) نى كىچىكلىتىش ئۈچۈن ۋازىن ۋە بىئاسنى Backpropagation ئارقىلىق يېڭىلايدۇ.
  1. Input data flows to the first layer of neurons.
  2. Each neuron computes: output = activation(weight * input + bias).
  3. This passes through multiple layers.
  4. During training, the model uses backpropagation to adjust weights and minimize loss.
5. ماشىنا ئۈگىنىش، Deep Learning ۋە نېرۋاتور
5. Relationship: ML, DL, and Neural Networks
تۈر تەسۋىر Type Description
ماشىنا ئۈگىنىش (ML) ماشىنىنىڭ مەلۇماتتىن ئۆزى ئۈگىنىش ئۇسۇلى Machine Learning (ML) Algorithms that learn from data without explicit programming.
نېرۋاتور (ANN) ML نىڭ بىر تارماقى، نېرۋا سېلىغا ئوخشاش Artificial Neural Network (ANN) A subset of ML inspired by the brain.
Deep Learning (DL) 2 ياكى ئۇندىن ئارتۇق يوشۇرۇن قەۋەتلىك نېرۋاتور Deep Learning (DL) Neural networks with **many hidden layers**.
6. ئىشلىتىش دائىرىسى
6. Applications
  • رەسىم تانىش (مۇشۇك/ئىت، چىقىرىش خەتتىكى خەت تانىش).
  • ئاۋاز تانىش (Siri، Google Assistant).
  • تېكىست تەھلىلى (ئۇيغۇرچە ماشىنا تەرجىمىسى).
  • تىبابەت (رەڭگەك، MRI رەسىمىدىن كىسىلنى بايان قىلىش).
  • ئۆي سەۋەتكۈچ مەھسۇلاتلىرى (مەسىلەن: Tesla نىڭ ئاپتوماتىك قوزغىلىشى).
  • Image recognition (cat/dog, handwritten digit recognition).
  • Speech recognition (Siri, Alexa).
  • Text analysis (Uyghur machine translation).
  • Healthcare (tumor detection from MRI scans).
  • Autonomous vehicles (Tesla Autopilot).
7. ئالاھىدىلىكى ۋە كەمچىلىكى
7. Advantages and Disadvantages

ئالاھىدىلىكى:

  • مۇرەككەپ، غىيرمۇرەككەپ مۇناسىۋەتلەرنى ئۆگىنىدۇ.
  • تېكىست، رەسىم، ئۈن قاتارلىق ھەممە مەلۇمات تۈرى بىلەن ئىشلەيدۇ.
  • زامانىۋى AI نىڭ ئاساسى.

Advantages:

  • Learns complex, non-linear patterns.
  • Works with all data types (text, image, audio).
  • Foundation of modern AI.

كەمچىلىكى:

  • چوڭ مەلۇمات ۋە كومپيۇتېر قۇۋۋىتى تەلەپ قىلىدۇ.
  • «قارا كۈتكۈچ» شەكلىدە — نەمە ئۈچۈن شۇنداق باھالىغانىنى تۈسۈنىش قىيىن.
  • ئاشۇرۇپ ئۈگىنىش (Overfitting) خەۋىپى بار.

Disadvantages:

  • Requires large datasets and computational power.
  • Acts as a "black box" — hard to interpret decisions.
  • Prone to overfitting without regularization.
