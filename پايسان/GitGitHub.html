Team Collaboration نىڭ 3 مودېلى:

1. Shared Repo مودېلى

مۇناسىۋىتى: ھەممە ئادەم بىر repo دا ئىشلەيدۇ

مەسىلىسى: كۆپ خەتەر، ئادەمنىڭ خاتا كودى ھەممىگە تەسىر قىلىدۇ

2. Branch Workflow

مۇناسىۋىتى: ھەر بىر ئادەم ئۆزىنىڭ branch دا ئىشلەيدۇ

مەسىلىسى: ھەممە ئادەم ھەممە كودنى كۆرەلەيدۇ

3. Private Fork System

مۇناسىۋىتى: ھەر بىر ئادەم ئۆزىنىڭ private repo سىدا ئىشلەيدۇ

ئارتۇقچىلىقى: باشقىلارنىڭ كودىنى كۆرەلمەيدۇ، پەقەت Manager كۆرەلەيدۇ

5. "Manager-only visibility" - Private Fork System

بۇ مودېلنىڭ 4 قەدەملىك قۇرۇلۇشى:

1. Main Repo نى Private قىلىش

GitHub → Settings → General → Private

Visibility: 🔒 Private ✓ Only you and people you give access

2. Forking نى قوزغىتىش

Settings → General → Features

✓ Allow forking ✓ Private forks are private

3. Collaborator قوشۇش

Settings → Collaborators → Add people

Role: Write ✓ Can push to repository ✓ Can create forks ✗ Cannot merge to main

4. Pull Request قوبۇل قىلىش

Manager Pull Request نى تەكشۈرۈپ، merge قىلىدۇ

✓ Review code ✓ Add comments ✓ Approve and merge

ئەملىي Simulation:

# User1 (Developer)
$ git clone https://github.com/user1/projectA-fork.git
$ git checkout -b feature-login
$ echo "// Login function" > login.js
$ git add .
$ git commit -m "Login feature added"
$ git push origin feature-login

# GitHub دا Pull Request قىلىدۇ
# Manager Pull Request نى كۆرۈپ، تەكشۈرىدۇ

# Manager (سەن)
$ git checkout main
$ git pull origin main
$ # PR نى تەكشۈرۈپ، approve قىلىدۇ
$ git merge feature-login
$ git push origin main

6. تولۇق Simulation: 3 ئەزا بىلەن تىم خىزمىتى

# ============ SIMULATION START ============
# Project: Todo List Application
# Team: Manager, Developer1, Developer2

👑 Manager creates main repository
$ git init todo-app
$ echo "# Todo App" > README.md
$ git add . && git commit -m "Initial commit"

👨‍💻 Developer1 forks the repository
$ # Creates private fork: todo-app-dev1
$ git clone https://github.com/dev1/todo-app-dev1.git
$ git checkout -b add-dark-mode

👩‍💻 Developer2 also forks the repository
$ # Creates private fork: todo-app-dev2
$ git clone https://github.com/dev2/todo-app-dev2.git
$ git checkout -b add-notifications

⏳ Both developers work independently...
👨‍💻 Dev1 creates dark mode feature
👨‍💻 Dev1 git add . && git commit -m "Added dark mode"
👨‍💻 Dev1 Creates Pull Request to main repo
👩‍💻 Dev2 Creates notification system
👩‍💻 Dev2 git add . && git commit -m "Added notifications"
👩‍💻 Dev2 Creates Pull Request to main repo
🔍 Manager reviews both PRs
✅ Manager approves and merges dark mode
✅ Manager approves and merges notifications
🎉 RESULT Main repo now has both features
👁️ VISIBILITY Dev1 cannot see Dev2's code, Dev2 cannot see Dev1's code
👑 MANAGER Can see all code from both developers

7. Code Review قانداق قىلىنىدۇ؟

1. Pull Request دا چۈشەندۈرۈش

نېمە ئۆزگەرتىلگەنلىكىنى، نېمە ئۈچۈن ئۆزگەرتىلگەنلىكىنى چۈشەندۈرۈش

Title: Add user authentication Description: - Added login form - Added validation - Added error handling

2. Inline Comments

كودنىڭ ئايرىم بۆلەكلىرىگە باھا بېرىش

// Consider using const instead of let const user = getCurrentUser(); // Good: Error handling added try { await login(user); } catch (error) { showError(error.message); }

3. Required Reviews

تەڭشەش: Pull Request merge قىلىشتىن ئىلگىرى review تەلەپ قىلىش

Settings → Branches → Branch protection rules: ✓ Require pull request reviews ✓ Required approving reviews: 1 ✓ Dismiss stale reviews ✓ Require review from Code Owners
