TensorFlow نېمە؟

What is TensorFlow?

TensorFlow - گوگۇل تەرىپىدىن ياسالغان ئوچۇق مەنبەلىك ماشىنا ئۆگىنىش كۈتۇپخانىسى. ئۇ سانلىق مەلۇماتنى ھېسابلاش ئۈچۈن گراف قۇرۇلمىسىنى ئىشلىتىدۇ.

TensorFlow is an open-source machine learning library developed by Google. It uses a graph structure for numerical computation.

مۇھىم ئالاھىدىلىكلەر

Key Features

  • ئىشلەتكۈچىگە قۇلاي: يۇقىرى سەۋىيەلىك API لار
  • User-friendly: High-level APIs

  • Flexibility: Works on CPU, GPU, TPU, etc.
  • كەڭ قوللىنىش: ئىلمىي تەتقىقاتتىن ئەمەلىي قوللىنىشقىچە
  • Wide adoption: From scientific research to practical applications
  • ھەمكارلىشىش: TensorFlow Hub ۋە Model Garden
  • Collaboration: TensorFlow Hub and Model Garden

Basic Concepts: Tensors and Fundamental Operations

1. تەنسورلار (Tensors)

1. Tensors

تەنسورلار - TensorFlow دىكى ئاساسىي سانلىق مەلۇمات قۇرۇلمىسى. ئۇلار 0-D دىن N-D گىچە بولغان مەلۇماتلارنى كۆرسىتەلەيدۇ.

Tensors are the fundamental data structures in TensorFlow. They can represent data from 0-D to N-D.

Python 
import tensorflow as tf
import numpy as np

# ھەر خىل تەنسورلارنى ياساش | Creating different types of tensors

# 0-D تەنسور (سكالار) | 0-D Tensor (Scalar)
scalar = tf.constant(5)
print("0-D تەنسور:", scalar)

# 1-D تەنسور (يۆنىلىش) | 1-D Tensor (Vector)
vector = tf.constant([1, 2, 3, 4, 5])
print("1-D تەنسور:", vector)

# 2-D تەنسور (ماترىتسا) | 2-D Tensor (Matrix)
matrix = tf.constant([[1, 2, 3], [4, 5, 6]])
print("2-D تەنسور:", matrix)

# 3-D تەنسور | 3-D Tensor
tensor_3d = tf.constant([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print("3-D تەنسور:", tensor_3d)

2. Tensor Operations

Python 
# تەنسور ئەمەلىيەتلىرى | Tensor operations

# قوشۇش | Addition
a = tf.constant([[1, 2], [3, 4]])
b = tf.constant([[5, 6], [7, 8]])
add_result = tf.add(a, b)
print("قوشۇش:", add_result)

# كۆپەيتىش | Multiplication
mul_result = tf.multiply(a, b)
print("كۆپەيتىش:", mul_result)

# ماترىتسا كۆپەيتىش | Matrix multiplication
matmul_result = tf.matmul(a, b)
print("ماترىتسا كۆپەيتىش:", matmul_result)

# تەنسور شەكلىنى ئۆزگەرتىش | Reshaping tensors
reshaped = tf.reshape(a, [4, 1])
print("شەكلى ئۆزگەرتىلگەن:", reshaped)

Model Building: With Keras API

1. Sequential مودېل قۇرۇش

1. Sequential Model Building

Python 
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense, Flatten

# Sequential مودېل قۇرۇش | Sequential model building
model = Sequential([
    Flatten(input_shape=(28, 28)),  # 28x28 رەسىمنى 1D گە ئايلاندۇرۇش | Flatten 28x28 image to 1D
    Dense(128, activation='relu'),   # 128 نېرونلۇق يوشۇرۇن قاتلام | 128 neuron hidden layer
    Dense(64, activation='relu'),    # 64 نېرونلۇق يوشۇرۇن قاتلام | 64 neuron hidden layer
    Dense(10, activation='softmax')  # 10 سىنىپلۇق چىقىش قاتلامى | 10 class output layer
])

# مودېل سەپلىمىسى | Model summary
model.summary()

Advanced Topics and Techniques

1. Transfer Learning (يۆتكەش ئۆگىنىش)

1. Transfer Learning

Python 
from tensorflow.keras.applications import VGG16
from tensorflow.keras import layers, Model

# ئالدىن مەشىق قىلىنغان VGG16 مودېلىنى يۈكلەش | Load pre-trained VGG16 model
base_model = VGG16(
    weights='imagenet',  # ImageNet دىكى ئالدىن مەشىق قىلىنغان ئېغىرلىقلار | Pre-trained weights from ImageNet
    include_top=False,   # ئەڭ ئۈستىدىكى تەسۋىرلەش قاتلامىنى ئۆچۈرۈش | Remove the top classification layer
    input_shape=(224, 224, 3)
)

# ئاساسىي مودېلنىڭ پارامېترلىرى مەشىق قىلىنمايدۇ | Base model parameters are not trainable
base_model.trainable = False

# يېڭى تەسۋىرلەش قاتلاملىرىنى قوشۇش | Add new classification layers
x = base_model.output
x = layers.GlobalAveragePooling2D()(x)
x = layers.Dense(1024, activation='relu')(x)
predictions = layers.Dense(10, activation='softmax')(x)  # 10 سىنىپ | 10 classes

# يېڭى مودېلنى قۇرۇش | Create new model
model = Model(inputs=base_model.input, outputs=predictions)

# مودېلنى كومپىلىيەش | Compile model
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

1. رەسىم تەسۋىرلەش

1. Image Classification

Python 
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras import layers, Model

# سانلىق مەلۇمات كۆپەيتىش | Data augmentation
datagen = ImageDataGenerator(
    rescale=1./255,
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True,
    validation_split=0.2  # 20% نى دەلىللەش ئۈچۈن ئىشلىتىدۇ | Use 20% for validation
)

# سانلىق مەلۇمات يۈكلەش | Load data
train_generator = datagen.flow_from_directory(
    'data/train',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical',
    subset='training'
)

val_generator = datagen.flow_from_directory(
    'data/train',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical',
    subset='validation'
)

# مودېل قۇرۇش | Model building
base_model = MobileNetV2(weights='imagenet', include_top=False, input_shape=(224, 224, 3))
base_model.trainable = False

model = Model([
    base_model,
    layers.GlobalAveragePooling2D(),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.5),
    layers.Dense(train_generator.num_classes, activation='softmax')
])

model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# مەشىقلەش | Training
history = model.fit(
    train_generator,
    steps_per_epoch=train_generator.samples // train_generator.batch_size,
    epochs=10,
    validation_data=val_generator,
    validation_steps=val_generator.samples // val_generator.batch_size
)
