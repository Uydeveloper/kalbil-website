دەرس بايانى

بۇ بابتا Python نىڭ ئاساسىي ئۇچۇرلىرىنى ئۆگىنىمىز. ئورنىتىش، Hello World كودى، كود مۇھىتى، Python نىڭ تىپلىرى، ئۆزگەرگۈچىلەر، سانلار، string، if/else شەرتلىك بايانلارغا تونۇشۇش.

Python ئورنىتىش

Python نى Python.org دىن چۈشۈرۈپ ئورنىتىشقا بولىدۇ. ئورنىتىشتىن كېيىن كوماندىلىق سۈرۈشتۈرۈش (Command Prompt / Terminal) ئارقىلىق تەستىقلاش:

python --version

Hello World - Python نى ئىشلىتىش

Python دا ئاۋۋال پروگراممىڭىزنى يازىپ كۆرۈش:

print("Hello, World!")

ئاساسىي سانلىق تىپلار

int - پۈتۈن سانلار

10, -5, 0

float - يۈكسەك تىپلىك سانلار

3.14, -0.5

str - تېكست

"Hello"

bool - ئىككىلىك قىممەت

True, False

ئۆزگەرگۈچىلەر ۋە سانلار

ئۆزگەرگۈچىلەرنى ئېلان قىلىش ۋە سانلار بىلەن ئامەل قىلىش:

x = 10 # int
y = 5 # int
sum = x + y # جەمئىيى
print("جەمئىي:", sum)

if/else شەرتلىك بايانلار

شەرت بويىچە پروگرامما ئىجرا قىلىش:

age = 18
if age >= 18:
    print("سىز چوڭسىز")
else:
    print("سىز ياشسىز")

مەسىل

ئىككى ساننى سېلىشتۇرۇش:

a = 10
b = 20

if a > b:
    print("a چوڭ")
elif a < b:
    print("b چوڭ")
else:
    print("a ۋە b تەڭ")

چۈشەندۈرۈش

بۇ بابتا Python نىڭ ئاساسىي تىپلىرى، ئۆزگەرگۈچىلەر، سانلار بىلەن ئامەل قىلىش، شەرتلىك بايانلار (if/else) ۋە سىستېما ئىشلىتىش ھەققىدە تونۇشۇشقا بولىدۇ. ئالدىنقى مەسىللەر Python دا سانلار بىلەن ئاسانچە ھېسابلاش ۋە شەرت بويىچە قارار چىقىرىش ئىشلەتكىلى بولىدىغانلىقىنى كۆرسىتىدۇ.
