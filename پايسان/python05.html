پايسان 5-باب - فۇنكسىيە ۋە مودۇل

دەرس بايانى

بۇ بابتا Python دا فۇنكسىيە قۇرۇش، ئۇنى چاقىرىش ۋە مودۇللارنى ئىشلىتىشنى ئۆگىنىمىز. فۇنكسىيە پروگراممىڭىزنى قۇراللار بىلەن بۆلۈش، قايتىدىن ئىشلىتىشكە قولايلىق بولىدۇ.

فۇنكسىيە قۇرۇش

# فۇنكسىيە ئېلان قىلىش
def greet(name):
    print("ياخشىمۇسىز, " + name + "!")

# فۇنكسىيەنى چاقىرىش
greet("قاۋۇلجان")

قايتۇرۇش قىممىتى

def add(a, b):
    return a + b

sum = add(5, 7)
print("جەمئىي:", sum)

مودۇل ئىشلىتىش

Python نىڭ بىرىنچى قوشۇمچە قۇراللىرىنى ئىشلىتىپ، مودۇلدىن پايدىلىنىش:

# math مودۇلنى چاقىرىش
import math

print("π قىممىتى:", math.pi)
print("كىچىك سان:", math.sqrt(16))

from ... import ...

# پەقەت sqrt فۇنكسىيەنى import قىلىش
from math import sqrt

print("كىچىك سان:", sqrt(25))

مەسىل

ئىككى ساننى قوشۇش ۋە ھەرىكىتىنى باشقۇرۇش فۇنكسىيەسى:

def compare_numbers(a, b):
    if a > b:
        return "a چوڭ"
    elif a < b:
        return "b چوڭ"
    else:
        return "a ۋە b تەڭ"

result = compare_numbers(12, 15)
print(result)

چۈشەندۈرۈش

بۇ بابتا Python دا فۇنكسىيە قۇرۇش، قايتۇرۇش قىممىتى ۋە مودۇللارنى ئىشلىتىشنى چۈشەندۇق. بۇ ئۇسۇل پروگراممىڭىزنى بۆلەك بۆلەك قىلىپ ئىشلىتىش، قايتىدىن ئىشلىتىش ۋە كۆپ فۇنكسىيەلىك كودلارنى باشقۇرۇشقا قولايلىق.
