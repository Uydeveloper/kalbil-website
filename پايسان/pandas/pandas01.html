دەرس بايانى

بۇ بابتا پەنداسنىڭ ئاساسىي تۇشۇنچىلىرى، مەلۇماتنى قانداق ئوقۇش، CSV، Excel فورماتلىرىنى قانداق ئوقۇش ھەققىدە ئۆگىنىمىز.

پەنداسنى ئورنىتىش

پەنداسنى ئورنىتىش ئۈچۈن تۆۋەندىكى كوماندىنى ئىشلىتىڭ:

pip install pandas

CSV مەلۇماتنى ئوقۇش

CSV (Comma-Separated Values) فورماتلىق مەلۇماتنى ئوقۇش:

import pandas as pd

# CSV مەلۇماتنى ئوقۇش
df = pd.read_csv('data.csv')

# مەلۇماتنى كۆرۈش
print(df.head())

Excel مەلۇماتنى ئوقۇش

Excel فورماتلىق مەلۇماتنى ئوقۇش:

import pandas as pd

# Excel مەلۇماتنى ئوقۇش
df = pd.read_excel('data.xlsx')

# مەلۇماتنى كۆرۈش
print(df.head())

مەلۇماتنىڭ ئاساسىي ئۇچۇرلىرى

مەلۇماتنىڭ شەكلى، سۈتۇنلار، قۇرلارنى كۆرۈش:

# مەلۇماتنىڭ شەكلى (قۇر × سۈتۇن)
print("Shape:", df.shape)

# سۈتۇنلارنى كۆرۈش
print("Columns:", df.columns.tolist())

# مەلۇماتنىڭ تىپى
print("Data types:")
print(df.dtypes)

چۈشەندۈرۈش

بۇ بابتا پەنداسنى ئورنىتىش، CSV ۋە Excel فورماتلىق مەلۇماتنى ئوقۇش، مەلۇماتنىڭ ئاساسىي ئۇچۇرلىرىنى كۆرۈشنى ئۆگىنىدۇق. بۇ پەنداس بىلەن مەلۇمات تەھلىلىنى باشلاشنىڭ ئەڭ مۇھىم قەدەمى.
