پەنداس 2-باب - DataFrame ۋە Series

دەرس بايانى

بۇ بابتا پەنداسنىڭ ئەڭ مۇھىم ئوبيېكتلىرى بولغان DataFrame ۋە Series نىڭ تۈزۈلۈشى، ئىشلىتىلىشى ھەققىدە ئۆگىنىمىز.

DataFrame نېمە؟

DataFrame - جەدۋەل شەكلىدىكى مەلۇمات بولۇپ، سۈتۇنلار ۋە قۇرلاردىن تۈزۈلگەن.

import pandas as pd

# DataFrame قۇرۇش
data = {
    'ئىسمى': ['ئالى', 'ۋالى', 'سانى'],
    'ياشى': [25, 30, 35],
    'شەھەر': ['ئۈرۈمچى', 'قەشقەر', 'خوتەن']
}
df = pd.DataFrame(data)
print(df)

Series نېمە؟

Series - بىر سۈتۇنلۇق مەلۇمات بولۇپ، ئىندېكس ۋە قىممەتلەردىن تۈزۈلگەن.

import pandas as pd

# Series قۇرۇش
s = pd.Series([10, 20, 30, 40], index=['a', 'b', 'c', 'd'])
print(s)

مەلۇماتنى تاللاش

سۈتۇن، قۇر، شەرت بويىچە مەلۇماتنى تاللاش:

# سۈتۇن تاللاش
print(df['ئىسمى'])

# قۇر تاللاش
print(df.iloc[0])

# شەرت بويىچە تاللاش
print(df[df['ياشى'] > 25])

چۈشەندۈرۈش

بۇ بابتا DataFrame ۋە Series نىڭ تۈزۈلۈشى، مەلۇماتنى تاللاش ئۇسۇللىرىنى ئۆگىنىدۇق. بۇ پەنداس بىلەن مەلۇمات تەھلىلىنىڭ ئەڭ مۇھىم ئاساسى.
