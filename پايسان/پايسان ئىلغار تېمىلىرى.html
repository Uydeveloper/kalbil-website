لىستىلەر (Lists)

Lists

لىستىلەر نېمە؟

What are Lists?

لىستىلەر - تەرتىپلىك مەلۇمات توپلىمى. ئۇلار كۆپ مەلۇماتنى بىر ئۆزگەرگۈچىدە ساقلايدۇ.

Lists are ordered collections of data. They store multiple data in one variable.

لىستا قۇرۇلماسى

List Structure

تەرتىپلىك مەلۇمات

Ordered Data

لىستا ئالاھىدىلىكلىرى:

List Features:

  • تەرتىپلىك (ئىندېكىس بار)
  • Ordered (has index)
  • ئۆزگەرتىش مۇمكىن (Mutable)
  • Changeable (Mutable)
  • كۆپلىگەن مەلۇمات تىپلىرىنى ساقلايدۇ
  • Stores multiple data types
  • قايتا-قايتا مەلۇمات بولۇشى مۇمكىن
  • Can have duplicate values

لىستىلەر بىلەن ئىشلەش

Working with Lists

Python 
# لىستا ياساش | Creating lists
مېۋىلەر = ["ئالما", "ئانار", "ئۆرۈك", "شاپتۇل"]
سانلار = [1, 2, 3, 4, 5]
ارىلاشما = ["ئالما", 5, True, 3.14]

# لىستىدىن مەلۇمات ئېلىش | Accessing list elements
print("بىرىنچى مېۋە:", مېۋىلەر[0])    # ئالما
print("ئاخىرقى مېۋە:", مېۋىلەر[-1])  # شاپتۇل

# لىستىغا مەلۇمات قوشۇش | Adding to list
مېۋىلەر.append("ئۈزۈم")        # ئاخىرىغا قوشۇش
مېۋىلەر.insert(1, "بانان")    # بەلگىلەنگەن ئورۇنغا قوشۇش

# لىستىدىن مەلۇمات چىقىرىش | Removing from list
مېۋىلەر.remove("ئانار")       # بەلگىلەنگەن قىممەتنى چىقىرىش
چىقىرىلغان = مېۋىلەر.pop(2)     # بەلگىلەنگەن ئىندېكىستىكىنى چىقىرىش

print("يېڭى لىستا:", مېۋىلەر)

لىستا ئەمەلىيەتلىرى

List Operations

Python 
# لىستا ئەمەلىيەتلىرى | List operations
لىستا1 = [1, 2, 3]
لىستا2 = [4, 5, 6]

# لىستىلارنى بىرلەشتۈرۈش | Combining lists
بىرلەشمە = لىستا1 + لىستا2
print("بىرلەشمە:", بىرلەشمە)  # [1, 2, 3, 4, 5, 6]

# لىستىنى كۆپەيتىش | Repeating lists
كۆپەيتىلگەن = لىستا1 * 3
print("كۆپەيتىلگەن:", كۆپەيتىلگەن)  # [1, 2, 3, 1, 2, 3, 1, 2, 3]

# لىستىنى تەرتىپكە سېلىش | Sorting lists
سانلار = [3, 1, 4, 2]
سانلار.sort()
print("تەرتىپكە سېلىنغان:", سانلار)  # [1, 2, 3, 4]

# لىستا ئۇزۇنلىقى | List length
print("لىستا ئۇزۇنلىقى:", len(لىستا1))  # 3

لۇغەتلەر (Dictionaries)

Dictionaries

لۇغەتلەر نېمە؟

What are Dictionaries?

لۇغەتلەر - كۇنۇپكا-قىممەت جۈپلىرىدىن تەركىب تاپقان مەلۇمات قۇرۇلمىسى. ئۇلار تەرتىپسىز.

Dictionaries are data structures consisting of key-value pairs. They are unordered.

لۇغەت قۇرۇلمىسى

Dictionary Structure

كۇنۇپكا → قىممەت

Key → Value

لۇغەت ئالاھىدىلىكلىرى:

Dictionary Features:

  • تەرتىپسىز (ئىندېكىس يوق)
  • Unordered (no index)
  • ئۆزگەرتىش مۇمكىن (Mutable)
  • Changeable (Mutable)
  • كۇنۇپكىلار تەكرارلانماسلىقى كېرەك
  • Keys must be unique
  • كۇنۇپكىلار ئۆزگەرمەس تىپتا بولۇشى كېرەك
  • Keys must be immutable types

لۇغەتلەر بىلەن ئىشلەش

Working with Dictionaries

Python 
# لۇغەت ياساش | Creating dictionaries
تەلەپپۇز = {
    "ئىسمى": "ئەخمەت",
    "يېشى": 25,
    "شەھەر": "ئۈرۈمچى",
    "كەسپى": "پروگراممىست"
}

# لۇغەتتىن مەلۇمات ئېلىش | Accessing dictionary elements
print("ئىسمى:", تەلەپپۇز["ئىسمى"])
print("يېشى:", تەلەپپۇز.get("يېشى"))

# لۇغەتكە مەلۇمات قوشۇش/ئۆزگەرتىش | Adding/changing to dictionary
تەلەپپۇز["تېلېفون"] = "123-456-7890"  # يېڭى كۇنۇپكا قوشۇش
تەلەپپۇز["يېشى"] = 26                # مەۋجۇت كۇنۇپكىنى ئۆزگەرتىش

# لۇغەتتىن مەلۇمات چىقىرىش | Removing from dictionary
چىقىرىلغان = تەلەپپۇز.pop("كەسپى")      # بەلگىلەنگەن كۇنۇپكىنى چىقىرىش
del تەلەپپۇز["شەھەر"]                 # باشقا ئۇسۇل بىلەن چىقىرىش

print("يېڭى لۇغەت:", تەلەپپۇز)

لۇغەت ئەمەلىيەتلىرى

Dictionary Operations

Python 
# لۇغەت ئەمەلىيەتلىرى | Dictionary operations
تەلەپپۇز = {"ئىسمى": "ئائىشە", "يېشى": 22, "شەھەر": "قەشقەر"}

# بارلىق كۇنۇپكىلارنى ئېلىش | Getting all keys
كۇنۇپكىلار = تەلەپپۇز.keys()
print("كۇنۇپكىلار:", list(كۇنۇپكىلار))

# بارلىق قىممەتلەرنى ئېلىش | Getting all values
قىممەتلەر = تەلەپپۇز.values()
print("قىممەتلەر:", list(قىممەتلەر))

# بارلىق كۇنۇپكا-قىممەت جۈپلىرىنى ئېلىش | Getting all key-value pairs
جۈپلەر = تەلەپپۇز.items()
print("جۈپلەر:", list(جۈپلەر))

# لۇغەت ئۇزۇنلىقى | Dictionary length
print("لۇغەت ئۇزۇنلىقى:", len(تەلەپپۇز))

# لۇغەتتىكى كۇنۇپكا بار-يوقلۇقىنى تەكشۈرۈش | Checking if key exists
if "يېشى" in تەلەپپۇز:
    print("يېشى كۇنۇپكىسى بار")

توپېللار (Tuples)

Tuples

توپېللار نېمە؟

What are Tuples?

توپېللار - تەرتىپلىك مەلۇمات توپلىمى، ئەمما ئۇلار ئۆزگەرتىشكە بولمايدۇ (Immutable).

Tuples are ordered collections of data, but they cannot be changed (Immutable).

توپېل قۇرۇلمىسى

Tuple Structure

ئۆزگەرمەس مەلۇمات

Immutable Data

توپېل ئالاھىدىلىكلىرى:

Tuple Features:

  • تەرتىپلىك (ئىندېكىس بار)
  • Ordered (has index)
  • ئۆزگەرتىشكە بولمايدۇ (Immutable)
  • Unchangeable (Immutable)
  • لىستىلاردىن تېز
  • Faster than lists
  • قايتا-قايتا مەلۇمات بولۇشى مۇمكىن
  • Can have duplicate values

توپېللار بىلەن ئىشلەش

Working with Tuples

Python 
# توپېل ياساش | Creating tuples
توپېل1 = ("ئالما", "ئانار", "ئۆرۈك")
توپېل2 = "قىزىل", "يېشىل", "كۆك"  # تىرناقسىزمۇ بولىدۇ
بىرلەنگەن = (1,)  # بىر ئېلېمېنتلىق توپېل (پەش بىلەن ئاخىرلاشقان)

# توپېلدىن مەلۇمات ئېلىش | Accessing tuple elements
print("بىرىنچى مېۋە:", توپېل1[0])    # ئالما
print("ئاخىرقى مېۋە:", توپېل1[-1])  # ئۆرۈك

# توپېل ئەمەلىيەتلىرى | Tuple operations
# توپېللارنى بىرلەشتۈرۈش | Combining tuples
يېڭى_توپېل = توپېل1 + توپېل2
print("بىرلەشمە توپېل:", يېڭى_توپېل)

# توپېلنى كۆپەيتىش | Repeating tuples
كۆپەيتىلگەن = توپېل1 * 2
print("كۆپەيتىلگەن:", كۆپەيتىلگەن)

# توپېل ئۇزۇنلىقى | Tuple length
print("توپېل ئۇزۇنلىقى:", len(توپېل1))

توپېل ۋە لىستا پەرقى

Tuple vs List Difference

لىستىلەر

Lists

ئۆزگەرتىش مۇمكىن (Mutable)

Changeable (Mutable)

  • ئېلېمېنت قوشۇش مۇمكىن
  • Can add elements
  • ئېلېمېنت چىقىرىش مۇمكىن
  • Can remove elements
  • ئېلېمېنت ئۆزگەرتىش مۇمكىن
  • Can modify elements
  • [] تىرناقلاردا
  • Uses [] brackets

توپېللار

Tuples

ئۆزگەرتىشكە بولمايدۇ (Immutable)

Unchangeable (Immutable)

  • ئېلېمېنت قوشۇشقا بولمايدۇ
  • Cannot add elements
  • ئېلېمېنت چىقىرىشقا بولمايدۇ
  • Cannot remove elements
  • ئېلېمېنت ئۆزگەرتىشقا بولمايدۇ
  • Cannot modify elements
  • () تىرناقلاردا
  • Uses () brackets

سېتلار (Sets)

Sets

سېتلار نېمە؟

What are Sets?

سېتلار - تەرتىپسىز مەلۇمات توپلىمى. ئۇلاردا قايتا-قايتا مەلۇمات بولۇشى مۇمكىن ئەمەس.

Sets are unordered collections of data. They cannot have duplicate values.

سېت قۇرۇلمىسى

Set Structure

تەكرارلانمىغان مەلۇمات

Unique Data

سېت ئالاھىدىلىكلىرى:

Set Features:

  • تەرتىپسىز (ئىندېكىس يوق)
  • Unordered (no index)
  • ئۆزگەرتىش مۇمكىن (Mutable)
  • Changeable (Mutable)
  • قايتا-قايتا مەلۇمات بولۇشى مۇمكىن ئەمەس
  • Cannot have duplicate values
  • مەلۇمات تەكشۈرۈش تېز
  • Fast membership testing

سېتلار بىلەن ئىشلەش

Working with Sets

Python 
# سېت ياساش | Creating sets
سېت1 = {"ئالما", "ئانار", "ئۆرۈك"}
سېت2 = set(["ئالما", "بانان", "شاپتۇل"])  # set() فۇنكسىيەسى بىلەنمۇ

# سېتقا مەلۇمات قوشۇش | Adding to set
سېت1.add("ئۈزۈم")
سېت1.update(["ئەنجۈر", "قاتاق"])  # كۆپ مەلۇمات قوشۇش

# سېتتىن مەلۇمات چىقىرىش | Removing from set
سېت1.remove("ئانار")      # مەلۇمات بولمىسا خاتالىق چىقىرىدۇ
سېت1.discard("بانان")    # مەلۇمات بولمىسا خاتالىق چىقىرمایدۇ
چىقىرىلغان = سېت1.pop()   # بىر ئېلېمېنتنى چىقىرىدۇ (تەسادىپىي)

print("يېڭى سېت:", سېت1)

سېت ئەمەلىيەتلىرى

Set Operations

Python 
# سېت ئەمەلىيەتلىرى | Set operations
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# بىرلەشمە (Union) - ھەر ئىككى سېتتىكى بارلىق مەلۇمات
بىرلەشمە = A | B
print("بىرلەشمە:", بىرلەشمە)  # {1, 2, 3, 4, 5, 6, 7, 8}

# ئورتاق (Intersection) - ھەر ئىككى سېتتا بار مەلۇمات
ئورتاق = A & B
print("ئورتاق:", ئورتاق)  # {4, 5}

# پەرق (Difference) - A دىكى ئەمما B دىكى ئەمەس مەلۇمات
پەرق = A - B
print("پەرق:", پەرق)  # {1, 2, 3}

# سېت ئۇزۇنلىقى | Set length
print("سېت ئۇزۇنلىقى:", len(A))

# سېتتا مەلۇمات بار-يوقلۇقىنى تەكشۈرۈش | Checking membership
if 3 in A:
    print("3 سېتتا بار")

فايل بىلەن ئىشلەش

File Handling

فايل بىلەن ئىشلەش نېمە؟

What is File Handling?

فايل بىلەن ئىشلەش - پروگراممىلارنىڭ فايللارنى ئوقۇش، يېزىش ۋە ئۆزگەرتىش قابىلىيىتى.

File handling is the ability of programs to read, write, and modify files.

فايل ئىشلەش قۇرۇلمىسى

File Handling Structure

ئېچىش → ئىشلەش → تاقاش

Open → Process → Close

ئاساسىي قەدەملەر:

Basic Steps:

  1. فايلنى ئېچىش
  2. Open the file
  3. ئوقۇش/يېزىش ئەمەلىيەتلىرى
  4. Read/write operations
  5. فايلنى تاقاش
  6. Close the file

فايل ئوقۇش ۋە يېزىش

File Reading and Writing

Python 
# فايل يېزىش | Writing to file
with open("مەسىلە.txt", "w", encoding="utf-8") as فايل:
    فايل.write("بىرىنچى قۇر\n")
    فايل.write("ئىككىنچى قۇر\n")
    فايل.write("ئۈچىنچى قۇر\n")

# فايل ئوقۇش | Reading from file
with open("مەسىلە.txt", "r", encoding="utf-8") as فايل:
    مەزمۇن = فايل.read()
    print("پۈتۈن مەزمۇن:")
    print(مەزمۇن)

# قۇرلارنى ئايرىم ئوقۇش | Reading lines separately
with open("مەسىلە.txt", "r", encoding="utf-8") as فايل:
    قۇرلار = فايل.readlines()
    for قۇر in قۇرلار:
        print("قۇر:", قۇر.strip())  # strip() بوشلۇقلارنى چىقىرىدۇ

فايل ھالەتلىرى

File Modes

"w" - يېزىش

"w" - Write

يېڭى فايل ياسايدۇ ياكى مەۋجۇت فايلنى ئەسلىيەتلىك قىلىدۇ

Creates new file or overwrites existing file

  • فايل بولمىسا ياسايدۇ
  • Creates file if not exists
  • فايل بار بولسا ئەسلىيەتلىك قىلىدۇ
  • Overwrites if file exists
  • يېزىش ئۈچۈن ئېچىلىدۇ
  • Opened for writing

"r" - ئوقۇش

"r" - Read

فايلنى ئوقۇش ئۈچۈن ئېچىدۇ

Opens file for reading

  • فايل بولمىسا خاتالىق چىقىرىدۇ
  • Raises error if file not exists
  • ئوقۇش ئۈچۈن ئېچىلىدۇ
  • Opened for reading
  • يېزىشقا بولمايدۇ
  • Cannot write

"a" - قوشۇش

"a" - Append

فايلنىڭ ئاخىرىغا مەلۇمات قوشۇش ئۈچۈن ئېچىلىدۇ

Opens file for appending data to end

  • فايل بولمىسا ياسايدۇ
  • Creates file if not exists
  • مەۋجۇت مەزمۇننى ساقلايدۇ
  • Preserves existing content
  • يېڭى مەلۇماتنى ئاخىرىغا قوشىدۇ
  • Adds new data to end

Error Handling

خاتالىقلارنى بىر تەرەپ قىلىش نېمە؟

What is Error Handling?

خاتالىقلارنى بىر تەرەپ قىلىش - پروگراممىدىكى خاتالىقلارنى تۇتۇش ۋە كونترول قىلىش ئۇسۇلى.

Error handling is the process of catching and controlling errors in programs.

خاتالىق بىر تەرەپ قىلىش قۇرۇلمىسى

Error Handling Structure

سىناش → تۇتۇش → بىر تەرەپ قىلىش

Try → Catch → Handle

ئاساسىي قۇرۇلما:

Basic Structure:

try: - خاتالىق كېلىشى مۇمكىن بولغان كود

try: - Code that might cause error

except: - خاتالىق كەلگەندە ئىجرا بولىدىغان كود

except: - Code to execute when error occurs

ئاساسىي خاتالىق بىر تەرەپ قىلىش

Basic Error Handling

Python 
# ئاساسىي try-except | Basic try-except
try:
    سان = int(input("بىر سان كىرگۈزۈڭ: "))
    نەتىجە = 10 / سان
    print("نەتىجە:", نەتىجە)
except ZeroDivisionError:
    print("خاتالىق: نۆلگە بۆلۈشكە بولمايدۇ!")
except ValueError:
    print("خاتالىق: توغرا سان كىرگۈزۈڭ!")
except Exception as e:
    print("باشقا خاتالىق:", e)
else:
    print("خاتالىقسىز ئىجرا بولدى!")
finally:
    print("بۇ ھەر ھالدا ئىجرا بولىدۇ.")
